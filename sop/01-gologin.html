步骤 1.5 · 应急方案(注册/试用续费)

⚠ 已知问题(2026-07-20):① gologin.com 国内直连偶发慢;② 试用 7 天到期后需 $24/月付费(年付 $192 ≈ ¥1380);③ 同一 Gmail 二次注册被风控

方案 A · gologin.com 国内访问慢 → 加速 3 招:
① Cloudflare WARP 免费(1.1.1.1,3 分钟装好)
② Edge 浏览器 + Cloudflare 扩展(零成本,适合 M1 试用)
③ 已有 Bright Data 代理先开 GoLogin(用 US/UK ISP IP 访问 gologin.com)

方案 B · 试用 7 天到期不续费 → 3 种替代路径:
① 新建 Gmail + 第二次 7 天试用(60% 通过,部分账号被标记)
② AdsPower 替代(https://adspower.com)$9/月,基础功能够用,缺点:无深度指纹修改
③ 不续费直接用 Chrome + Bright Data(单 Workspace 够用,M2 前不必扩 GoLogin)

方案 C · 付费 $24/月 → 4 级支付备选:
① 招行 / 工行 / 中行双币信用卡(VISA/MasterCard)(75%,首选)
② PayPal 绑双币信用卡(85%,中转拒付率低)
③ Wise 虚拟卡(95%,长期订阅避风控)
④ 淘宝代付(100%,搜 gologin 会员 代付,加 10% 服务费)

方案 D · 年付 $192 太贵 → 拆解策略:
M1 试用 7 天免费 → M2 月付 $24 → M4 月入 ≥¥3k 后转年付($192 省 $96)
实测发现月付 → 年付 切换 goLogin 不扣留余额,可放心月付试水
⚠ 红线: 不要用 1.1.1.1 外的免费 VPN(被 GoLogin 风控标记)→ 注册即封号;不要在淘宝买"低价 GoLogin 账号"代注册 → 90% 盗号,登录即失效

步骤 2 · 下载客户端

后台 → "Downloads"
Windows:GoLogin-Setup-x.x.x.exe(约 250MB)
安装路径建议:D:\Tools\GoLogin\(不放 C 盘)
启动后用刚注册的账号登录

步骤 3 · 创建第 1 个指纹档案

客户端 → "Create New Profile"
名称:AR-Main-Workspace(语义化命名)
操作系统:Windows 11
浏览器:Chrome 120
分辨率:1920x1080
语言:en-GB
📷 截图位: 档案配置页

步骤 4 · 绑定 Bright Data UK IP

在档案配置 → "Proxy" → 选 HTTP
填入 SOP-03 获取的代理信息:
Host: brd.superproxy.io
Port: 22225
Username: brd-customer-XXX-zone-isp-uk
Password: XXXXX
点击 "Check Proxy" → 验证显示 UK IP
⚠ 绑定前先验证: 若未验证就保存,后续所有浏览都失败;Check Proxy 必须显示国家=United Kingdom
📷 截图位: 代理绑定 + IP 验证成功

步骤 5 · 启动档案 + 验证

选中 AR-Main-Workspace → 点击 "Run"
自动打开隔离 Chrome 窗口
访问 https://browserleaks.com 检查:
• Canvas 指纹:每次启动应不同(随机)
• WebGL 渲染器:显示真实 GPU(非 SwiftShader)
• 时区:Europe/London
• 语言:en-GB
访问 https://whoer.net 检查匿名度 ≥ 80%
💡 指纹独立性: 同一台机器开 2 个 GoLogin 档案,canvas 哈希完全不同 = Google 无法关联
📷 截图位: browserleaks 检测结果

步骤 6 · 用档案注册 Workspace

在 GoLogin 档案内访问 https://workspace.google.com
选择 "Start a free 14-day trial"
用 泰国 +66 号接收验证码(SOP-01 准备的卡)
业务名:填个人工作室名(英文)
国家:United Kingdom
注册成功后 → 截图保存到 sop/_records/workspace-1.png

步骤 7 · 试用 7 天结束后决策

试用期内判断:
• 跑通 M1 全流程(注册 Workspace + YT 频道 + 30 条上传)
• 若跑通 → M2 W1 转 $24/月年付($192/年,折 ¥1380)
• 若未跑通 → 不续费,直接用现有 Chrome + Bright Data(单 Workspace 够用)
