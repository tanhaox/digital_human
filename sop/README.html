📐 SOP 使用规则(必读)

每个 SOP 必须包含 5 大要素:
  • 1. 元信息块 — 阶段 / 前置依赖 / 单次成本 / 耗时 / 责任人
  • 2. 操作流程 — 编号步骤(每步 1-3 行 + 截图位)
  • 3. 验收清单 — 可勾选 checkbox(点击交互)
  • 4. 验收标准 — 明确"完成"定义(可量化)
  • 5. 完成确认按钮 — 一键确认 + 时间戳 + 进度归档
SOP 状态机:

待执行 (Pending) → 进行中 (In Progress) → 待验收 (Verifying) → 已完成 (Done)
                                                             ↓
                                                           失败 (Failed) → 回退待执行

何时新建 SOP(任一条件):
  • 涉及真实付款(>¥100 或 >$10)
  • 涉及不可逆操作(LLC 注册、EIN 申请、域名购买)
  • 涉及关键决策点(语言切换、风控应对)
  • 需多人协作(助理接入)
