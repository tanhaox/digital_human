🎯 为什么用 Edge TTS

  • 零成本:Microsoft Edge 浏览器内置 TTS,通过 Python 库免费调用,无需 Azure 账号
  • 多语种:支持 100+ 语种 / 400+ 声音,中文 / 英文 / 阿语均有 Neural 级别音色
  • 离线推理:Python 库只发起 HTTP 请求,Edge 服务返回 MP3,本地无 GPU 也能跑
  • 零依赖:pip 一行安装,无 ffmpeg / 无 tensorflow / 无 CUDA
⚠ 限制:Edge TTS 商用风险?个人非商业可免费,商用建议升级 Azure($1/百万字符,首月 $200 免费)。本 SOP 仅用于 M0 验证,后续阶段会评估 Azure。

🚨 应急方案

方案 A · NoAudioReceived / 网络失败
1. 重试 3 次(Edge 服务偶发超时)
2. 改用 VPN / 代理(科学上网)
3. 改用 edge-tts --list-voices 列出所有可用声音(网络通则能列)
4. 还失败 → 备用 Coqui TTS(完全本地,但慢 + 模型大)
方案 B · 阿语发音差(打算放弃 Edge 阿语)
1. 试听后请阿拉伯语朋友评分(≥7 分继续用)
2. 评分 ≤6 → M2 启动后切 Azure 阿语 Neural($1/百万字符,先试 100 条 ≈ ¥20)
3. Azure 体验仍差 → 改 MUSE / ElevenLabs(更贵,$5/月起)
方案 C · pip 装错环境
若同时有 Python 3.8 / 3.11 多版本:用 py -3.11 -m pip install edge-tts 指定版本
推荐:用 conda 或 pyenv 隔离环境
