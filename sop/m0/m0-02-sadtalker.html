🎯 为什么选 SadTalker

  • 开源:GitHub 开源,4 万 star,持续更新(github.com/OpenTalker/SadTalker)
  • 效果好:唇形 / 表情 / 头部运动 自然度,在开源方案中第一梯队

  • 替代:MuseTalk(更新,效果更好) / LivePortrait(更快,但只头部运动)

✅ 10 步执行清单

命令(Windows CMD):
nvidia-smi
期望输出: 显示 GPU 型号 + CUDA Version(≥11.7)+ 显存 ≥4GB
若无 NVIDIA 卡: 跳过此步,直接走步骤 7(Colab 方案)
📷 截图位: GPU 信息(型号 + 显存)
✅ 验收:看到 NVIDIA 显卡信息 OR 决定用 Colab
命令(根据 CUDA 版本,NVIDIA 官网选对应命令):
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
注: cu118 = CUDA 11.8;若 CUDA 12.x 用 cu121
验证:
python -c "import torch; print(torch.cuda.is_available())"
期望: 输出 True
⚠ 慢:PyTorch 安装 2-5 GB,看网络。失败重试 3 次。
✅ 验收:torch.cuda.is_available() 返回 True
命令:
git lfs install
若 git lfs 未装: 下载 git-lfs.github.com 安装
为什么:SadTalker 模型权重 >2GB,必须 LFS 下载
✅ 验收:git lfs install 无报错
命令:
cd F:\AI-Agent-Local\数字人计划 git clone https://github.com/OpenTalker/SadTalker.git
期望: 生成 SadTalker/ 目录,大小 ≈150MB(不含模型)
⚠ 网速慢:GitHub 国内不稳定,失败可用 Gitee 镜像:
git clone https://gitee.com/mirrors/SadTalker.git
📷 截图位: SadTalker 目录结构(应有 inference.py + checkpoints/)
✅ 验收:目录存在 + 有 inference.py
方法 A · 用 SadTalker 自带脚本(推荐):
cd SadTalker bash scripts/download_models.sh
方法 B · 手动下载(网络不稳时):
1. 访问 SadTalker Releases
2. 下载 epoch_20.pth(≈80MB)+ SadTalker_V0.0.2_*.safetensors(≈2GB)
3. 放到 SadTalker/checkpoints/
4. 下载 epoch_5.pth 等其他模型
⚠ 失败 3 次: 可能是 HuggingFace 被墙,改镜像 HF_ENDPOINT=https://hf-mirror.com bash scripts/download_models.sh
📷 截图位: checkpoints/ 目录列表,文件总大小 >2GB
✅ 验收:checkpoints 目录有 epoch_20.pth 等关键模型
命令:
cd SadTalker pip install -r requirements.txt
期望: 安装 dlib / face-alignment / librosa 等
常见错误:
  • dlib install failed: 装 Visual Studio Build Tools(C++ 编译器)
  • ffmpeg not found: 装 ffmpeg 加入 PATH
✅ 验收:pip install 无报错退出
目的:准备 1 张正面图(512x512+)+ 1 个音频(MP3/WAV)
图要求:
  • 正面照,1 张脸,无遮挡(眼镜 / 口罩会降低效果)
  • 分辨率 ≥512x512,推荐 1024x1024
  • 格式:JPG / PNG,大小 <5MB
来源:
  1. 先用 SadTalker 自带示例: SadTalker/examples/source_image/ 有 4 张默认图
  2. 或下载 Pexels 免费人像(关键词 "portrait man front")
  3. 或用 M0-SOP-04 准备的形象照
音频:用 M0-SOP-01 生成的 test_zh.mp3(或任一段 5-10 秒音频)
📷 截图位: 测试图文件 + 音频文件
✅ 验收:有 1 张 512x512+ 的正面图 + 1 个 5-10 秒音频
命令(假设图叫 avatar.jpg,音频 test_zh.mp3):
cd SadTalker python inference.py --driven_audio test_zh.mp3 --source_image avatar.jpg --result_dir ./results --enhancer gfpgan
期望:
  • 终端输出 Loading... → Inferencing... → Done!
  • 耗时 30-90 秒(3060/4060)
  • 产出:results/2026_07_20_xx_xx_xx/full.mp4(5-15 秒)
⚠ OOM 显存不够: 加 --size 256 降低分辨率;或加 --batch_size 1
📷 截图位: 终端 Done + results 目录列出 MP4
✅ 验收:results 目录有 MP4 + 文件大小 >100KB
打开 MP4(VLC / 系统播放器 / Chrome)

🚨 应急方案

方案 A · OOM(CUDA out of memory)
1. 加 --size 256 降低分辨率(256x256)
2. 关闭其他 GPU 程序(浏览器硬件加速 / 游戏)
3. 升级到 8GB+ 显存显卡(二手 RTX 3060 ¥800)
方案 B · SadTalker 效果差(评分 ≤6)
换工具链(按推荐度):
1. MuseTalk(效果更好,2024 新)
2. LivePortrait(超快,只头部)
3. HeyGen API($24/月,商业级,但成本高)
4. D-ID($5.9/月,云端,免 GPU)
方案 C · 模型下载失败 5+ 次
HuggingFace 被墙 → 设环境变量:
set HF_ENDPOINT=https://hf-mirror.com
重跑下载脚本
