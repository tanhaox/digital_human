🎯 为什么需要 FFmpeg

  • 拼接:SadTalker 输出的是无声 MP4 + TTS 是 MP3 → 必须用 FFmpeg 合流
  • 转码:不同采样率 / 分辨率 / 帧率统一输出(避免 YT 上传报错)
  • 轻量:一个 ~80 MB 的 exe,无需安装,绿色版直接用
  • 免费:开源 LGPL/GPL,商用无版权问题

🚨 应急方案

方案 A · FFmpeg 合并报错 "moov atom not found"
视频流有问题:
ffmpeg -i full.mp4 -c copy -fix_sub_duration fixed.mp4
或重新转:
ffmpeg -i full.mp4 -c:v libx264 -preset fast -crf 23 fixed.mp4
方案 B · 音画不同步(常见)
1. SadTalker 输出的 full.mp4 时长 ≠ 音频时长 → 重新推理(可能偶发 bug)
2. 用 -ss 和 -t 截断到等长:
ffmpeg -i full.mp4 -i news.mp3 -c:v copy -c:a aac -shortest -fflags +shortest sync.mp4
方案 C · FFmpeg 输出文件超 10 MB(1 分钟视频)
加压缩:
ffmpeg -i demo.mp4 -c:v libx264 -preset slow -crf 28 -c:a aac -b:a 128k small.mp4
crf 28 = 高压缩,画质仍可接受
