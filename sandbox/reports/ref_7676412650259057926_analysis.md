# 短视频编导拆解报告

## 1. 剪辑节奏

**切换频率：**
- 开场前15秒：平均每1.5秒切换一次，高密度视觉轰炸
- 技巧讲解段：每3-5秒切换，配合口播节点
- 口播段落：10-15秒长镜头，营造知识分享氛围

**段落结构：**
```
[0-33s]  开场钩子 + 8大技巧预告
[33-35s]  技巧一标题卡
[35-193s] 技巧一（角色资产）详细讲解
[193-220s] 技巧二（空间地图）
[220-253s] 技巧三（多人穿帮处理）
[253-289s] 技巧四（尺寸比例）
[289-347s] 技巧五（镜头语言）
[347-394s] 技巧六（物理质感）
[394-418s] 技巧七（提示词结构）
[418-442s] 结尾引导 + 下期预告
```

**关键发现：** 每个技巧讲解时长约30-40秒，形成稳定的"知识单元"节奏，观众容易跟随。

## 3. 配合规律

**触发画面切换的关键词：**

| 词性/内容 | 示例 | 对应画面 |
|-----------|------|----------|
| **数字** | "95分钟"、"15个人"、"50万"、"14天" | 数字大字卡 + B-roll |
| **转折词** | "更夸张的是"、"但"、"而" | 画面切换，制造节奏感 |
| **名词概念** | "角色资产"、"声音资产"、"空间地图" | 标题卡 + 对应B-roll |
| **动作词** | "准备"、"去掉"、"贴回"、"生成" | 展示操作过程B-roll |
| **对比词** | "不是...而是..." | 左右分屏或画中画对比 |
| **强调词** | "注意"、"真的" | 画面放大/特效突出 |

**发现：** 数字类信息几乎100%配画面，形成"口播数字→画面弹出数字"的条件反射，提升信息吸收率。

## 4. 后期包装规律

**字幕：**
- 位置：底部中央黑底白字（口播时）/ 右上角（B-roll时）
- 字号：口播时约24-28px，B-roll时约18-22px
- 颜色：白字为主，数字/强调用黄色
- 出现时机：口播开始后0.5秒内上屏，口播结束前0.3秒下屏

**贴纸/特效：**
- 开场段：绿色光效、粒子、圆形画中画（营造电影感）
- 技巧段：无特效，保持干净
- 数字卡：金色渐变字 + 光晕
- 界面展示：无额外特效，突出UI本身

**标题卡：**
- 33-35s：技巧一标题，圆角框 + 渐变背景
- 后续技巧：用口播过渡，不单独做标题卡（避免节奏拖沓）
