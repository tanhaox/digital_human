# 美术圣经 (全片统一, 每镜必须继承)

**风格**: 传统赛璐璐手绘动画 (1988 年代感) — 线条干净、色彩鲜艳、明暗界限分明、12帧手绘呼吸感、略显笨拙的手工质感。角色绘制在透明赛璐珞胶片上与手绘背景叠加。
**注意**: 风格随书变 (同受众地图) — 每本书的美术圣经可能不同, 此为 HBO 书的定稿。
**色彩**: 靛墨蓝/琥珀黄/纸白/雾灰蓝 基调, 朱红仅作强调色 (全片最多 3 处)。
**角色**: 如需人物, 用极简几何剪影 (无脸/背影/侧影), 不画具体五官。
**禁**: 赛璐璐平涂、日系动漫、赛博朋克、写实风、3D 渲染。全片一个视觉身份, 禁风格切换。

# 六原则 (0914 定稿, 违反=废稿)

1. **音频先行**: 时长从 TTS manifest 来, 每段时长 = 字数÷4.6
2. **运动驱动**: 先想"什么运动在讲故事"(扩张/时间流逝/变形), 按运动节拍切镜; 禁逐句配图
3. **双向增益**: 画面补充/放大/对比口播, 禁复述 (口播说"很小"→画面给"小到地图上看不见", 不是画一个小房子)
4. **时间预算**: 每镜 2-6s (口播≤2句); 段内镜数 = 段时长÷4 向上取整 不封顶; 整集镜数 ≈ 集时长秒数÷5 (230s 的集 ≈ 45镜) — 视觉密度是留存硬指标, 宁密勿疏
5. **弧内连贯·每镜必换构图**
6. **清单段禁卡牌 (0916 用户最不想要)**: 口播逐条列举 (第X集/工具清单/多条测试) 时,
   严禁物化成卡牌/卡片/图鉴陈列 — 每条给生活真实场景, 或全段一个连贯视觉隐喻
   (旅程/流水线/地图) 每镜一站; 条目文字交给花字层, 全片禁卡牌式画面
: 同弧共享场景/主体/色调, 但每镜的景别/机位/主体动作至少一项不同; **严禁「同一场景 机位不变」式续镜** — 同场景重访必须换视角, 一个画面概念不得连续占用两镜 (续镜=浪费镜头预算, 实锤被毙)
6. **全片统一**: 吉普力水彩贯穿全片

# H3 技术禁忌 (实锤)

- **定焦为主**: camera holds fixed + 内容动画 (光效变化/渐显/屏幕变化) — 这是主模式
- **dolly in/out 可用** 但禁急推急拉
- **禁全场景形变/禁原地跑/禁镜面反射**
- **每拍至少一个可见变化** (整拍静止 = H3 自由发挥穿模)
- **禁文字数字** → 走 text_layer

# 任务（对整集口播稿，分三件事）

1. **语义分段**：把口播稿重新切成语义段落。稿件原有【起-止秒｜段落名】标签只是原文档的估算参考，**不要按它铺时间**。切分与时长只看口播本身：每段口播 ≤37 字（≈8 秒实讲，语速 4.6 字/秒 — 2.5 说书音色实测），一段一个意思；**段时长 = 字数÷4.6 秒**（系统会确定性覆算，你给的 duration_s 只是初值）。宁短勿长，长段必拆。
2. **画面描述（visual_desc）**：每段一条中文画面描述，具体到可画：构图（中景/特写/全景）、主体与动作、场景物件、光线色彩。抽象概念必须落到具体视觉隐喻（"增长停滞"→ 曲线撞墙，不是"低迷氛围"）。
3. **动画节拍（anim）**：每段给英文节拍，2-3s/拍，总长 = 段长。

# 硬约束

- **人物设定库（出镜必逐字沿用，跨镜一致）**：
  - 女主青年：灰色短头发、白衬衣、黑色超短裙、黑色高跟鞋。
  - 男主中年：黑色短头发、白衬衣、黑色西裤、黑色皮鞋。
- **微叙事（画面丰富的正解, 用户实测范式）**：不是堆道具数量，是每个元素都讲故事。黄金范例：
  「深夜办公室。一个动漫风格的无脸职场女性背影，面对三块发光屏幕：账号后台、投流预算、收入曲线。预算数字翻倍，收入线平直。桌上咖啡冷掉。青灰环境，暖橙屏幕光」
  拆解: ①时段/场所氛围(深夜办公室) ②人物姿态优先背影/侧影/低头/仰头, 可无脸——情绪靠姿态与光线, 不靠脸 ③道具要讲故事(三块屏各有内容、咖啡冷掉=熬了很久) ④一组冷暖光色对比(青灰环境×暖橙屏光)。
- 每条 visual_desc 必含: 时段氛围 + 人物具体姿态 + 1-3 个讲故事的道具细节 + 冷暖光色对比。
- **文字分工（0911 晚定稿, 两流联动）**：K2 出图**全面零文字零数字**——屏幕只给纯图形画布（曲线/柱形/色块/走势形态，无标注无数字无招牌，系统尾已锁）；需要的文字（数据标签/标题卡/字卡）**全部推迟到 anim 节拍里写**，由 H3 视频层渲染（写法见「视频内文字」条）。visual_desc 永不写文字内容，要字就写进 beats。
- **禁悬浮装饰物**（天线/雷达/悬空道具/悬空文字带）——穿模重灾区；场景元素要么落地、要么远景留白。
- **四条动画禁令**：①禁全场景几何形变→改阴影/亮度变化；②~~禁 orbit~~ **orbit 环绕已解禁**（0911 晚 s59 实证 anime 态干净：从背后连续单弧绕到正脸，背景透视自然旋转）——写法=one smooth continuous orbit + 人物/环境锚定只有视点动；③禁元素巨变生长→改渐显/发光；④禁分屏结构重排→改光晕呼吸明暗。
- **第五条禁令（位移行进, 收窄版 s16/s19/s60 三案定谳）**：禁「画框内的原地行进」（朝镜头走/跑步机上式走动=原地跑鬼畜）与长距离框内位移+道具（推车穿插）。**放行**：走出画面/走入画面（exit/enter frame, 有明确目的地, s60 实证拿包出画完全干净）、弯腰拿取道具的交互动作（拿包甩肩 s60 实证）、背景配角走动（s41）。人物框内站位移动仍交给镜头推近与光影流动表达。
- **结尾微动纪律（禁 PPT 定格, s17/s18 实锤）**：ending 禁止"settles/holds/still"式纯定格。落点必须保留可见微动：发丝与衣角被风轻拂、尘埃在光里飘、光晕呼吸。系统壳会自动追加全程微风条款，你的 ending 不要与之矛盾。
- **page_type**：开头钩子/核心隐喻/结尾问句段 = "C"（全帧动画页，每集 2-3 个，ending 给白闪硬切口）；其余 = "B"（ending 落在可定格的稳定画面）。
- **画面多样性（隐喻轮换纪律）**：同一核心道具（墙/门/路/平板等）全集成片最多 2-3 镜。核心概念重复出现时必须换隐喻载体轮换，例如"空间耗尽"可用：收窄的走廊、装满再也塞不进的容器、到顶的电梯、走到头的楼梯、见底的水池、关死的门、用尽的胶卷、停摆的钟。禁止多镜反复"人面对墙/摸墙"。
- **首分钟铁三角: 密度 × 多样性 × 钩子 (0923 双实锤: 7镜同景=幻灯片 / 1镜60s=纪录片)**:
  ① **密度**: 前 60s 特区 = **12-18 镜** (每镜 2-4s)。一镜到底(>8s)或只切 1-2 镜 = 严重违规。
  ② **多样性**: 相邻镜 keyframe_zh 必须**换主体/换场景/换隐喻** — 同一场景/道具只换机位
     (特写→中景→俯视) 不算多样。判定: 前后镜主体名词重叠 >50% = 违规。
     但多样性靠**多出镜**实现, 不靠**合并镜** — 越多样越要切碎, 不是合并成一镜。
  ③ **钩子**: 首分钟是流量承接区, 观众手指在滑 — 每镜首拍 1s 内就要有可见变化。
  范式参考: 钩子镜(情绪冲击)→诊断镜(概念可视化)→案例镜(故事场景)→数据镜(数字具象化)→
  人物镜(角色出场)→概念镜(隐喻载体)→悬念镜(半开之门/悬置之物) — 每镜一个独立画面世界。
