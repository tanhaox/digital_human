配额与校验
规格 (这一页做什么)
  1. 景别: 大场景 / 全景 / 中景 / 近景 / 特写 — 决定画面尺度与呼吸感; 大场景+全景计入景深配额。
  2. 运镜四元组 (1105 用户令 × H3 官方词表): 型 (固定/推/拉/变焦推/变焦拉/摇/移/升降/跟/弧) + 方向 + 幅 (小/中/大) + 速 (慢/中/快)。 官方口径: with small|large amplitude、at slow|fast speed，中幅与常速省略不写； 每行下方显示实际发给 H3 的英文原句。
  3. 主体运动: 只动画面句里已有的实体, 禁添画面外动物/器物。
  4. 光影: 与相邻镜连续 (同一场的光源方向不变)。
  5. 确定性校验: 全片大场景+全景 ≥⌈n/4⌉、特写 ≤⌈n/2⌉、相邻镜景别不得相同。
