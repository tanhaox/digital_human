      五段式骨架（方法论 · 未被改写）
      
1. Core theme            ← 3-6 个风格标签, | 分隔
2. Character & scene     ← 人物 / 瑕疵 / 环境
3. Atmosphere & quality  ← 视觉基底 / 色调 / 风格核心 (+真实机身镜头)
4. Camera rules          ← 单/多镜头 / 运镜 / 呼吸感 / 现场声
5. Storyboard            ← 逐秒或逐镜分解 + 留白结尾

三条反直觉规则:
① 写真实相机+镜头型号, 不写 "cinematic feel"
② 描述瑕疵 (战损/掉漆/油污) — 完美看起来假
③ 结尾留白 — 不爆炸不闪白, 只留一个画面
