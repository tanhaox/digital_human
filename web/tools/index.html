Prompt Workshop

提示工坊不会写提示词也能用。下面选一件你想做的事，跟着步骤走就行——每一步都有说明，不用猜。

首页 反推 人物 镜头 道具 场景
1 我有一张图，想知道它的提示词 上传照片或搜一张网图 → AI 自动拆解出长相、材质、场景描述 → 一键带走。最适合「照着这个感觉做」。 进入 → 2 我要设计一个角色（设定图） 填几个空：长相、发型、穿着 → 自动生成「正面+侧面+背面+特写」四合一设定图的完整提示词，保证四个视角是同一个人。 进入 → 3 我要写视频的生成提示词 简易模式只需三步：说拍什么 → 选风格 → 选时长。适合即梦 / 可灵 / Sora 等视频工具。 进入 → 4 我要做道具设定图测试中 模板还在实测。急着用？先去「反推」选道具类型，同样能拿到材质细节。 暂缓 5 我要做场景设定图测试中 模板还在实测。急着用？先去「反推」选场景类型，同样能拿到环境描述。 暂缓

怎么用 · 通用三步

选页面填空 / 选图反推→ 复制生成的提示词→ 粘贴到生图工具
提示词粘贴到哪？——生图：即梦 / 豆包 / Midjourney / 剪映；生视频：即梦 / 可灵 / Sora / Runway。国内工具直接粘贴中文描述也行，英文提示词通用性最好。
