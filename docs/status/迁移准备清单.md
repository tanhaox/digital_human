## 6. 路径一致性（最大风险）

代码/config/数据库里**大量硬编码绝对路径**：

| 硬编码 | 出现处 |
|---|---|
| `E:/AI/ComfyUI_windows_portable/...` | config/app.yaml + ppt_service + 代码 |
| `E:/数字人计划/...`（roles/hf_visual/director/composition/materials/ppt/logs） | config + 代码 |
| `E:/AI/tts/index-tts-windows`、`E:/AI/tts/fish-speech`、`E:/AI/tts/F5-TTS` | config/app.yaml:tts_services |
| `E:/Llama-cpp-12/...`（llama-server + Gemma/Qwythos GGUF） | distiller + 打标/质检服务 |
| `G:/Desktop/畅销书` | config（book_source_dir 兜底） |
| `C:/Programs/ffmpeg`、`C:/Program Files/Google/Chrome/...` | 代码 |
| `C:/Users/tanhaox/AppData/...`（Playwright/剪映/hyperframes） | 代码 |

**数据库内**：`audio_files.file_path`、`video_assets`、`material_items`、`director_slots` 等存**绝对路径**（2000+ 条），改路径会断引用。

**方案 A（推荐，零改动）**：目标机保持同盘符结构（`E:/` `C:/` `G:/` + 同用户名 `tanhaox`），整盘拷贝 → 无需改任何路径。
**方案 B（改路径）**：改 `config/app.yaml` + 代码硬编码 + `git grep` 全量替换 + SQL 批量 `UPDATE ... REPLACE(path前缀)`。工作量大，建议只做 A。

## 8. 其他注意

- **智谱免费额度 2026-09-12 到期**（迁移后留意续费/换 key）
- **剪映**：需新机装同版本专业版（草稿明文读取兼容）；草稿目录路径随用户名
- **HF 模板无版本控制**：单独备份 `hf_prep/`，易丢失
- **4090 显存竞争**：TTS 托管 + ComfyUI + 蒸馏共用 4090，`tts_services.idle_timeout_sec` 已配自动腾显存
- **GPU 服务托管**：`gpu_service_manager` 按 4090 显存调度，目标机若无 4090 需调 `_specs`/CUDA 设备
