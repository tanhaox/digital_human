# 自动化数字人短视频 — ComfyUI 本地部署方案（v3.0 · 2026-07-22）

> **来源**: [执行计划清单.md](执行计划清单.md) v10 §二 / §三 / §四  
> **定位**: M0 工作流验证阶段的本地 ComfyUI workflow 部署与运行手册。  
> **前提**: 已完成 [M0-GPU-checklist.md](M0-GPU-checklist.md) 自检，确认 GPU 等级与本地/云端混合策略。

---

## 〇 核心原则

1. **单底座**: 图像、视频、后期、导出统一用 **ComfyUI**，不再把 MuseTalk / LivePortrait / SadTalker 作为默认主链。
2. **TTS 多候选**: 中文 **Fish Speech / F5-TTS**，英文/高质感用 **ElevenLabs**。
3. **工作流即资产**: 每个 workflow、prompt 模板、音色包必须版本化入 Git。
4. **M0 门禁**: 1 分钟内连续产出 3 条 30 秒成品视频。

---

## 一、部署目标

| 目标 | 说明 |
|------|------|
| 端到端出片 | 文案 → 图片/视频生成 → 后期合成 → 配音 → 字幕 → 导出 MP4 |
| 输出规格 | 1080×1920 / 30fps / 9:16 / 30 秒 |
| 稳定复现 | 同一 workflow 换文案、换音色后仍能稳定出片 |
| 可扩展 | M2 跑量阶段可半自动化/脚本化批量执行 |

## 三、ComfyUI 安装与配置

### 3.1 安装

```bash
# 1. 克隆
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI

# 2. 虚拟环境
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/macOS

# 3. PyTorch（CUDA 12.1 示例）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# 4. 依赖
pip install -r requirements.txt

# 5. 启动
python main.py
```

默认界面：<http://127.0.0.1:8188>

### 3.2 外置模型目录（推荐）

创建 `extra_model_paths.yaml`：

```yaml
comfyui:
  base_path: D:/comfyui-models/
  checkpoints: models/checkpoints/
  clip: models/clip/
  clip_vision: models/clip_vision/
  configs: models/configs/
  controlnet: models/controlnet/
  diffusers: models/diffusers/
  embeddings: models/embeddings/
  loras: models/loras/
  upscale_models: models/upscale_models/
  vae: models/vae/
  unet: models/unet/
```

### 3.3 启动参数（按显存）

| 显存 | 推荐参数 |
|------|----------|
| ≥12 GB | `python main.py --highvram` |
| 8-12 GB | `python main.py --normalvram --fp16-unet` |
| 6-8 GB | `python main.py --lowvram --fp16-unet --fp16-vae` |
| <6 GB | 本地仅编辑 workflow，渲染走云端 |

### 3.4 必备节点包

| 节点包 | 作用 | 安装 |
|--------|------|------|
| ComfyUI-Manager | 节点/模型管理 | 内置或单独安装 |
| ComfyUI-VideoHelperSuite | 视频加载、导出 | ComfyUI Manager |
| WAS Node Suite | 图像处理、批量 | ComfyUI Manager |
| Comfyroll Studio | 基础工具节点 | ComfyUI Manager |
| Segment Anything / comfyui_segment_anything | 抠像/遮罩 | 按需 |

> M0 先保证“文生图 → 图生视频/动画 → 合成 → 导出 30 秒 9:16”能跑通，再按需扩展节点。

## 四、TTS 部署

### 4.1 Fish Speech（中文主力）

```bash
git clone https://github.com/fishaudio/fish-speech.git
cd fish-speech
pip install -e .
python tools/download_models.py        # 首次下载模型
python tools/run_webui.py              # 启动推理界面 / API
```

- 推理显存：约 4-6 GB
- 默认地址：<http://127.0.0.1:7860>
- 音色文件存档：`assets/voices/fish-speech/`

### 4.2 F5-TTS（轻量备选）

```bash
git clone https://github.com/SWivid/F5-TTS.git
cd F5-TTS
pip install -e .
python src/f5_tts/infer/infer_gradio.py
```

- 推理显存：约 4 GB
- 默认地址：<http://127.0.0.1:7860>（若与 Fish Speech 同时运行需改端口）
- 音色文件存档：`assets/voices/f5-tts/`

### 4.3 ElevenLabs（英文/高质感）

无需本地部署：

```bash
pip install elevenlabs
export ELEVENLABS_API_KEY=your_key
```

- 通过 API 调用
- 音色存档：`assets/voices/elevenlabs.json`

## 五、标准 Workflow 结构（M0 目标）

### 5.1 推荐节点链路

```
文案 / 脚本
  ↓
图像生成 (KSampler / SDXL / Flux)
  ↓
角色/场景一致性控制 (IPAdapter / ControlNet / InstantID)
  ↓
图生视频/动画 (AnimateDiff / Video LDM /  comfy 视频节点)
  ↓
抠像/遮罩/合成 (Segment Anything + Composite)
  ↓
调色/风格化 (Color Correction / LUT)
  ↓
导出 30 秒 9:16 视频 (Video Combine)
  ↓
FFmpeg 后处理：音频混音、LUFS 标准化、硬字幕烧录
```

### 5.2 输出规格

| 维度 | 标准 |
|------|------|
| 分辨率 | 1080×1920（9:16） |
| 帧率 | 30 fps |
| 时长 | 30 秒 ±2 秒 |
| 视频编码 | H.264，YUV420P |
| 音频 | 48 kHz 立体声，LUFS -14 ±1 |
| 字幕 | SRT + 烧录双版本 |

### 5.3 质量门禁

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 分辨率/帧率 | FFmpeg `ffprobe` | 1080×1920 / 30fps |
| LUFS | FFmpeg `loudnorm` | -14 ±1 |
| 音画同步 | 人工听看 | 无明显延迟 |
| 画面一致性 | 人工抽查 | 无闪烁/崩坏 |
| 敏感内容 | 预审清单 | 无政治/医疗/金融/擦边 |

## 六、文件与资产管理

### 6.1 项目目录建议

```
digital_human/
├── workflows/                 # ComfyUI workflow JSON
│   ├── production/            # 已验证生产 workflow
│   └── experiments/           # 实验副本
├── prompts/
│   ├── characters/            # 角色 prompt
│   ├── scenes/                # 场景 prompt
│   └── styles/                # 风格/调性 prompt
├── voices/
│   ├── fish-speech/
│   ├── f5-tts/
│   └── elevenlabs.json
├── scripts/
│   ├── generate_video.py      # 批量生成入口
│   ├── postprocess.py         # FFmpeg 后处理
│   └── upload_queue.py        # 发布队列（M2 后）
├── outputs/                   # 成品视频
├── archive/                   # 历史版本
└── docs/
    └── changelog.md
```

### 6.2 版本化要求

- workflow 文件命名：`workflow_v1.0_20260722.json`
- 每次节点升级/模型替换前复制一份到 `experiments/`
- 通过 Git 提交，commit message 写明变更原因
- 音色文件与对应人设绑定，禁止随意更换

## 八、关键陷阱

| 陷阱 | 后果 |
|------|------|
| 把 MuseTalk/SadTalker/LivePortrait 当主链 | 与 v10 工具链冲突，workflow 无法复用。 |
| 不固定 ComfyUI 节点版本 | 升级后 workflow 崩溃。 |
| 生产/实验 workflow 混用 | 已验证工作流被改坏。 |
| TTS 音色不绑定人设 | 品牌混乱。 |
| 跳过 M0 门禁直接跑量 | M2 产能崩盘。 |
| 本地显存不足硬跑视频节点 | OOM、死机、时间浪费。 |
