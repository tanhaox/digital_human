## 一、一句话结论

优秀的西语 30 秒数字人短视频 = **强钩子（0-3s）+ 价值承诺（3-8s）+ 高密度信息事件（8-28s）+ 明确 CTA（28-30s）**，全程音画稳定、字幕可读、人设一致、母语可懂、合规无敏感内容。

---

## 二、西语脚本节奏（30 秒）

### 2.1 词数与语速

| 指标 | 标准 |
|------|------|
| 总词数 | **60-80 词**（30 秒） |
| 语速 | 约 **130-160 wpm** |
| Hook 词数 | ≤ 10 词，0-3 秒 |
| 每 beat 时长 | 7-10 秒 |

> 西语词长全欧最长（平均 5.8 字母），同样 30 秒信息密度低于中文，需比英文更克制动词变位与从句嵌套。

### 2.2 三段式模板

```
[0-3s]   Hook    → "¿Crees que la renta es el problema? No lo es."
[3-8s]   Promise → "En 30 segundos, las 3 señales que realmente importan."
[8-28s]  Body    → Señal 1 (7s) + Señal 2 (7s) + Señal 3 (6s)
[28-30s] CTA     → "Dale like y sígueme si te sirvió."
```

**西语 Hook 高打开句式**：
- 反直觉："¿Crees que X? La verdad es Y"
- 数字冲击："El 90 % no sabe la señal #3"
- 悬念缺口："La verdadera razón por la que pasa X"
- 冲突："Este dato nuevo te va a sorprender"

## 三、字幕与文案硬指标

### 3.1 字幕排版

| 维度 | 标准 |
|------|------|
| 行数 | ≤ 2 行 |
| 行宽 | **≤ 6 词/行**（西语单词长，宁短勿满） |
| 字号 | 1080 宽下 ≥ 48 pt |
| 安全区 | 底部 15% 留给平台 UI |
| 关键词高亮 | 每 30 秒 3-5 次，颜色与品牌色一致 |
| 字体 | Inter / Roboto / Montserrat / Helvetica Neue，必须完整支持 ñ / á / é / í / ó / ú / ü / ¿ / ¡ |
| 描边 | 白字 + 黑描边，确保任何背景可读 |

### 3.2 西语文案禁忌

- 避免医疗/金融/法律投资建议（优先加 "No es asesoramiento financiero/médico/legal" 免责声明）。
- 避免绝对化表述："siempre", "nunca", "garantizado", "100%"（平台+合规风险）。
- 避免文化刻板印象：拉美不是单一国家，忌用 "todos los latinos..."。
- 单条视频内统一方言/拼写：墨西哥拼写（color）与西班牙拼写（colour）不可混用。

## 四、音频硬指标

### 4.1 TTS 选型

| 语言 | 首选 | 备选 | 备注 |
|------|------|------|------|
| 西班牙语 | **ElevenLabs** | **Fish Speech / F5-TTS** | ElevenLabs 多语言音色自然；Fish Speech/F5-TTS 待实测西语效果 |

### 4.2 响度与混音

| 指标 | 标准 |
|------|------|
| 成品 Integrated LUFS | **-14 LUFS** |
| True Peak | ≤ -1 dBTP |
| 人声 vs BGM | BGM 低于人声 12-18 dB |
| Hook/CTA BGM | 可略增强，但不超过 -22 LUFS |

### 4.3 西语音色与人设

- 每个账号绑定 1 个固定音色。
- 默认优先覆盖 **es-MX 墨西哥口音**（人口基数最大、拉美电视文化强势）。
- News / Finance：沉稳、清晰、略带权威感。
- Tech / Vlog：亲和、自然、节奏明快。
- Story / Lifestyle：温暖、情感、语速偏慢。
- 发布前必须听完整条，检查数字读法、专有名词重音、吞音与连读是否自然。

## 五、镜头与构图（9:16）

| 维度 | 标准 |
|------|------|
| 画幅 | **1080×1920 / 30fps** |
| 头部位置 | 画面上 1/3，cx ≈ 0.5，cy ≈ 0.42 |
| 头顶留白 | 8-12% |
| 视线方向留白 | 40-50% |
| 下巴下方留白 | 30-40%（字幕安全区） |
| 人物占比 | 胸部以上特写为主 |

**西语形象气质特殊要求**：
- **不绑肤色 / 不绑国籍 / 不绑性别**：墨西哥混血、阿根廷欧裔、哥伦比亚三色混血差异极大，忌"金发碧眼白人模板"。
- **业务亲和 > 权威感**：西语观众偏好"邻家业务主播"，而非央视式硬新闻脸。
- **年龄**：25-40 岁区间最吸睛。
- **表情**：友好微笑可露齿，西语市场视为亲和力而非不专业。
- **穿着**：casual profesional（海军蓝 / 炭灰 / 暖白针织外套 + 衬衫），忌纯黑权力套装；眼镜细框金属可戴（西语例外）。

## 六、节奏与视觉事件

30 秒内建议 **10-15 个视觉断点**：

| 事件 | 时机 | 形式 |
|------|------|------|
| 字幕卡弹出 | 关键词出现 | 0.2-0.4s 缩放进入 |
| 关键词高亮 | 每 7-10s | 变色/放大/描边 |
| 微 zoom | 每 5-10s | 5-10% 推近 |
| PIP 数据卡 | 数据/对比出现时 | 占画面 15-25% |
| BGM beat | 每 2-3s | 配合画面切换 |

## 七、ComfyUI Workflow 反推

西语 30 秒短视频的推荐节点链路：

```
西语文案 / 脚本模板
    ↓
角色一致性控制（IPAdapter / InstantID / ControlNet）
    ↓
文生图 / 图生视频（SDXL / Flux / AnimateDiff / 视频节点）
    ↓
口型/动画（ComfyUI 内唇同步节点，按需）
    ↓
9:16 构图/合成（固定头部位置、背景、安全区）
    ↓
西语字幕/关键词高亮（字幕节点 / drawtext，必须支持特殊字符）
    ↓
TTS（ElevenLabs / Fish Speech / F5-TTS）→ loudnorm → sidechain ducking BGM
    ↓
导出 1080×1920 / 30fps / H.264 / LUFS -14 / 硬字幕 + SRT
```

**必须参数化**：

| 参数 | 说明 |
|------|------|
| `character_prompt` | 西语人设 prompt（形象、服装、气质） |
| `scene_prompt` | 场景/背景 prompt |
| `script_text` | 西语文案 |
| `voice_id` | 西语音色 ID，默认绑定 es-MX |
| `subtitle_style` | 西语字体/颜色/高亮规则（含特殊字符支持） |
| `bgm_mood` | BGM 情绪标签 |
| `output_format` | 9:16 / 1:1 / 16:9 |

## 九、西语内容合规

1. **AIGC 标识**：视频或简介显著标注 "Contenido generado por IA" / "host digital"；YouTube 上传时勾选 "Altered or synthetic content"。
2. **欧盟 AI Act**：若覆盖西班牙，视频前 3 秒必须叠加 "Contenido generado por IA" 字样（2026-08 生效）。
3. **墨西哥 LFPDPPP**：评论区收集任何 PII（电话/邮箱）需双 opt-in。
4. **禁区**：政治煽动、金融投资建议、医疗效果、擦边、性暗示、冒充真人、DMCA 高风险素材。
5. **拉美限流词慎用**：
   - 毒品："narcotráfico" / "narco" / "cártel" / "sicario"
   - 暴力："ejecución" / "masacre"（大场景才允许）
   - 政治极端："dictadura" / "golpe de estado" / "fraude electoral"
   - 替代策略："violencia" 改 "incidente de seguridad" / "narco" 改 "crimen organizado"
6. **文化红线**：
   - 禁用"毒贩/毒品"作为吸睛点。
   - 西班牙频道忌议西班牙内战 / 佛朗哥（YouTube 西班牙区域易限流）。
   - 委内瑞拉政治敏感，涉马杜罗政权新闻慎发。
7. **免责声明**：涉及财经/健康/法律时加 "No es asesoramiento financiero/médico/legal"。
8. **版权**：背景音乐必须使用授权曲库（Epidemic Sound / Artlist / Musicbed）；新闻素材改写 ≥ 30% 或购买授权。
9. **可溯源**：保留文案、提示词、生成参数、发布链接。

## 十、跨语种本地化要点

西语版必须从中文稿 **equivalencia dinámica** 重写，而非直译：

| 中文表达 | 西语处理 |
|----------|----------|
| "内卷" | competencia feroz / "todos corren por lo mismo" |
| "躺平" | "dejar de competir" / "bajarse del tren" |
| "996" | "la jornada 9-9-6" + 脚注 |
| "割韭菜" | "estafar a los pequeños inversores" / "sacar provecho de la gente común" |
| 政策/官方表述 | 弱化口号，强化影响与数据 |

**西语内部差异（M3 前默认锁定 es-MX）**：

| 维度 | 墨西哥（默认） | 阿根廷 | 西班牙 |
|------|----------------|--------|--------|
| 车辆 | carro | auto | coche |
| 电脑 | computadora | computadora | ordenador |
| 手机 | celular | celular | móvil |
| 你（普通） | tú | vos | tú |
| 您（正式） | usted | usted | usted |
| 数字千分位 | 1,000.50 | 1.000,50 | 1.000,50 |

- 每批西语文案需母语者或本地用户抽检 3 条以上。
- punchline 必须本地重写，禁止机器翻译直接发。

## 十一、M0 验收门禁

1. 同一 workflow 换 3 组西语脚本，连续产出 3 条 30 秒视频。
2. 分辨率/帧率：1080×1920 / 30fps。
3. LUFS：-14 ±1。
4. 西语字幕：≤ 2 行，≤ 6 词/行，关键词高亮 3-5 次，特殊字符显示正确。
5. 母语抽检：文案自然、无文化冒犯、无机器翻译感。
6. 人工抽检：音画同步、画面一致、无敏感内容。
7. **1 分钟内完成 3 条出片**。
