数字人短视频项目执行计划清单 v10

启动日：2026-07-20｜语言：中文基线 + EN/ES｜平台：国内为主 / YouTube 为辅｜ 当前策略：单 ComfyUI 工作流 + 多 TTS 候选

0. 一句话目标

用一套可复用的 ComfyUI 数字人工作流，在 12 个月内把中文、英文、西班牙文的短视频账号跑通； 若第 12 个月月收入未达预设阈值，立即砍掉外语线，退回中文-only 兼职模式。

M0 门禁 工作流成熟度：一个 ComfyUI 工作流可在 1 分钟内连续产出 3 条 30 秒成品视频。

1. 关键决策摘要

  • M0 不跑量、不变现，只验证 ComfyUI 工作流能否稳定、快速地端到端出片。
  • 数字人管线：ComfyUI 统一负责图片生成、视频生成、风格化、后期合成；不再以 MuseTalk / SadTalker / LivePortrait 作为默认主链。
  • TTS 方案：Fish Speech（中文主力）/ F5-TTS（轻量备选）/ ElevenLabs（英文/高质感备选）。
  • 平台优先级：头条 / 西瓜 / 视频号 / 小红书 / B站 / 抖音 为主战场；YouTube / YPP 作为长尾与素材复用池。
  • 多语言顺序：中文 → EN + ES 同步推进；AR 在 M3 复盘后、且工作流能自动切换语言前，不再启动。
  • 资金维度：删除所有启动资金、借款、成本上限内容；仅保留“月收入”作为 M12 硬截止指标。
  • 朋友/借款/豁免条款：全部从本清单中移除；相关文档不在 HTML 中引用。

2. 铁律

1. 工具即资产

每个可复用的 ComfyUI workflow、prompt 模板、TTS 音色包都要版本化，存到 Git。

2. 先跑通，再跑量

M0-M1 不追求爆款，追求稳定出片；跑量从 M2 开始。

3. 数据说话

所有分发决策必须依赖真实播放、完播、互动数据，不凭感觉。

4. 多语言≠多团队

EN/ES 内容必须能从中文 workflow 一键/半自动衍生，否则不做。

5. 硬截止不商量

M12 月收入未达标，立即砍掉外语线，仅保留中文账号并转为兼职节奏。

6. 平台合规优先

国内平台内容先审后发，严禁踩政治、医疗、金融红线；YouTube 遵守 YPP/社区准则。

3. 导演守则

  1. 每个账号必须有明确的人设、视觉风格、内容母题，禁止“搬运感”。
  2. ComfyUI workflow 输出前必须通过自动质量检查（分辨率、帧率、口型/画面一致性、水印）。
  3. 同一批素材优先出 9:16（短视频）与 1:1（图文/封面）两版，再考虑 16:9（YouTube）。
  4. 文案必须拆成“钩子 3 秒 + 信息主体 + 行动号召”三段式。
  5. 每条视频保留源文件、提示词、生成参数、发布链接，统一归档。
  6. TTS 音色必须与人设绑定，不要随意切换，避免品牌混乱。
  7. 多语言版本必须做母语者/本地用户可懂度抽检，禁止纯机器翻译直接发。
  8. 封面标题避免夸大、绝对化、诱导点击；国内平台尤其注意。
  9. 每周复盘一次数据，砍掉连续两周低于均线 50% 的内容线。
  10. 账号矩阵用不同手机号/邮箱/设备指纹隔离，避免被平台判定为营销号。
  11. 所有发布内容必须保留可追溯的生成记录，以备申诉。
  12. ComfyUI 节点升级、模型替换前先在副本 workflow 上验证，禁止直接动生产 workflow。

4. 八阶段路线图

M0 工作流验证

搭建 ComfyUI 端到端 workflow； Fish Speech / F5-TTS / ElevenLabs 接入；跑出 3 条 30 秒视频。

M1 账号矩阵

注册/养号 6 大国内平台 + YouTube；完成头像、简介、封面视觉统一。

M2 内容跑量

稳定日产 ≥3 条；建立选题库、文案模板、素材库。

M3 分发优化

分析各平台最佳发布时间、标签、标题结构；启动 EN/ES 内容线。

M4 变现实验

测试橱窗、带货、中视频、YPP、付费社群等模式，跑通最小变现闭环。

M5 数据驱动

建立看板；用数据反向指导选题、剪辑、发布策略。

M6 矩阵放大

复制已验证人设/内容线；引入半自动化发布与评论管理。

M7 复盘/退出

M12 硬截止评估；决定是否继续、收缩、或完全退出。

5. M0 工具链

图像 / 视频 / 后期

ComfyUI 为统一工作流底座。

负责：文生图、图生视频、风格迁移、抠像、合成、调色、导出。

要求：workflow 节点模块化、参数可调、输出规格固定（1080×1920/30fps）。

语音 / TTS

Fish Speech F5-TTS ElevenLabs

中文首选 Fish Speech 或 F5-TTS；英文/高质感场景用 ElevenLabs；所有音色入库存档。

文案 / 翻译

中文文案库 + 结构化模板；EN/ES 走 AI 翻译 + 母语抽检。

发布 / 数据

平台官方创作者后台为主；数据用表格/看板汇总，暂时不做复杂爬虫。

10. 首周行动

  1. 安装/更新 ComfyUI，整理必备节点包与模型清单。
  2. 部署 Fish Speech 与 F5-TTS，录制/收集 3 个候选音色。
  3. 设计第一条 workflow：文生图 → 图生视频 → 合成 → 导出 30 秒 9:16。
  4. 注册 6 个国内平台账号 + 1 个 YouTube 频道，统一视觉风格。
  5. 建立选题库（至少 30 个），按人设分类。
  6. 制定数据记录表格模板，包含日期、平台、标题、播放量、互动、变现。
  7. 第一次周会：检查 M0 门禁进度，调整工具链。
