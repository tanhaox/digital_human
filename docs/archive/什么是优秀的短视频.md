## 一、一句话结论

30 秒数字人短视频要"优秀"，必须同时满足：

1. **0-3 秒有强钩子**（字幕卡 + SFX + 视觉冲突）。
2. **3-8 秒给出价值承诺**（"看完你会知道 X"）。
3. **8-28 秒高密度交付**（每 2-3 秒一个视觉/信息事件）。
4. **28-30 秒有明确 CTA**（关注/评论/转发）。
5. **全程音画稳定、LUFS -14、字幕可读、人设一致、无敏感内容**。

技术底座必须是**可复用、可版本化、可一键/半自动批量执行的 ComfyUI workflow**；TTS 音色与人设绑定；多语言版本必须母语抽检。

## 二、节奏与留存（30 秒版本）

### 2.1 时长与节拍

| 指标 | 短视频标准 | 说明 |
|------|------------|------|
| 视频时长 | **30 秒 ±2 秒** | v10 执行计划目标时长 |
| 前 3 秒 | 决定 70% 去留 | 算法 + 用户双重判断窗口 |
| 完播率 | > 50% 才考虑放量 | 平台算法加权核心指标 |
| 视觉事件频率 | **每 2-3 秒 1 次** | 字幕弹出、关键词高亮、zoom、PIP、BGM 鼓点 |
| ASL（平均镜头长度） | **1-3 秒** | TikTok/抖音/Shorts 信息流节奏 |

### 2.2 30 秒三段式结构

```
[0-3s]   Hook      → 反常识 / 数字 / 悬念 / 冲突（大字幕 + 0.4s SFX）
[3-8s]   Promise   → "今天用 30 秒讲清楚 X"
[8-28s]  Body      → 2-3 个 story beat，每个 7-10 秒，配关键词高亮/PIP
[28-30s] CTA       → "点赞让更多人看到 / 关注我，明天讲 Y"
```

**数字人局限**：无法做拍肩膀、挥手等手势，必须用"台词 + 字幕 + 视觉特效"复合实现 Hook 与节奏。

## 三、镜头与构图硬指标

### 3.1 静态人像构图（9:16）

| 维度 | 数值/标准 |
|------|-----------|
| 画幅 | **9:16，1080×1920**；后期可衍生 1:1 封面、16:9 YouTube 版 |
| 帧率 | **30 fps**（最低 25 fps） |
| 头部位置 | 画面上 1/3 区，cx ≈ 0.5，cy ≈ 0.42 |
| 头顶留白 | 8-12% 画面高 |
| 视线方向留白 | 40-50% 画面宽 |
| 下巴下方留白 | 30-40% 画面高（给字幕安全区） |
| 人物占比 | 胸部以上特写为主，增强亲密感 |

### 3.2 视觉运动（Ken Burns / 伪多机位）

| 手法 | 参数 | 频率 |
|------|------|------|
| 微 zoom | 5-10% | 每 5-10 秒一次 |
| 平移/轻微推近 | ≤ 5% | 配合 beat |
| 字幕卡弹出 | 0.2-0.4s | 关键词出现时 |
| PIP 小图/数据卡 | 占画面 15-25% | 数据/对比出现时 |
| 背景微动效 | 粒子/光斑 | 慎用，避免"脸溢出" |

> 30 秒视频应有 **10-15 个视觉断点**，避免单镜头念稿感。

## 四、脚本与字幕硬指标

### 4.1 30 秒字数/词数

| 语种 | 类型 | 30 秒字数/词数 |
|------|------|----------------|
| 中文 | 知识/新闻 | 70-100 字 |
| 英文 | 标准旁白 | 60-80 词 |
| 西班牙文 | 标准旁白 | 60-80 词 |

### 4.2 字幕标准

- **必备**：短视频 80% 以上在静音环境被刷到，字幕不是可选项。
- **行数**：≤ 2 行。
- **行宽**：中文 ≤ 12 字/行；英文 ≤ 6 词/行；西语 ≤ 6 词/行。
- **字号**：1080 宽下 ≥ 48 pt，确保手机小屏可读。
- **安全区**：底部 15% 画面留给平台 UI（点赞/评论/标题）。
- **关键词高亮**：每 30 秒 3-5 次，颜色与人设品牌色一致。
- **双语字幕**：国内平台一般不需要；YouTube 长视频可考虑。

### 4.3 Hook / CTA 模板

```
[0-3s]  Hook        → "你以为 X，其实是 Y"
[3-8s]  Promise     → "今天 30 秒讲清楚"
[8-28s] Body        → beat 1 + beat 2 + beat 3
[28s]   软 CTA      → "如果对你有用，点个赞"
[30s]   主 CTA      → "关注我，下期讲 Z"
```

## 五、音频硬指标

### 5.1 LUFS 响度

| 平台 | Integrated LUFS | True Peak |
|------|-----------------|-----------|
| YouTube / TikTok / 抖音 | **-14 LUFS** | ≤ -1 dBTP |
| 通用短视频 | -14 LUFS | ≤ -1 dBTP |

### 5.2 人声 vs BGM

| 场景 | 人声 LUFS | BGM LUFS | 差值 |
|------|-----------|----------|------|
| 口播主体 | -18 | -30 至 -24 | **BGM 低于人声 12-18 dB** |
| Hook / CTA | -16 | -22 | 略增强 |
| punchline 前 0.5s | -18 | -∞ | 完全让出 |

### 5.3 BGM 与 SFX

- **BPM**: 80-120，短视频节奏偏快；知识类可 80-100，娱乐类可 110-130。
- **SFX**: 30 秒内 ≤ 3 次（whoosh/pop/boom），避免嘈杂。
- **Beat 停顿**: 30 秒短视频不需要长停顿，可在 beat 间留 0.3-0.5s 静音给人脑"标点"感。

### 5.4 TTS 音色

- 每个账号/人设绑定**固定音色**。
- 中文首选 **Fish Speech / F5-TTS**；英文/高质感用 **ElevenLabs**。
- 发布前必须听完整条，检查断句、语速、情绪是否匹配人设。

## 六、跨语种本地化

### 6.1 执行范围

v10 多语言策略：

| 语言 | 状态 | 备注 |
|------|------|------|
| 中文 | 主战场 | 原稿 + 本土语境 |
| 英文 | 同步推进 | 从中文 workflow 一键/半自动衍生 |
| 西班牙文 | 同步推进 | 从中文 workflow 一键/半自动衍生 |
| 阿拉伯文 | **冻结** | M3 复盘后且 workflow 能自动切换语言前不启动 |

### 6.2 翻译原则

- **Dynamic equivalence**: 优先"效果"对等，不直译。
- **Domestication**: 喜剧/口语化内容必须本地重写 punchline。
- **母语抽检**: EN/ES 版本必须经母语者或本地用户可懂度测试，禁止纯机器翻译直接发。
- **文化专有项**: 中文词如"内卷"、"996"、"躺平"需加脚注或换成功能对等表达。

### 6.3 数字人跨语种注意点

| 坑 | 严重度 | 处理 |
|----|--------|------|
| 中英文本密度差异 | 中 | 中文 2 字 ≈ 英文 3 词，字幕字号/时长需分别调 |
| 西语语速与断句 | 中 | 西语词较长，需控制每行词数 |
| 阿语 RTL | 高 | **冻结**，解冻后单独处理 RTL 字幕与排版 |
| emoji 跨文化 | 中 | 避免在中东市场用 👍 等手势 emoji |
| 形象服装 | 高 | 阿语女性需 hijab；EN/ES 形象需避免刻板印象 |

## 七、数字人质量评测

### 7.1 基础质量门

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 分辨率/帧率 | ffprobe | 1080×1920 / 30fps |
| LUFS | FFmpeg loudnorm | -14 ±1 LUFS |
| 音画同步 | 人工听看 | 无明显延迟 |
| 画面一致性 | 人工抽查 | 无闪烁/崩坏/换脸感 |
| 字幕可读性 | 手机预览 | 字号、行宽、安全区合规 |
| 敏感内容 | 预审清单 | 无政治/医疗/金融/擦边 |
| AI 标识 | 元数据/可见标注 | 符合平台 AIGC 合规要求 |

### 7.2 进阶指标（可选，M3 后逐步建立）

| 指标 | 说明 | 目标 |
|------|------|------|
| LSE-D / LSE-C | 唇同步误差/置信度 | LSE-D < 10，LSE-C > 3 |
| FID | 视觉真实度 | < 20（越低越好） |
| MOS | 用户主观评分 | 生产线目标 ≥ 4.0 |
| 眨眼/头部运动 | 微观真实度 | 自然、不机械 |

> 当前数字人 SOTA 仍未追平真人，项目竞争点是"内容强 + 稳定产出"，而非"绝对逼真"。

## 八、从标准反推 ComfyUI Workflow

### 8.1 推荐节点链路

```
文案 / 脚本（结构化模板）
    ↓
角色一致性控制（IPAdapter / InstantID / ControlNet）
    ↓
文生图 / 图生视频（SDXL / Flux / AnimateDiff / 视频节点）
    ↓
口型/动画（ComfyUI 内唇同步节点，按需）
    ↓
构图/合成（固定 9:16 画幅、头部位置、背景）
    ↓
字幕/关键词高亮（drawtext / 字幕节点 / 后期合成）
    ↓
音频：TTS → loudnorm → sidechain ducking BGM
    ↓
导出 1080×1920 / 30fps / H.264 / LUFS -14 / 硬字幕 + SRT
```

### 8.2 每个 workflow 必须参数化

| 参数 | 说明 |
|------|------|
| `character_prompt` | 角色形象 prompt，固定人设 |
| `scene_prompt` | 场景/背景 prompt |
| `script_text` | 文案 |
| `voice_id` | 音色 ID，与人设绑定 |
| `language` | zh / en / es（ar 冻结） |
| `subtitle_style` | 字体/颜色/高亮规则 |
| `bgm_mood` | BGM 情绪标签 |
| `output_format` | 9:16 / 1:1 / 16:9 |

### 8.3 质量门禁（M0 必须跑通）

1. 同一 workflow 换 3 组脚本，连续产出 3 条 30 秒视频。
2. 每条视频通过 ffprobe 分辨率/帧率检查。
3. 每条视频通过 loudnorm 检查，LUFS -14 ±1。
4. 人工抽检：音画同步、字幕可读、画面一致、无敏感内容。
5. 1 分钟内完成 3 条出片（M0 硬门禁）。
