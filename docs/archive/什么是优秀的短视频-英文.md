## 一、一句话结论

优秀的英文 30 秒数字人短视频 = **强钩子（0-3s）+ 价值承诺（3-8s）+ 高密度信息事件（8-28s）+ 明确 CTA（28-30s）**，全程音画稳定、字幕可读、人设一致、母语可懂、合规无敏感内容。

---

## 二、英文脚本节奏（30 秒）

### 2.1 词数与语速

| 指标 | 标准 |
|------|------|
| 总词数 | **60-80 词**（30 秒） |
| 语速 | 约 120-160 wpm |
| Hook 词数 | ≤ 10 词，0-3 秒 |
| 每 beat 时长 | 7-10 秒 |

### 2.2 三段式模板

```
[0-3s]   Hook    → "You think rent is the problem? It’s not."
[3-8s]   Promise → "In 30 seconds, the 3 signals that actually matter."
[8-28s]  Body    → Signal 1 (7s) + Signal 2 (7s) + Signal 3 (6s)
[28-30s] CTA     → "Like and follow if this helped."
```

**英文 Hook 高打开句式**：
- Counter-intuitive: "You think X, but it's actually Y"
- Number shock: "90% of people miss #3"
- Curiosity gap: "The real reason why X happens"
- Conflict: "This new data will surprise you"

## 三、字幕与文案硬指标

### 3.1 字幕排版

| 维度 | 标准 |
|------|------|
| 行数 | ≤ 2 行 |
| 行宽 | **≤ 6 词/行** |
| 字号 | 1080 宽下 ≥ 48 pt |
| 安全区 | 底部 15% 留给平台 UI |
| 关键词高亮 | 每 30 秒 3-5 次，颜色与品牌色一致 |
| 字体 | Inter / Roboto / Montserrat / Helvetica Neue，移动端可读 |
| 描边 | 白字 + 黑描边，确保任何背景可读 |

### 3.2 英文文案禁忌

- 避免医疗/金融/法律投资建议（"not financial/medical advice" 免责声明优先加）。
- 避免绝对化表述："always", "never", "guaranteed", "100%"（平台+合规风险）。
- 避免文化刻板印象与冒犯性隐喻。
- 英式/美式拼写和用词需单条统一，不可混用。

## 四、音频硬指标

### 4.1 TTS 选型

| 语言 | 首选 | 备选 | 备注 |
|------|------|------|------|
| 英文 | **ElevenLabs** | **Fish Speech / F5-TTS** | ElevenLabs 音色库最丰富，高质感首选 |

### 4.2 响度与混音

| 指标 | 标准 |
|------|------|
| 成品 Integrated LUFS | **-14 LUFS** |
| True Peak | ≤ -1 dBTP |
| 人声 vs BGM | BGM 低于人声 12-18 dB |
| Hook/CTA BGM | 可略增强，但不超过 -22 LUFS |

### 4.3 英文音色与人设

- 每个账号绑定 1 个固定音色。
- News / Finance：沉稳、清晰、略带权威感。
- Tech / Vlog：亲和、自然、节奏明快。
- Story / Lifestyle：温暖、情感、语速偏慢。
- 发布前必须听完整条，检查吞音、连读、重音是否自然。

## 五、镜头与构图（9:16）

| 维度 | 标准 |
|------|------|
| 画幅 | **1080×1920 / 30fps** |
| 头部位置 | 画面上 1/3，cx ≈ 0.5，cy ≈ 0.42 |
| 头顶留白 | 8-12% |
| 视线方向留白 | 40-50% |
| 下巴下方留白 | 30-40%（字幕安全区） |
| 人物占比 | 胸部以上特写为主 |

**英文平台视觉偏好**：
- YouTube Shorts：强字幕、快切、可接受略高信息密度。
- TikTok/Reels：高节奏、强情绪、字幕卡大字。
- 国内平台：英文版多为"外语学习/国际视角"人设，封面需体现差异化。

## 六、节奏与视觉事件

30 秒内建议 **10-15 个视觉断点**：

| 事件 | 时机 | 形式 |
|------|------|------|
| 字幕卡弹出 | 关键词出现 | 0.2-0.4s 缩放进入 |
| 关键词高亮 | 每 7-10s | 变色/放大/描边 |
| 微 zoom | 每 5-10s | 5-10% 推近 |
| PIP 数据卡 | 数据/对比出现时 | 占画面 15-25% |
| BGM beat | 每 2-3s | 配合画面切换 |

## 七、ComfyUI Workflow 反推

英文 30 秒短视频的推荐节点链路：

```
英文文案 / 脚本模板
    ↓
角色一致性控制（IPAdapter / InstantID / ControlNet）
    ↓
文生图 / 图生视频（SDXL / Flux / AnimateDiff / 视频节点）
    ↓
口型/动画（ComfyUI 内唇同步节点，按需）
    ↓
9:16 构图/合成（固定头部位置、背景、安全区）
    ↓
英文字幕/关键词高亮（字幕节点 / drawtext）
    ↓
TTS（ElevenLabs / Fish Speech / F5-TTS）→ loudnorm → sidechain ducking BGM
    ↓
导出 1080×1920 / 30fps / H.264 / LUFS -14 / 硬字幕 + SRT
```

**必须参数化**：

| 参数 | 说明 |
|------|------|
| `character_prompt` | 英文人设 prompt（形象、服装、气质） |
| `scene_prompt` | 场景/背景 prompt |
| `script_text` | 英文文案 |
| `voice_id` | 英文音色 ID |
| `subtitle_style` | 英文字体/颜色/高亮规则 |
| `bgm_mood` | BGM 情绪标签 |
| `output_format` | 9:16 / 1:1 / 16:9 |

## 九、英文内容合规

1. **AIGC 标识**：视频或简介显著标注"AI-generated" / "digital host"；YouTube 上传时勾选 "Altered or synthetic content"。
2. **禁区**：政治煽动、金融投资建议、医疗效果、擦边、性暗示、冒充真人、DMCA 高风险素材。
3. **免责声明**：涉及财经/健康/法律时加 "Not financial/medical/legal advice"。
4. **版权**：背景音乐必须使用授权曲库（Epidemic Sound / Artlist / Musicbed）；新闻素材改写 ≥ 30% 或购买授权。
5. **可溯源**：保留文案、提示词、生成参数、发布链接。

## 十、跨语种本地化要点

英文版必须从中文稿 **dynamic equivalence** 重写，而非直译：

| 中文表达 | 英文处理 |
|----------|----------|
| "内卷" | involution / rat race / "everyone is overworking" |
| "躺平" | lying flat / opting out / "quiet quitting" |
| "996" | "the 9-9-6 grind" + 脚注 |
| "割韭菜" | "rip off retail investors" / "exploit the masses" |
| 政策/官方表述 | 弱化口号，强化影响与数据 |

- 每批英文文案需母语者或本地用户抽检 3 条以上。
- punchline 必须本地重写，禁止机器翻译直接发。

## 十一、M0 验收门禁

1. 同一 workflow 换 3 组英文脚本，连续产出 3 条 30 秒视频。
2. 分辨率/帧率：1080×1920 / 30fps。
3. LUFS：-14 ±1。
4. 英文字幕：≤ 2 行，≤ 6 词/行，关键词高亮 3-5 次。
5. 母语抽检：文案自然、无文化冒犯、无机器翻译感。
6. 人工抽检：音画同步、画面一致、无敏感内容。
7. **1 分钟内完成 3 条出片**。
