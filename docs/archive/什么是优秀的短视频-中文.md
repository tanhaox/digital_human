## 一、一句话结论

优秀的中文 30 秒数字人短视频 = **强钩子（0-3s）+ 价值承诺（3-8s）+ 高密度信息事件（8-28s）+ 明确 CTA（28-30s）**，全程音画稳定、字幕可读、人设一致、合规无敏感内容。

---

## 二、中文脚本节奏（30 秒）

### 2.1 字数与语速

| 指标 | 标准 |
|------|------|
| 总字数 | **70-100 字**（30 秒） |
| 语速 | 约 140-180 字/分钟 |
| Hook 字数 | ≤ 12 字，0-3 秒 |
| 每 beat 时长 | 7-10 秒 |

### 2.2 三段式模板

```
[0-3s]   Hook    → "你以为买房最难的是首付？错。"
[3-8s]   Promise → "今天 30 秒讲清楚真正卡人的 3 个信号。"
[8-28s]  Body    → 信号 1（7s）+ 信号 2（7s）+ 信号 3（6s）
[28-30s] CTA     → "点赞收藏，下次讲怎么破。"
```

**中文 Hook 高打开句式**：
- 反常识："你以为 X，其实是 Y"
- 数字冲击："90% 的人不知道第 3 点"
- 悬念："为什么聪明人都在 X？"
- 冲突："刚出炉的数据，可能会打你脸"

## 三、字幕与文案硬指标

### 3.1 字幕排版

| 维度 | 标准 |
|------|------|
| 行数 | ≤ 2 行 |
| 行宽 | **≤ 12 字/行** |
| 字号 | 1080 宽下 ≥ 48 pt |
| 安全区 | 底部 15% 留给平台 UI |
| 关键词高亮 | 每 30 秒 3-5 次，颜色与品牌色一致 |
| 字体 | 思源黑体 / 阿里巴巴普惠体 / 站酷系列，手机端可读 |

### 3.2 中文文案禁忌

- 避免政治、金融投资建议、医疗效果承诺。
- 避免"最"、"第一"、"绝对"等绝对化用语（广告法风险）。
- 避免谐音敏感词和谐音梗绕过审核。
- 数字表达：优先阿拉伯数字（"3 个信号"比"三个信号"更有冲击力）。

## 四、音频硬指标

### 4.1 TTS 选型

| 语言 | 首选 | 备选 | 备注 |
|------|------|------|------|
| 中文 | **Fish Speech** | **F5-TTS** | 本地部署，音色自然 |

### 4.2 响度与混音

| 指标 | 标准 |
|------|------|
| 成品 Integrated LUFS | **-14 LUFS** |
| True Peak | ≤ -1 dBTP |
| 人声 vs BGM | BGM 低于人声 12-18 dB |
| Hook/CTA BGM | 可略增强，但不超过 -22 LUFS |

### 4.3 中文音色与人设

- 每个账号绑定 1 个固定音色。
- 知识/财经类：沉稳、低音、语速偏慢。
- 娱乐/生活类：轻快、亲和、语速偏快。
- 发布前必须听完整条，检查儿化音、多音字、断句错误。

## 五、镜头与构图（9:16）

| 维度 | 标准 |
|------|------|
| 画幅 | **1080×1920 / 30fps** |
| 头部位置 | 画面上 1/3，cx ≈ 0.5，cy ≈ 0.42 |
| 头顶留白 | 8-12% |
| 视线方向留白 | 40-50% |
| 下巴下方留白 | 30-40%（字幕安全区） |
| 人物占比 | 胸部以上特写为主 |

**中文平台视觉偏好**：
- 抖音：高饱和、强字幕、快节奏剪辑。
- 视频号：色调可更温和，适合私域人设。
- 小红书：封面要求极高，需 1:1 封面图。
- B站/头条/西瓜：可接受信息密度更高的中视频，但短视频仍按 30 秒标准。

## 六、节奏与视觉事件

30 秒内建议 **10-15 个视觉断点**：

| 事件 | 时机 | 形式 |
|------|------|------|
| 字幕卡弹出 | 关键词出现 | 0.2-0.4s 缩放进入 |
| 关键词高亮 | 每 7-10s | 变色/放大/描边 |
| 微 zoom | 每 5-10s | 5-10% 推近 |
| PIP 数据卡 | 数据/对比出现时 | 占画面 15-25% |
| BGM beat | 每 2-3s | 配合画面切换 |

## 七、ComfyUI Workflow 反推

中文 30 秒短视频的推荐节点链路：

```
中文文案 / 脚本模板
    ↓
角色一致性控制（IPAdapter / InstantID / ControlNet）
    ↓
文生图 / 图生视频（SDXL / Flux / AnimateDiff / 视频节点）
    ↓
口型/动画（ComfyUI 内唇同步节点，按需）
    ↓
9:16 构图/合成（固定头部位置、背景、安全区）
    ↓
中文字幕/关键词高亮（字幕节点 / drawtext）
    ↓
TTS（Fish Speech / F5-TTS）→ loudnorm → sidechain ducking BGM
    ↓
导出 1080×1920 / 30fps / H.264 / LUFS -14 / 硬字幕 + SRT
```

**必须参数化**：

| 参数 | 说明 |
|------|------|
| `character_prompt` | 中文人设 prompt（形象、服装、气质） |
| `scene_prompt` | 场景/背景 prompt |
| `script_text` | 中文文案 |
| `voice_id` | 中文音色 ID |
| `subtitle_style` | 中文字体/颜色/高亮规则 |
| `bgm_mood` | BGM 情绪标签 |
| `output_format` | 9:16 / 1:1 / 16:9 |

## 九、中文内容合规

1. **AIGC 标识**：视频或简介显著标注"AI 生成" / "数字人"。
2. **禁区**：政治、金融投资建议、医疗效果、擦边、性暗示、冒充真人。
3. **广告法**：避免"最"、"第一"、"国家级"、"100%"等绝对化用语。
4. **先审后发**：国内平台审核严格，标题/封面避免夸大诱导。
5. **可溯源**：保留文案、提示词、生成参数、发布链接。

---

## 十、M0 验收门禁

1. 同一 workflow 换 3 组中文脚本，连续产出 3 条 30 秒视频。
2. 分辨率/帧率：1080×1920 / 30fps。
3. LUFS：-14 ±1。
4. 中文字幕：≤ 2 行，≤ 12 字/行，关键词高亮 3-5 次。
5. 人工抽检：音画同步、画面一致、无敏感内容。
6. **1 分钟内完成 3 条出片**。
