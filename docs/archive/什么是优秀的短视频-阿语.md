## 一、阿语内容标准速查

### 1.1 目标市场

| 优先市场 | 备份市场 |
|----------|----------|
| 沙特 (SAU)、埃及 (EGY)、阿联酋 (UAE) | 摩洛哥 (MAR)、海湾六国 (GCC)、卡塔尔 |

### 1.2 形象气质

| 维度 | 标准 |
|------|------|
| 种族 | 阿拉伯人 / 波斯人 / 库尔德人（70% 阿拉伯 + 30% 多元） |
| 性别策略 | 男主播为主（沙特/阿联酋/埃及通用）；女主播需戴 hijab |
| 年龄 | 30-50 岁（阿语观众偏好成熟稳重） |
| 表情基线 | 严肃中性，避免露齿大笑 |
| 手势 | 避免夸张西式手势 |
| 观众期待 | 庄重可信、主动解读、不纯念稿 |

### 1.3 穿着与文化合规

| 子维度 | 推荐 | 禁忌 |
|--------|------|------|
| 女主播头巾 | hijab 必须（罩发 + 颈，不遮脸） | 露发、只围颈巾、印花鲜艳 |
| 女主播服装 | 长袖 + 长裙（到脚踝）+ 黑色/深色 | 短袖、鲜艳、紧身 |
| 女主播颜色 | 黑色 / 深蓝 / 米色 / 棕色 | 黄色（部分地区视为订婚标志）、白色（殡葬色） |
| 男主装 | 简朴西装 + 白衬衫 | 短袖、太花哨 |
| 男头巾 | 海湾六国可戴，埃及一般不戴 | 在埃及频道戴 topi 可能被视为政治表态 |
| 女化妆 | 中性淡妆 | 浓妆、红唇 |

### 1.4 语速与配音

| 方言 | 推荐 wpm | 说明 |
|------|----------|------|
| MSA 标准阿语 | 140-155 | 朗读腔 + 慢速 = 权威感 |
| 埃及方言 | 160-175 | 埃及人说话快 + 娱乐风 |
| 沙特方言 | 140-155 | 规范 + 慢速 |

**TTS 选型（v10 工具链）**:

- 中文/多语言测试期：Fish Speech / F5-TTS / ElevenLabs。
- 阿语解冻后：优先评估 ElevenLabs 阿语音色或其他支持阿语的高质量 TTS；不再以 Edge-TTS 为默认。

### 1.5 新闻出处

| 新闻类型 | 必标源 |
|----------|--------|
| 海湾/中东政治 | Al Jazeera / Al Arabiya |
| 埃及本地 | Al-Ahram / Al-Masry Al-Youm |
| 国际 | AP Arabic / Reuters Arabic / BBC Arabic |
| 中国相关 | 中国国际广播电台 (CRI) 阿语部 / CGTN 阿语 / 新华社阿语 |
| 宗教新闻 | 沙特 SPA / 埃及 Dar al-Ifta |
| 财经 | Bloomberg Arabia / Al Eqtisadiah |

### 1.6 阿语独有技术注意点

| 注意点 | 说明 |
|--------|------|
| RTL 书写方向 | 从右到左；字幕、标题、缩略图均需 RTL 排版 |
| Tashkeel（变音符号） | 稿件带变音符号，TTS 读得更准 |
| 两套数字 | Arabic-Indic 数字（٠-٩）与西方数字；需统一 |
| 希贾里历 | 沙特官方使用；中国相关新闻以公历为主，可选备注 |
| 专有名词音译 | 中国领导人/地名需建立标准音译表 |

### 1.7 合规红线

| 红线 | 说明 |
|------|------|
| 沙特王室 | 不议国王/王储/王室成员 |
| 宗教 | 真主/安拉名字需带尊大词；先知需带祝福词；禁止讽刺伊斯兰教 |
| 政治 | ISIS / 穆兄会 / 以色列-巴勒斯坦 等敏感话题慎议或避开 |
| LGBT | 完全禁议 |
| AI 标识 | 视频需标注 AI 生成内容 |
| 斋月 | 白天不出现进食画面（沙特/阿联酋传统） |

## 二、技术栈冻结说明

### 2.1 旧 v1.0 技术栈已废弃

旧 ar-v1.0 中使用的以下工具栈已不再作为本项目默认方案：

- SadTalker（数字人驱动）
- Edge-TTS（阿语默认 TTS）
- GFPGAN（增强）
- 详细 FFmpeg 命令模板

### 2.2 v10 统一技术栈

| 模块 | 方案 |
|------|------|
| 图像/视频/后期 | ComfyUI |
| TTS | Fish Speech / F5-TTS / ElevenLabs（阿语解冻后评估） |
| 工作流 | 必须能从中/EN/ES workflow 一键/半自动衍生 |

### 2.3 解冻前不做

- 不制作阿语 demo。
- 不注册阿语 YouTube 频道。
- 不采购阿语 SIM 卡/电话卡。
- 不签约阿语翻译者。
- 不为阿语单独搭建 workflow。

## 三、与 v10 对齐的启动条件

阿语频道解冻必须同时满足：

1. M3 复盘通过，中文 + EN/ES 已稳定日产 ≥3 条。
2. ComfyUI workflow 已支持一键/半自动切换语言（文案、TTS、字幕字体、RTL 排版）。
3. 已确认阿语母语校对资源（翻译 + 文化合规）。
4. 已重新评估 2026-07 后 YouTube 政策对阿语 AI 内容的影响。
5. 已确认阿语内容 ROI 高于新增中文/EN/ES 账号。

**任一不满足 = 继续冻结。**
