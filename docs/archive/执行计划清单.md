# 数字人短视频项目执行计划清单（v10）

**版本**: v10 · 2026-07-20  
**核心原则**: 先验证后投入 · 工作流即资产 · 数据说话 · 硬截止不商量  
**渲染配套**: [执行计划清单.html](执行计划清单.html)（高保真甘特图）  

---

## 〇 一句话目标

用**一套可复用的 ComfyUI 数字人工作流**，在 12 个月内把中文、英文、西班牙文的短视频账号跑通；
若第 12 个月月收入未达预设阈值，立即砍掉外语线，退回中文-only 兼职模式。

**M0 门禁**: 工作流成熟度——一个 ComfyUI 工作流可在 **1 分钟内连续产出 3 条 30 秒成品视频**。

---

## 0.1 关键决策摘要

- **M0 不跑量、不变现**，只验证 ComfyUI 工作流能否稳定、快速地端到端出片。
- **数字人管线**: ComfyUI 统一负责图片生成、视频生成、风格化、后期合成；不再以 MuseTalk / SadTalker / LivePortrait 作为默认主链。
- **TTS 方案**: Fish Speech（中文主力）/ F5-TTS（轻量备选）/ ElevenLabs（英文/高质感备选）。
- **平台优先级**: 抖音 / 视频号 / 小红书 / B站 / 头条 / 西瓜 为主战场；YouTube / YPP 作为长尾与素材复用池。
- **多语言顺序**: 中文 → EN + ES 同步推进；AR 在 M3 复盘后、且工作流能自动切换语言前，不再启动。
- **资金维度**: 删除所有启动资金、借款、成本上限内容；**仅保留“月收入”作为 M12 硬截止指标**。
- **朋友/借款/豁免条款**: 全部从本清单中移除；相关文档不在本清单中引用。

## 0.3 导演守则

1. 每个账号必须有明确的人设、视觉风格、内容母题，禁止“搬运感”。
2. ComfyUI workflow 输出前必须通过自动质量检查（分辨率、帧率、口型/画面一致性、水印）。
3. 同一批素材优先出 9:16（短视频）与 1:1（图文/封面）两版，再考虑 16:9（YouTube）。
4. 文案必须拆成“钩子 3 秒 + 信息主体 + 行动号召”三段式。
5. 每条视频保留源文件、提示词、生成参数、发布链接，统一归档。
6. TTS 音色必须与人设绑定，不要随意切换，避免品牌混乱。
7. 多语言版本必须做母语者/本地用户可懂度抽检，禁止纯机器翻译直接发。
8. 封面标题避免夸大、绝对化、诱导点击；国内平台尤其注意。
9. 每周复盘一次数据，砍掉连续两周低于均线 50% 的内容线。
10. 账号矩阵用不同手机号/邮箱/设备指纹隔离，避免被平台判定为营销号。
11. 所有发布内容必须保留可追溯的生成记录，以备申诉。
12. ComfyUI 节点升级、模型替换前先在副本 workflow 上验证，禁止直接动生产 workflow。
13. **严禁数字人讨论金融、法律、医疗健康等敏感专业话题；严禁擦边、性暗示、情绪操纵类内容。**
    - **执行口径（2026-07-25）**：财经新闻"解读 + 评论"（带明确新闻源、不推荐具体金融产品 / 个股 / 投资建议、不构成投资引导）视为合规；GitHub 开源项目介绍天然合规（属科技评论 / 信息传播）。任何"我建议你买/卖 X"的语句零容忍。
14. YouTube 内容必须具有明显的原创剪辑、真人解说或观点增量，避免被判定为“AI 垃圾”。

| **M7 复盘/退出** | 第 12 月 | M12 硬截止评估；决定是否继续、收缩、或完全退出。 | 月收入未达预设阈值 → 砍掉 EN/ES，退回中文-only 兼职模式。 |

## 三、平台矩阵

### 3.1 国内平台（主战场）

| 平台 | 优先级 | 内容形态 | 备注 |
|------|--------|----------|------|
| 抖音 | P0 | 9:16 短视频 | 流量大、算法强，人设/完播是关键 |
| 视频号 | P0 | 9:16 短视频 | 私域联动强，适合人设沉淀 |
| 小红书 | P1 | 9:16 视频 + 1:1 图文 | 女性/生活方式用户集中，封面重要 |
| B站 | P1 | 9:16 / 16:9 中视频 | 长尾流量，适合系列化、深度内容 |
| 头条 / 西瓜 | P1 | 9:16 / 16:9 | 中视频计划、搜索流量、男性用户多 |

### 3.2 YouTube（长尾与素材复用池）

**定位**: YouTube 不作为主变现渠道，而是国内素材的复用池与品牌长尾。

| 维度 | 策略 |
|------|------|
| **Shorts** | RPM 极低（约 $0.01–$0.07/千次，100 万播放约 $10–$70），且 2026-07-16 起平台严打模板化、低质、AI 垃圾内容。**不指望 Shorts 广告分成养活自己。** |
| **长视频** | 真正贡献 RPM 的格式，广告位多、CPM 高。计划把国内 9:16 素材重剪/扩写为 16:9 长视频，主攻中长尾部。 |
| **YPP 门槛** | 高级 YPP: 1000 订阅 + 过去 365 天长视频 4000 小时公开观看时长；或 1000 订阅 + 过去 90 天 Shorts 1000 万次播放。两条赛道**独立统计、互不通算**。 |
| **数字人合规** | 2026-07 YouTube 更新政策：通用重复的模板化 AI 内容、令人反感/痛苦的内容、AI 虚拟人物讨论金融/法律/医疗等敏感话题，均会被**排除在 YPP 变现之外**。严禁数字人碰擦边、性暗示、敏感专业话题。 |
| **变现预期** | YouTube 收入列为“长尾/意外之财”，M4 变现实验阶段只做“跑通第一笔”验证；不纳入 M12 硬截止的主要收入来源。 |

## 七、首周行动

1. 安装/更新 ComfyUI，整理必备节点包与模型清单。
2. 部署 Fish Speech 与 F5-TTS，录制/收集 3 个候选音色。
3. 设计第一条 workflow：文生图 → 图生视频 → 合成 → 导出 30 秒 9:16。
4. 注册 6 个国内平台账号 + 1 个 YouTube 频道，统一视觉风格。
5. 建立选题库（至少 30 个），按人设分类。
6. 制定数据记录表格模板，包含日期、平台、标题、播放量、互动、变现。
7. 第一次周会：检查 M0 门禁进度，调整工具链。

## 八、风险与应对

| 风险 | 应对 |
|------|------|
| ComfyUI 工作流不稳定 | 节点版本锁定；生产/测试 workflow 分离；关键节点做 fallback |
| 平台审核/限流 | 内容预审清单；一账号一设备一网络；避免敏感词与夸大标题 |
| TTS 音色与人设不符 | 固定音色库；发布前必须听完整条 |
| 多语言内容质量差 | EN/ES 必须母语抽检；M3 前不做 AR |
| 月收入长期不达标 | M12 硬截止：砍掉外语线，中文转兼职 |
| YouTube 数字人被判定为低质/非真实内容 | 每段视频加入原创剪辑、真人配音/解说、观点增量；避免模板化与敏感话题 |
| YouTube Shorts RPM 过低 | 不把 Shorts 分成作为主要收入；重点做 16:9 长视频复用 |
| 触碰 YouTube 擦边/敏感红线 | 内容预审加“广告友好”与“社区准则”双清单；一经黄标立即下架重剪 |
