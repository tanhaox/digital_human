## 二A、动画线动线 (与 📐页单工坊 二选一)

> 演化脉络: 页单工坊替代 PPT 上传模式 (文字→工坊制作); 动画线是新动线
> (文字→**音频**→分镜→动画), 音频是动画线的硬前置 — 同一集二选一。
> **0914 晚导演引擎 v2 正身接入** (scripts/anim_director.py → director2.py):
> 叙事弧结构 + 一组一段长镜 + 美术圣经书级锁定 + 开场 5.5s 剪辑层预留。

```
讲书页 第N集行 →「🔊 TTS音频」生成 + 人耳验收  ←—— 硬前置 (无音频 = 规划禁用)
            ↓
       「🎬 动画 ↗」→ 工坊页 anim.html:
  🧭 规划 (v2 导演引擎: 时间轴直出 manifest, 叙事弧+运动线+圣经, 零事后归真)
  → 🎨 K2 批生图 (圣经风格前缀+定格画面) → 组卡片 ✅过审/🔁打回(可定向改画面)
  → 🎬 H3 批生视频 (motion_en 单拍壳; >10s 组 overrun 定格吸收)
  → 🎞 装配剪映草稿 (开场 5.5s: 打字卡+书封墙/主书封 epub 备料 → 组时间轴
     → 品牌卡自动插 → text_layer 暖金字幕 → 整集口播; 翻书/扫描特效=剪映位)
```
- 工坊页呈现: 弧头(叙事任务+运动线🏃) + 可折叠美术圣经 + 运镜标签[缓推/移/跟/固定]

- API: `/api/anim/ep/{book}/{ep}/status|plan|k2|approve|h3|align|draft|file/...` (app/routers/anim.py)
- 对齐归真仅 v1 旧数据需要; v2 原生对齐 (音频重渲染后也只需重规划该部分)

## 三、已定稿的技术配置 (不要改)

### K2 生图 (赛璐璐)
- 模型: krea2_turbo_fp8_scaled
- LoRA: Krea2-漫画白鲸记风格_NSW @0.8
- VAE: 000_qwen_image_vae.safetensors (必须有 000_ 前缀)
- 分辨率: 1920×1080
- 耗时: ~16s/张

### H3 生视频
- 模型: MiniMaxH3 (本地 ComfyUI)
- Sampler: MiniMaxH3TurboSampler, 6步 sigma: 1.0,0.95,0.88,0.75,0.55,0.3,0.0
- 耗时: ~100s/5s视频
- 文字渲染: 单一文字+一次淡入+楷体/衬线体+暖色系 ✓
- 首尾帧: MiniMaxH3ImageToVideo 支持 first_frame+last_frame (需同场景编辑)

### 风格 (随书变, 同受众地图)
- HBO 书: 1988 赛璐璐手绘动画 (线条干净/色彩鲜艳/明暗分明)
- 品牌卡: 登山客(烧橙冲锋衣+橄榄绿背包) 坐山脊读书→起身→走向群山+"拆一本书翻一座山"书法

## 五、禁忌清单 (违反=废片)

| 禁忌 | 原因 | 替代 |
|---|---|---|
| K2 画文字/数字 | 模型不渲染文字 | text_layer / H3 渲染 |
| H3 自由运镜 | 全屏抖动 | 定焦+内容动画 / 首尾帧 |
| H3 ambient life 指令 | 水彩纹理游泳 | 只写光影渐变 |
| H3 4步 sigma | 不稳定 | 6步 |
| 快推快拉 | 糊帧 | 缓推/缓拉, 快变靠切镜 |
| 突然变白/白闪转场 | 观感差(用户令禁) | warm glow 定格 |
| 连续镜重复同一文字 | s09+s10 实锤 | 每个文字只出一次 |
| 文字变形/morph | H3 画不了 | 单一文字+淡入 |
| VAE 名无 000_ 前缀 | 400 报错 | 000_qwen_image_vae.safetensors |
| 灰冷色文字 | 丑 | 楷体/衬线体+暖金色 |
