## 判定卡 (活冲突的验证机制 — 预注册, 判读日数据说话)

### 卡A · 两秒卡 vs 三秒卡
- 冲突: 撤卡定谳"须单集A/B" vs 两秒令"整线压缩"
- 设计: 顾问或高效能相邻两集交替 2s/3s 卡 (其余变量冻结: 同档位选题/同时长带)
- 判读线: 播放差>30% 或 吸粉率崩<0.4% → 回 3s; 播放持平且 5s率降幅≤5pp → 2s 定型
- 到期: 高效能 ep2+48h (~11-21)

### 卡B · 六拍 × 3-5min 瘦身
- 冲突: 六拍结构按 5min 设计 vs 900-1100 字精简令
- 设计: 高效能 ep1-3 用瘦身版(钩子/回顾一句式/拆解三/预告紧凑型), 与卓档基线比
- 判读线: 均看≥9.5s 且 5s率≥卓3s卡基线(21%) → 定型; 任一跌破 → 结构回调(回顾段整段让位)
- 到期: 高效能 ep3+48h (~11-23)

### 卡C · 挂车时点
- 冲突: 框架"千粉前不动账号" vs 指南+复盘"500有效粉挂车A/B"
- 前置: 后台确认有效粉真值 (顺带校准 8 折律)
- 判读线: 挂车集 vs 不挂车集 — 掉粉率无异常抬升 且 播放不降 → 常开; 异常 → 回撤等千粉
- 到期: 真值确认后 7 天

### 卡D · 视觉一致性 (观察位, 非实验)
- 张力: 一书一赛道(视觉每书换脸) vs 账号 IP 识别度
- 机制: 高效能视觉选型时登记风格族谱; 累积 3 书后回看回访率/主页转化趋势
- 到期: ~12 月中 (3 书后)
