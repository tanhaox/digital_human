## 二、指标口径

- 单集: 播放/赞/评/藏/享/吸粉/深度 (后台「平均播放占比」列, 完播口径待官方确认) — 48h 值与定型值分开记。
- **指标权威按 §〇 阶段门禁分层**: 泛流期只有涨粉系数据可出结论, 其余只记不裁。
- **每日账** (创作者中心每日数据, 10-05 起纳入): 投稿/日播放/5s完播/2s跳出/平均播放时长 — **前段漏斗真值**; 非发布日播放=账号底流读数; 泛流期只记不裁, P1 首分钟杠杆的实弹靶位。
- **2s跳出是特性 (10-05 用户定谳)**: 前 5.5s 开场 (打字卡+品牌卡) = **泛流过滤器** — 主动弃泛流换精准打标; 2s跳出 43-49% 是设计内行为, 不是缺陷; 500 粉后评估拆否 (ID-076)。
- **每日两表导出规约 (10-05 用户实录)**: 两表 (每日流量账/每日粉丝账) 由抖音后台导出, **仅保留 30 天, 超期断档** → 每次节点 (Te/Tx/Tm/里程碑, 间隔 ≤8 天) 必导两表, 断档风险归零; 数据**次日 12 点更新昨日** → 节点快照统一在正午后拿。**作品列表亦支持 xlsx 导出直读** (免截图抠图; openpyxl 已入 venv), 16 列含官方完播率/主页访问量 — 节点首选数据源。
- **官方指标定义 (抖音后台说明, 10-05 录)**: 同类创作者=相似创作领域或粉丝量级的创作者 (**基准对比能力, 列入节点采集**); 互动指数=观看/赞/评/转发综合分; 完播率=完整播放次数占比 (每日口径=当日完播浏览/总浏览, 十分钟级=累计/累计); 粉丝净增=涨粉-掉粉; 抖音精选=精选APP+PC端+精选Tab。列表"平均播放占比"列官方未定义 — 后续导出直接取官方完播率字段。
- 系列: 吸粉总数+吸粉率(粉/总播放)/均互动率/藏赞比/深度均值/最佳最差集归因。
- 账号: 三数; **1000 粉解锁项** (热词/画像聚集) 到点必回看。
- 假象清洗沿用 0906 框架: 置顶/热点/小样本封面率(弃用)/评论污染。

### 4.4 有效粉口径 (内功课; 2026-09-30 考据)

**官方定义 (2024-04-16 新规)**: 通过持续发优质内容、经**自然推荐渠道**吸引的真实关注 — 排除互关互粉/第三方渠道/低频活跃/机器粉。**全部经营权限门槛 (带货/橱窗/伙伴计划) 均按有效粉判定**, 主页总粉只是展示数。

| 维度 | 总粉丝 (主页三数) | 有效粉丝 |
|---|---|---|
| 统计 | 所有关注者 | 仅自然渠道真实活跃粉 |
| 用途 | 展示 | **权限判定** (橱窗=1000有效粉, 2024-08-20 起从500提至1000; 伙伴计划=5000互动粉) |
| 健康 | — | 静默粉占比高 → 降权限流; 官方有自助清粉/清赞 |

- **查看路径**: 创作者中心 → 设置 → 「经营类使用组件要求」(官方口径入口; **用户 0930 实测当前账号无处显示有效粉数** → 真值不可见期一律用折算)。
- **🎯 8折折算律 (2026-09-30 用户裁定, 有待观察)**: 有效粉 ≈ 总粉 × **0.8** (依据: ep6 粉丝重度 88%, 取 8 折留余量) — **一切粉丝目标按 8 折折算成总粉口径执行**; 系数为暂定值, 任何渠道见真值即回填校准。
- **折算表**: 200 有效 ≈ **250 总粉** · 500 有效 ≈ **625 总粉** · 1000 有效 ≈ **1250 总粉** · 5000 互动 ≈ **6250 总粉**。
- **有效粉率**: 真值不可见期以重度占比代理 (画像快照的活跃分布), 每次快照记录 — 重度占比持续 >85% 则 8 折系数成立; 跌破 80% 则系数下调并查原因 (静默粉堆积/互关污染)。
- **产线内功三条** (有效粉是产出来的, 不是运营出来的): ①只做自然渠道 (永不做互关/投放涨粉 — 会往分母掺水) ②内容留互动钩 (有效粉判活跃行为: 赞评享私) ③重度活跃结构是目标 (ep6 实测粉丝重度 88%, 好底子; 每次画像快照必看活跃分布)。

## 六、运营视角: 指标 → 系统杠杆映射 (2026-09-30 用户定则)

复盘不为记账, 为**驱动系统变更** — 每个数据信号对应明确的产线杠杆 (文章布局/提示词/装配配方),
改系统必须从这张表出单, **不凭感觉、不凭喜好**。

| 数据信号 | 运营判读 | 系统杠杆 (落点) |
|---|---|---|
| 深度低/前段流失 | 开头钩子与节奏 | 首分钟蓝图参数: 打字卡时点/3s开口/视角拉起20-25s/60·90检查点 (episode_gen 首分钟段 + anim_draft 开场链) |
| 时长↑深度↓ | 时长档漂移 | series_outline 240s/集 + 集数带[5,10] (ep4=5:57 唯一深度塌方集, 实证在案) |
| 收藏弱 | 选题型配比失衡 (框架型/工具型 vs 叙事型) | 总纲生成 prompt + 选题池权重 (ep6 四维算账=框架型最强, 实证在案) |
| 播放量级低 | 选题大众度不足 | 选题规则"子域内选大众题" + 源头书库选书 (ep3 B端窄题塌量, 实证在案) |
| 吸粉率低 | 转化设计弱 | 宪法收口句式/系列CTA (转发钩子) + 系列连续性露出 (角标/署名条) |
| 人群漂移 | 语义纯度破口 | 宪法文本 (laotan-book.txt 口径/禁令) + episode_gen 确定性闸 |
| 互动率低 | 观点锐度/情绪配比 | 宪法"情绪换点赞/理性换收藏"原则 + P5情绪标注带宽 |
| 评论区纠错/嘲笑 | 口播卫生 | 纠音词表 + 黑话禁令 + 归因句配额 (磷化铟纠音案先例) |
| 封面点击弱 | 封面模板 | 发布卡/封面配方 (科技号封面1.8%弱=真信号, 先例) |

**变更纪律 (三条, 防凭感觉)**:
0. **阶段门禁前置 (§〇)**: Phase 0 泛流期, 本表仅 ①语义纯度 ②涨粉转化 两类行可出单; 深度/时长/收藏/量级/封面各行待 Phase 1 打标确认后激活。
1. **定型才改**: 48h 数据只标记不触发; 变更仅在 Tx 定型复盘 / 粉丝里程碑过点后出单。
2. **出单留痕**: 每次系统变更 = 一张运营变更单 (指标证据 → 杠杆落点 → 预期 → 验证点), 进案卷; 遵循"修模板不修稿" — 改通用模板, 个案禁入。
3. **变更即 A/B**: 变更后以下一集/下一本书为对照组, 回看同指标; 不达预期可回滚 (杠杆全部是配置/prompt 层, 物理可回滚)。

## 七、复查节点三轨制 (系统/内容/提案; 每逢 Tx 定型 + 粉丝里程碑触发)

复查不止看数据 — 每次节点输出**三张清单**, 与数据档分离、直接驱动产线:

### 7.1 系统轨 (产线健康)
- **生产损耗统计**: 本系列生产中 anim_fail 镜数 / 违禁跳卡 / 打回重掷次数 / 人检卡点 (从 job 历史与 shots.json 取数, 不靠记忆)
- **变更单 A/B 回看**: 上一张变更单验证了吗 — 达预期→关单; 不达→回滚或改单 (写明)
- **杠杆激活状态表**: §六各行 Phase 0 冻结中 / 已激活, 随 §〇 判据更新

### 7.2 内容轨 (内容质量)
- 选题型配比实测: 框架型 vs 叙事型的**吸粉贡献**对比 (泛流期唯一权威口径)
- 钩子/收口表现: 收口 CTA 触发的关注行为痕迹 (评论区/私信弱信号)
- 口播卫生: 评论纠错/嘲笑条数 (纠音词表命中率)
- 视觉人检问题清单: 乱码/花字/风格漂移/违禁误拦 的当期存量

### 7.3 提案轨 (更新精进提案 → backlog)
- 每条提案 = 一张单: **指标证据 → 杠杆落点 → 预期 → 验证点**, 入 `docs/status/backlog.md` 编号排队
- 提案 ≠ 立即改: 受 §〇 阶段门禁 + 变更纪律约束, 排队等开闸
- 既有 backlog 项随数据重排优先级 (数据支持度升/降级注明)
- 无新提案也要写"本期零提案" — 空档也是结论, 防漏检
