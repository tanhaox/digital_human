## 采集与复查速查 (详见框架)

- **阶段模型 (判据驱动)**: P0 泛流期(打标+涨粉验证) → P1 打标期(指标全开) → P2 成长期; 判据 = 兴趣聚集跨快照复现 ∨ 画像两次同构 ∨ 千粉热词同向
- **书轴节点**: T0 开更前 / T+48h / Tm 中期 / Te 收官 / Tg 书间交接 / Tx 定型(+7d)
- **里程碑检查点**: 100(起号验证) / 200(模式复制) / 500(打标推进) / 800(冲千前哨) / 1000(毕业线·热词解锁)
- **涨粉阶梯 (§4.3)**: 0→100(冷启动,1-2周·实测11天✓) → 100-200(首标,判据①首测) → 200-500(爬池,互动率>5%闸) → 500-1000(跳档) → 1000-1250(毕业,估11月中); 打标窗 7-14天/~20条, 本号落点 10-18 条; 正规全程 1.5-2.5 月, 本号快于行业
- **有效粉口径 (§4.4, 内功)**: 全部权限门槛按**有效粉**判 (自然渠道真实活跃粉); **8折折算律** — 有效粉≈总粉×0.8, 一切目标按折算执行 (暂定系数, 见真值即校准): 橱窗1000有效≈**1250总粉**, 伙伴计划5000互动≈6250总粉; 代理指标=画像活跃分布重度占比 (>85%系数成立)
- **变现线 (§4.5 并行轴)**: 0粉任务类**P0禁碰**(污染打标); 1000有效粉=橱窗挂书决策点(按变更单A/B, 非自动开关); 5000互动粉=创作者伙伴计划(播放分成, 远水); 千粉前只做选品调研等不动账号的准备
- **三轨复查** (每逢 Tx + 里程碑): ①系统轨 生产损耗+变更单A/B回看 ②内容轨 选题型吸粉贡献+口播卫生+视觉人检 ③提案轨 → backlog 出单排队
- **定时窗**: D 槽 D-15 开窗; "盯到几号" = min(已排, 今+15)
