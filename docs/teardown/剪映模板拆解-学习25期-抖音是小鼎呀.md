## 3. 复合片段机制（本拆解最重要的发现）

- 主轨 segment → `materials.drafts[id]` → 实体存于 **`subdraft/{GUID}/draft_content.json`**（**不加密**）
- 每个复合片段 = 一个封装单元：内含 1 video 轨 + 素材（视频文件/crop/蒙版/matting 智能抠像参数）+ `extra_material_refs`（动画/特效/变速）+ 关键帧
- 命名有锚点：`复合片段N` + 语义名（`1素材_手机出现`、`我的预设15`）
- subdraft 内 video 素材可再嵌套引用复合片段（多层包装），`type=video` 无 path 时即指向下一层

**对 J 线的意义**：复合片段 ≈ 我们的 director slot——**槽位化封装（素材+动画+特效+文字）**。模板逆向 = 把每个复合片段的（素材引用、动画 ID、时间窗）参数化，替换成本线素材。

## 5. 平行教训：学习15期 VIP 打不开（实测确认）

15期-副本打开失败，剪映提示 **VIP 素材**——模板引用了会员特效资源，非会员账号无法从服务端拉取，直接阻塞整个草稿。证实设计方案 §3.4 判断：
- J 线模板筛选红线：**只收无 VIP 资源依赖的模板**（可先用本拆解工具扫 resource_id 对照 pyJianYingDraft 的 `is_VIP` 元数据预筛）
- 已中招模板的两种处置：换近似免费特效 ID；或改版（VIP 解锁）环境导出一次"洗白"副本

## 6. 明文获取路径总结（本次实测全链路）

```
draft_content.json   ❌ AES 加密 (6.0+)
template.json        ✅ 完整明文镜像 — ⚠️ 打开草稿时被剪映消费删除（一次性）
Timelines/*/template.json  ✅ 同镜像的另一份，打开后仍幸存（25期实测）
subdraft/*/draft_content.json  ✅ 复合片段实体，从不加密
.backup/*.save.bak   ❌ 加密
```

**纪律**：模板到手先快照明文（`data/jy_template_snapshot/` 已建，847 文件/32 草稿），再进剪映。
