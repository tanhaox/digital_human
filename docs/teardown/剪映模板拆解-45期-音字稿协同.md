## 2. 🔥 核心发现：协同三件套律

每句口播在画面上同时产生**三层联动**，且时间戳完全同帧：

```
口播句 "美女月入300000+"
   ├─ T5 字幕轨: 整句白字 10 号 (0.02s)
   ├─ T6 强调轨: 关键词大字 "300000+" (1.10s, 数字更醒目)
   └─ SFX: 收银机叮 (1.10s ← 与强调字同帧!)
```

| 层 | 轨道 | 字号/颜色 | 内容来源 |
|---|---|---|---|
| **字幕层** | T5（82 条，≈1.2s/句 高密度） | 白 10 号（63 条）；强调句 18 号；4 条金 24 号 | 口播逐句 |
| **强调层** | T6/T7/T8（引用+关键词大字） | **金 (1, 0.96, 0.54)** 10-21 号 | 字幕句内关键词**原词提取**（带引号""怎么追女生""） |
| **冲击层** | T9/T2（?/VS/负面词） | **红 (0.72, 0.11, 0.11)** 28-44 号 | 疑问/对比/负面冲击词 |
| 封面层 | T1/T11 | 70 号 | 标题 |

**三色板**（抖音知识区标准）：白=正文 / 金=强调 / 红=冲击。红与 16期 完全同值——**跨模板统一色板，可直接定为 J 线默认**。

## 3. 🔊 音效语义实践（53 个音效的落点规律）

音效对齐的**不是句子，是强调字的出现帧**（误差 <10ms）。落点：句首 23 / 句中 23 / 句尾 7——句中一半，因为关键词常在句中。

| 口播内容类型 | 音效 | 对应强调字形态 |
|---|---|---|
| 金额/数字（300000+、月入几十万） | **收银机叮**、水滴×2 | 金色大字数字 |
| 引用/设问/负面（"怎么追女生"、舔狗?） | **悬疑不对劲、沙锤长、紧张回响** | 引号引用 + 红 ? |
| 对比/反差（长得丑 VS 长得美） | **高音闪光、玻璃碎了** | VS/对比大字 |
| 概念强调（共产主义、白月光） | 水滴/空灵水滴、发条 | 金色概念词 |
| 打字机动画文字 | **打字声**（同步逐字） | 打字动画字幕 |
| 转场/段落切换 | 呼2/whoosh | 大标题/新段 |

→ 与用户标注的语义库（`config/jy_sound_semantics.json`）**完全互证**：money/suspense_hook/impact/punchline/typing 分类在这条模板里全部实战出现。

### 3.1 A/B 两遍对照的启示（2026-08-16 用户判读 + 数据验证）

两遍**音效骨架完全同构**（水滴开场→收银机→打字×2→悬疑×2→沙锤→呼→高音闪光→发条→空灵水滴，节拍一一对位），B 遍为**同语义变奏重混**：

- **音效族规则**：同一语义槽位绑定的是"音效族"而非固定单音——A 用 `玻璃碎了`，B 换 `玻璃破碎声1`；`发条旋钮转动齿轮`→`发条转动`。→ R9 实现时按**类别内轮换**选音（`jy_sound_semantics` 每类的 sounds 数组正好如此），避免长视频同一音效听腻。
- **B 版新增的注意力点缀**：`鼠标单击`（指认/点选时刻）、`木鱼`（节奏性强调）、`闪回`（回顾/揭示）、`魔法音效`。→ 正确演示版比基础版多的正是**交互感与节奏点**，可作为 R9 的进阶点缀层。
