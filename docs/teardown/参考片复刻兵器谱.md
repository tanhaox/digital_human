
## 五、三层架构定位(2026-08-26 定)

```
导演层 = director_jobs/director_slots (时间段+visual_type+workflow字段)
素材层 = material_packages/video_assets + HF卡 + P线 + ComfyUI武器 ← 本谱全部内容
剪辑层 = 剪映/ffmpeg (拼接+字幕+调色)
```

**三层合同语言**: 运动模式与光效公式已是可枚举规格(非提示词玄学) —
导演层下单 `slot{时间段|视觉类型|情绪色彩|运动需求}` → 素材层按武器枚举出活(每件自带后期语法: zoompan推镜/倒放/444母版) → 剪辑层只组装不救素材。
**ComfyUI 的定位纪律**: 一切工作流为增强视频视觉服务,按需开发,不做产线外玩具。

## 六、当日验证的硬规则(复用时直接引用)

1. Wan2.2范式: 首帧嵌LATENT(`Wan22ImageToVideoLatent`), 禁用2.1的`WanImageToVideo`; 分辨率必须32步进(1280×704, 720非法)
2. 运动提示词铁律: 只写镜头+环境, 不写首帧没有的内容(写了=幻觉, 如凭空双尾焰); 极简提示词+照片原生微动态=最真实
3. 亮度词只锚一个, 叠词→过曝; 亮调需负面词手术(去"色调艳丽"加"过暗死黑")
4. 方向词当硬词前置(涨↑跌↓), 但模型方向控制弱, 验收按画面实际内容入库(prompt只是抽卡器)
5. 选片三律: 主体清晰/图文匹配/动元素够大 — 照片缺陷会被首帧锚定忠实锁定
6. 5B质感天花板: 实拍质感类"假"是模型档位问题, 提示词变体无效(已证); 换档=云端API或14B(未测)
7. **动态全有或全无定律**: "镜头完全固定"会连光效一起杀死 — Wan需要整体动(推进)才肯让局部动(光呼吸); 固定机位+纯光效=光死
8. 镜头语言: 只用**推进**(放大已有内容,模型乐意); 拉远不执行(要凭空生成边缘新内容)→用推进视频倒放; "滑轨"词→主体平移视差穿帮,弃用; deshake实测无效(抖幅低于门槛), 匀速感靠zoompan数学变焦叠加
9. 爆炸分层: 分离向✅(结构稳,方向随机,按实际结果入库), 聚合向❌(层重叠→坍塌形变)
10. 光效挂载律: 想让什么动,首帧里它必须已显著存在 — 光效是调制器不是创世者(鼠标LED占8-11%像素成功 vs 金属光泽无自发光源失败)
