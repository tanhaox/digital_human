# 动画产线"道法术器"架构设计 v3 — 定稿

> 2026-10-07 用户讨论定稿。融合: 道法两层设计(v1/v2) + 注意力拆解 + 模板填空 + 格式统一。
> 核心原则: **能用参数解决的不用文字, 能用校验解决的不用期望, 每层 LLM 只做一件事。**

## 一、总架构

```
┌─────────────────────────────────────────────────────┐
│ 道: 世界规则手册 (书级, LLM 生成一次, 人审锁定)        │
│                                                     │
│ 职责: 定义"这部片子是谁"                              │
│ 输入: 书名 + 核心主张 + L0拆解 (~3,000字)            │
│ 输出: World Bible JSON (结构化)                      │
│ 注意力: 100% 用于世界构建                             │
│                                                     │
│ 不直接给导演 LLM → 避免注意力稀释                     │
│ 执行方式: 作为法层输入 + K2/H3 参数注入               │
├─────────────────────────────────────────────────────┤
│ 法: 拍摄脚本 (集级, LLM 每场生成)                     │
│                                                     │
│ 职责: 定义"这集怎么讲"                                │
│ 输入: 道层摘要 + 本集稿件 + 音频manifest (~5,000字)  │
│ 输出: Episode Shooting Script JSON                  │
│   ├─ 镜头序 (size/angle/movement)                   │
│   ├─ 光影方案 (key/fill/practical + temp/ratio)     │
│   ├─ 色彩脚本 (hue/sat/val per scene)               │
│   ├─ 道具可见性 (prop_visibility per shot)          │
│   ├─ 连续性 (blocking/eyeline/axis)                 │
│   ├─ 创作槽 (action/scene_detail/atmosphere = null) │
│   └─ 切镜规则 (cut_points + transition_types)       │
│                                                     │
│ 注意力: 100% 用于镜头语言设计                         │
│ 不需要记住皮肤/服装/容量红线 — 那些不归它管           │
├─────────────────────────────────────────────────────┤
│ 术: 分镜填充 (镜级, LLM 只填创作槽)                   │
│                                                     │
│ 职责: 用自然语言填充法层留下的三个创意槽               │
│ 输入: 法层模板 + 本镜口播段落 (~300字)               │
│ 输出: 三个槽值 (~60字)                               │
│   [action] "坐在桌前, 双手举着沙漏"                  │
│   [scene_detail] "桌上散落着几份文件"                │
│   [atmosphere] "忙碌但有序"                          │
│                                                     │
│ 注意力: 100% 用于创作 (不写景别/角度/光影/服装)       │
│ LLM 只做一件事: 描述"画面里在发生什么"               │
├─────────────────────────────────────────────────────┤
│ 器: 渲染执行 (零 LLM, 纯确定性组装)                   │
│                                                     │
│ K2 prompt = style_head                             │
│            + MAP[法.size]         (景别短语)         │
│            + MAP[法.angle]        (角度短语)         │
│            + MAP[法.lighting]     (光影短语)         │
│            + LOOKUP[道.character] (角色外观)         │
│            + 术.action            (动作)            │
│            + LOOKUP[道.props]     (道具描述)         │
│            + 术.scene_detail      (场景细节)         │
│            + 术.atmosphere        (氛围)            │
│            + style_tail                             │
│                                                     │
│ 注意力: 零 (不需要 LLM)                              │
├─────────────────────────────────────────────────────┤
│ 校验: 后置硬检查 (零 LLM, 纯逻辑)                     │
│                                                     │
│ validate_shot_size_variance    相邻景别至少差一级     │
│ validate_lighting_consistency  同场光源一致           │
│ validate_eyeline_pairs         视线匹配              │
│ validate_prop_visibility       道具按法层出现        │
│ validate_color_arc             色彩弧线符合脚本      │
│ validate_narration_sync        旁白与镜头对齐        │
│                                                     │
│ 不合格 → 确定性修正 (覆写, 不用 LLM 重生成)           │
└─────────────────────────────────────────────────────┘
```

## 二、注意力预算表

| 层 | 调用频率 | 输入量 | 输出量 | 注意力用途 | 无用思考 |
|---|---|---|---|---|---|
| 道 LLM | 每书 1 次 | ~3,000字 | World Bible | 100% 世界构建 | 0 |
| 法 LLM | 每场 1 次 | ~5,000字 | Shot List JSON | 100% 镜头语言 | 0 |
| 术 LLM | 每镜 1 次 | ~300字 | 3 个槽值 (~60字) | 100% 创作描述 | 0 |
| 器 | 每镜 1 次 | 0 (参数) | K2/H3 prompt | 0 (确定性) | 0 |
| 校验 | 每集 1 次 | 0 (逻辑) | 通过/修正 | 0 (确定性) | 0 |

**对比现有系统:**
- 现有导演 LLM: 17,000字输入 → 200字输出, 遵守率 <60%
- 改造后术层 LLM: 300字输入 → 60字输出, 遵守率 = 100% (因为只需要创作, 不需要遵守规则)

## 三、格式统一五原则

| # | 原则 | 说明 |
|---|---|---|
| 1 | **一个字段只在一层定义** | 景别只在法定义, 术不重复; 光影只在法定义, K2 不猜 |
| 2 | **层间传 JSON, 不传自然语言** | 法→术 传模板 JSON, 术只填 null 槽 |
| 3 | **术层输出是槽值, 不是完整描述** | 术不写 keyframe_zh 全文, 只写三个值 |
| 4 | **K2 prompt 是组装的, 不是 LLM 写的** | 结构参数确定性映射, 创作槽直接插入 |
| 5 | **角色/道具用引用, 不重复描述** | 法层写 ref, 渲染时从角色卡/道具体系 LOOKUP |

## 六、术层 Prompt (模板填空)

```
你是画面描述师。根据口播, 填写三个创意槽。

口播段落: "{narration_segment}"

镜头已定: {size} / {angle} / 光源={lighting}
角色已定: {character_name}
道具已定: {props_list}

不要写镜头/角度/光影/服装/皮肤 — 已由其他层决定。
只写: 这个人在做什么, 画面里有什么, 什么感觉。

[action] (≤20字): 这个人在做什么
[scene_detail] (≤30字): 画面里还有什么细节
[atmosphere] (≤10字): 情绪氛围

输出 JSON: {"action": "...", "scene_detail": "...", "atmosphere": "..."}
```

## 七、K2 Prompt 组装 (确定性)

```python
def assemble_k2_prompt(dao, fa, shu, shot_id):
    """确定性组装 — 零 LLM"""
    shot = fa.get_shot(shot_id)
    scene = fa.get_scene(shot.arc_id)

    # 结构参数 → 短语映射
    size_phrase = SIZE_MAP[shot.size]              # "ELS" → "辽阔的全景画面"
    angle_phrase = ANGLE_MAP[shot.angle]           # "birds_eye" → "俯瞰视角"
    light_phrase = LIGHT_MAP(scene.lighting_setup) # → "自然光从左上射入, 暖白色调"

    # 角色/道具 → 从道层查表
    char_phrase = CHAR_LOOKUP(dao, shot.blocking.character)
    prop_phrase = PROP_LOOKUP(dao, shot.props_visible)

    # 创作槽 → 从术层取值
    action = shu.get(shot_id, "action", "")
    detail = shu.get(shot_id, "scene_detail", "")
    atmo = shu.get(shot_id, "atmosphere", "")

    # 组装
    return f"{style_head}{size_phrase}{angle_phrase}{light_phrase}" \
           f"{char_phrase}{action}{prop_phrase}{detail}{atmo}{style_tail}"
```

## 八、与现有管线的迁移路径

| 现有组件 | 改造 | 新增 |
|---|---|---|
| 圣经 JSON | 扩展为道层 World Bible | + grammar/lighting/color/props/motifs |
| DIRECTOR_SYS | 拆分: 法层 prompt(设计) + 术层 prompt(填空) | 两个新 system prompt |
| 增强器 pass1/2 | 大部分被确定性组装替代 | 只保留 creative slot 的润色 |
| keyframe_zh | 从"LLM 全文"变为"组装结果" | 组装函数 |
| prop_lock | 从法层 prop_visible 自动生成 | LOOKUP 表 |
| K2 build_prompt | 从"LLM keyframe + style"变为"组装 prompt" | SIZE/ANGLE/LIGHT_MAP |
| H3 build_prompt | 从"anim dict"变为"法层 blocking + 术层 action" | 结构化注入 |
| 校验 | 从 prop_lock_audit + text_lint 扩展 | validate_* 函数族 |
| 页面 | style_bible 展示道, anim 展示法 | 两个页面扩展 |
