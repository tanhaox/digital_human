# 电影感·微空间变奏 (1008 用户令定稿)

> 起因: ep2 s01-s03b 四镜被判"独立的4个镜头, 没有小故事感"。
> 根因 = 0919 铁令"组内场景禁重复"逼每镜换片场 (23秒跳3个世界)。
> 用户裁定: 铁令升级为**微空间变奏** — 多样性手段从"换场景"换成"同大空间换微位+换景别角度"。

## 一、规则变更

| | 旧 (0919) | 新 (1008) |
|---|---|---|
| 多样性来源 | 每镜换场景 (scene_tag 禁重复 = 地点禁重复) | 同大空间换**微位** + 景别角度必变 |
| 空间 | 组内每镜一个新片场 | 组内共享一个 **location** (道层 world.exists 选定) |
| scene_tag | 场景名 (深夜书房/印刷车间) | **微位名** (工位/窗边/白板前/会议室玻璃后), 组内禁重复不变 |
| 防构图同源 | 靠换房间 | 法层相邻镜景别必差一级+角度变 (确定性硬校验) + 母题轮换保留 |
| 承接 | 无 | 视线链 (上镜看向哪, 下镜顺着接) + 动作链 (术层填空带前镜 action) |

执法不变的部分: `hook_zone.zone_scene_issues` 硬审计 (scene_tag 组内禁重复),
`zone_composition_issues` 构图同源软审计, 母题轮换。

## 二、落点 (六处)

1. **hook_zone.ZONE_RULES** — 条款2/4/7 重写 (微空间变奏+视线链)
2. **法层 _SHOOTING_SYS** — scene.location + shot.blocking.micro_position 入 schema;
   _summarize_dao 下发 world.exists 世界清单 + 角色名单
3. **法层 _sanitize_scenes** — 微位场内去重 (方位后缀 左/右)
4. **术层 _CREATIVE_SYS** — 输入带 location/微位/前镜action/视线链; scene_detail 禁换空间
5. **器层 assemble_k2_prompt** — 场空间·微位注入画面句; H3 opening_desc 带空间锚
6. **器层 fa_index → _expand_fa_shots** — 法层F镜→docN镜**游走插值展开**:
   - 旧比例映射 j*F//N 在 N>F 时连续同槽 (12镜吃3个ELS)
   - 新: 尺寸沿阶梯游走 (每步必变/末步落anchor/边界翻方向), 插值镜微位加方位
   - 3000 组随机合法法层暴力验证 PASS (相邻必变+首镜=fa0+末镜=fa末+定长)
