# 素材层 2.0 — 实体驱动管线（设计方案 + 首跑状态）

> 建立日期 2026-08-28 ｜ 状态：**管线贯通（实验态，未接产线）**
> 背景：用户裁决——稿件层已 80-90 分，画面层 40-50 分是拉分项，核心升级 = 素材 + 剪辑；
> 素材层 40 分根因 = **源类型错配**（Pexels 图库没有真实人物/装备/事件画面）+ **检索与口播稿脱节**（9 维词表全是风格维度无实体维度）。

## 一、架构（实体驱动 + 多源路由 + 回库复利）

```
口播稿 → ①实体抽取 (person/military/event/org/place/concept 六类)
              ↓ 按类型路由
         ② ┌ 人物/事件/装备 → 油管精准截取 (官频=原封未动保证)
           │ 军事装备       → DVIDS (公共领域, 未接)
           │ 通用意象       → Pexels (现有, 降兜底位)
           └
         ③ 油管入库管线: batch(频道→30s~10min口径→下载) → split(切点切片)
              → tag(llama 逐段: 内容/烧录字幕检测/实体标签) → register(VideoAsset)
         ④ 调取: 实体靶心通道 (英文query × 素材英文指纹, 命中即正解绕9维门槛)
              + no_subtitle 标签优先 (烧录字幕片降权)
```

## 三、实测结论

- 靶心命中：小米空调（无字幕✓）/芯片特写（无字幕✓）/台积电相关 ✓ —— 从"口播提英伟达"到"取出官片片段"全链走通
- 9B vs 30B 交叉验证（20 片）：字幕判定一致率 87%；30B 描述/OCR（读图表标题/26℃显示屏）/品牌识别全面高一档 → **双层分工定稿**
- T3R3（Redkont 先进封装动画）反推：口播无来源声明，判定自制；同级动画公开源 = semiengineering / ASE / 官频
