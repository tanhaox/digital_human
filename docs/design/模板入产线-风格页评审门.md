# 模板入产线 — 风格页评审门（硬性工作流）

> 用户令 2026-09-04：**今后所有模板（HF 卡/海报/任何视觉模板），必须先在「风格候选页」上讨论完毕，才可进入产线。**

## 为什么

- 黑金 v2 直接入产线 → 与科技/时局赛道调性不符，整套返工为纸墨 v3。
- 编辑纸墨 v3 走风格页讨论（`.tmp/style_gallery_h.html` 横版 17:16 定稿）→ 一次通过，烟测三修即收。
- 教训：模板的风格决策不能在产线里试错 — 渲染、注册、提示词接线都是沉没成本。

## 怎么做

1. **先产风格候选页**（不改 `templates/`、不接注册点）：
   - 本地 `.tmp/style_gallery*.html`，同款页面模式：真实数据样例（非 lorem）、**横版 16:9**（竖版暂不开发，有需求再加）、风格 token（色板/字体/留白）并列候选
   - 先例：`.tmp/style_gallery_h.html`（横）
2. **用户在页面上拍板** — 色板/字体/布局/调性
3. **拍板后才动**：`templates/hf_prep_v3/` 写模板 → 注册点接线 → 烟测（RapidOCR 逐帧验证）→ CHANGELOG
4. 未过风格门的模板工作，一律不得 commit 进产线分支

## 评审页内容清单

- [ ] 真实稿件的代表性数据（标题/数字/引用，不用占位文）
- [ ] 横版 16:9 一屏（竖版暂缓，有需求再开发）
- [ ] 与现有 v3 纸墨系并排对比（新旧同屏，调性冲突一眼可见）
- [ ] 风格 token 明示：底色/主字色/强调色/字体/圆角
