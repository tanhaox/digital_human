## 三、越狱机制 (查证: 为什么"不换LoRA永远不会出")

Base 出厂经**安全对齐训练**把特定概念方向在权重里摁住; 越狱 LoRA = 几 MB 低秩增量专门逆转被摁方向
(SaLoRA/LoRAShield 等防御研究反向印证)。推论: 权重里没有的能力, 提示词/参考图/mask 都召不出来 —
身份战役图像层全灭的根因即此: **向没装"德鲁克弹匣"的模型要德鲁克**。
