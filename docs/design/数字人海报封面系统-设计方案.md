## 0. 一句话

封面是信息流的"0.5 秒拦截器"；用 **内容驱动生成画面 + 本地确定性渲染文字 + 安全区排版** 自动产横竖多张候选，交给平台 A/B 换素材择优，跑出数据后再决定集不集成、怎么集成。

## 1. 为什么封面点击率高（调研结论）

| # | 规律 | 关键数据 | 对系统的落地要求 |
|---|---|---|---|
| 1 | 时间窗极短，封面是唯一拦截器 | 抖音信息流给封面 ~0.5s；用户停留 <3s；头条"黄金3秒" | 信息分层：主视觉占 60%+，1 主标题+辅助信息，删无关元素 |
| 2 | **文字是点击率第一杠杆** | 主标题 ≤12 字（抖音）/≤10 字（通用）；手机缩略图 ~3cm 宽 | LLM 直出 ≤12 字 headline，大字号，无衬线字体 |
| 3 | 高对比 + 文字可读 = 点击基础 | 暗背景配亮黄/纯白文字 + 2-4px 描边或半透明底块 | 文字节点默认开描边/阴影/底块 |
| 4 | 情绪脸是视觉锚点 | 真人出镜人脸占 1/3~1/2，表情明显 | 主播人像作为画面主体（可关） |
| 5 | 平台 UI 遮挡 → 必须留安全区 | 9:16：顶 0-200px/右 150px/底 350px 死亡区；主页 3:4 裁切 | 核心内容集中在中央 1080×1440 安全区 |
| 6 | 封面点击率决定流量池 + 平台读图 | 封面点击率 <2% → 播放难破 500；头条"图+文相关度"影响初始推荐池，情绪张力图 CTR 平均高 30%+ | 画面与标题强相关，账号品牌统一 |
| 7 | 平台合规与硬性尺寸 | 头条：单图 16:9/三图 3:2，禁广告/模糊/无关图；抖音：JPG 500KB-2MB 防二次压缩 | 导出 JPG q80-90，体积合规 |

## 3. 工作流架构

```
口播稿全文 + 标题
   │
   ├─▶ [画面管线·LLM] 提取主题/情绪基调/画面元素/场景 → 拼画面 prompt
   │       └─▶ Krea2-Turbo + Klein 一致性 LoRA（零文字 prompt）× 3 seed → 超分 → 安全区构图校验
   │
   └─▶ [文案管线·LLM] 版面约束下直出 JSON（headline/subheadline/channel_tag/edition）
           └─▶ Advanced-TextOverlay 本地渲染（中文字体+描边+底块）→ 合成 → 导出 JPG
                                    │
                                    ▼
                        竖版 3 张(9:16) + 横版 3 张(16:9)
```

**关键分层**：画面=AI 生成（背景/氛围/构图），文字=确定性本地渲染（100% 正确），最后合成。两条管线都吃同一个 LLM 提取的结构化信息，保证图文强相关（平台读图要求）。

## 4. 画面管线（内容驱动）

### 4.1 输入 → LLM 提取

```
口播稿全文 + 标题
→ { 核心主题, 情绪基调, 画面元素, 场景关键词, 主播形象描述? }
```

### 4.2 提示词三段式（借鉴头条"情绪词公式"）

| 情绪基调 | 提示词骨架（示例） |
|---|---|
| 冲突感 | `Real photo, low angle shot, dramatic lighting, intense atmosphere, realistic style, 4k` |
| 专业感 | `Minimalist vector flat illustration, business data, 3d icon, tech blue and white background, clean composition` |
| 好奇/悬念 | 留白 + 剪影/背影 + 逆光 |
| 实用/干货 | 高亮主体 + 干净背景 + 聚焦 |

LLM 按情绪基调选骨架 → 拼入画面元素/场景/主播描述 → 最终 prompt。

### 4.3 A/B 变体策略
- 同 prompt 换 **3 个 seed** 出 3 张变体。
- 必要时附加构图词差异（近景/中景/特写、不同情绪强度）。
- 如需主播形象：模板含"主播形象描述"，**默认开启可关**（纯内容画面跑另一组）。

### 4.4 铁律
- **画面 prompt 严禁任何文字/数字字符串** → 从源头杜绝 AI 画字鬼画符。

## 5. 文案管线（版面约束）

### 5.1 LLM 直出 JSON

```
{
  "headline":     "≤12字主标题",   // 缩略图清晰，数字/关键词前置
  "subheadline":  "≤12字副标题",   // 信息补强（可空）
  "channel_tag":  "频道标签",      // 品牌统一（可空）
  "edition":      "期号/日期"      // 可空
}
```

### 5.2 文字渲染（本地确定性）
- 工具：**ComfyUI-Advanced-TextOverlay**（已装，像素级排版：字距/行距/对齐/描边/阴影/底块/富文本/系统字体）。
- **中文字体显式指定**（微软雅黑/思源黑体），避免 fallback 豆腐块/乱码。
- 描边 2-4px + 可选半透明底块（高对比保证可读性）。

## 6. 安全区规则（决定文字/人物摆放）

| 平台 | 画布 | 规则 |
|---|---|---|
| 抖音竖版 | 1080×1920 | 顶 0-200px / 右 150px / 底 350px 死亡区不放文字；主标题+人物集中在**中央 1080×1440 安全区**（进主页裁 3:4 不切） |
| 头条/YouTube 横版 | 1920×1080 | 上下各留 ~120px；标题区避开右侧按钮位 |

- 合成后按 **15% 缩放**自检主标题清晰度（模拟手机信息流）。
- 人物与背景撞色 → 加白色描边/外发光抠出。
