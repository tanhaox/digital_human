## 三、提示词语法（内嵌模板提炼）

1. **首行图片引用**: `@图片1作为主角身份与服装参考@图片2作为场景与光影参考`（与提交顺序一致，一图多功能合并写）
2. 正文: `生成一段{5|10|15}秒、16:9、2K、原生立体声的{类型}短片。{主角锁定}。{0-N秒逐段时序}。{镜头规则}。视觉风格：{...}。`
3. **全正向措辞**（只写要什么）；时间段无缺口；连续感靠身份/轴线/道具/色彩母题，默认允许多镜头
4. 三流程: **文戏**（关系转折/微表情）/ **武戏**（攻防节奏预算/受力反制）/ **九宫格**（先生成 3×3 母版 → `@图片1作为九宫格时序参考` 转视频）
5. 视频参考冲突规则: 图片锁身份，故事/视频锁事件；冲突时图片身份优先

## 五、对我们产线的接入点

1. **拆书分镜→H3 r2v 直出**: 分镜图占图槽 + 三流程模板做提示词引擎（模板与 ai-storyboard-director 文/武分科同构，可直接熔接）
2. **九宫格模式 = pose 线 15 格的 H3 版**：定妆表/九宫格母版 → 时序一致性视频
3. **动作克隆**: 参考视频（2-15s）+ 定妆图 = SCAIL 的 H3 平替路线（待消融：H3视频槽 vs SCAIL2 专用模型）
4. **配音原型**: 音频槽锁音色 + 台词进提示词 → 对白镜头音画一体出（对比我们 IndexTTS 产线：免装配但不可控）
5. **无声版**（断 261.audio）配自家 TTS/BGM = 现行装配原则的标准打法
6. 底模矩阵在库: r2v pruned int8（本流）/ Dasiwa hybrid（动漫向）/ fl2va / it2v boogu

## 七、定妆消融定论（1011 用户人检）

- **A 单镜参考（00010）：转头时身份完全失守**；**B 九宫格定妆（00011）：身份锁住** → 组合拳成立
- 标准链路: **单图 → 2511+Multiple-Angles LoRA 九宫格定妆（28s, 1280², Lightning-8, 须人检重roll）→ H3 r2v 身份槽**
- **逐格位置说明**（用户补强）: 提示词须写明 3×3 每格内容（"第一行左→右为正脸/左45°/正左侧…"），模型对网格语义理解显著提升
- 九宫格生成与 H3 提示词的格子顺序必须一致（行主序对齐）
