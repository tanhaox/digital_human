# laotan-tech.txt 短视频化改造（7层框架定稿，2026-08-14）

> **核心判断：** 原laotan-tech.txt的"六模块"结构本身没问题，问题在于每层的"配重"和"表达方式"全是长视频逻辑。
> **改造原则：** 不改层数，改每层的交付物——从"信息"改成"情绪+认知缺口"。
> **最终输出：** `config/laotan-tech_7layer.txt`（7层独立子提示词，每层可单独调用）

## 改造要点记录

1. **全程禁止示例句**（LLM会照抄示例）
2. **每层独立可调用**——每层包含：时长→任务→观众反应→硬性要求→字数→停顿标记
3. **删掉了"在这个不确定的时代"**等泛泛口号
4. **身份段改成"我是老谭，专盯XX"**带具体标签
5. **第5层用"两胜一负"快剪节奏**（过→过→翻车，翻车处必须有共鸣比喻）
6. **第7层统一收束到"一个认知+一个行动指令"**（不分散到三段点赞）

**boost 改造**：
- 砍 P1/P2/P3（7层已有等价结构，它们只覆盖）
- P4 重写：1:1 锁 7层结构/身份段/结尾/钩子，只精修表达
- 新流程：`原稿 → P4精修 → P5情绪标注`（情绪走 emotion_annotations 给 IndexTTS，不污染稿件）
- boost 终稿：身份段/结尾保留7层格式，无旧版覆盖

**情绪链路**：P5 标 8 段段落级情绪（surprised 主基调×5 + serious×2 + happy×1）→ emotion_annotations → IndexTTS 按段情绪合成（vector 传导日志验证通过）。
