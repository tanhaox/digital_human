# 运镜军规 · 1017 定稿

> 本文档是镜头语言与动画纪律的**唯一真源**（三代白名单归一：G1 sandbox 0914 → G2 0915 宪法 → G3 ID-100）。
> 代码执法点在条款旁标 `〔执法:文件〕`；实锤判例见 §9 索引表。
> 生成时间：2026-10-17（ep4 两晚战役收敛）。

## 1. 总律：锁构图动画密度律（ID-100）

**相机全程固定在 Picture 1 取景**——动效全部发生在画框内。四条铁律：
1. 每拍 ≥2 个画框内可见变化（光带扫过/边缘反光滑动/粒子/微表情/物件微动/灯光呼吸）。
2. 相机零运动：禁急推/zoom/重构图/离场特写。
3. **冻结瞬间续写**：第一拍必须从图的冻结姿势向前演，禁回卷禁前置（图里卡已举在手上就不能写"伸手去拿"）。
4. 人物转向镜头解禁但须双约（长相锚 Picture 1 + 表情基调）。〔执法:h3.py S1 锚行 / beats_enrich 模板 / director_prompt.txt〕

## 3. 密度与节奏

- 每拍 1.5-3s；每镜 2-6s；首拍 1s 内见变化（钩子纪律）。
- 前 60s 特区 12-18 镜；0-25s 段长 2-3s 优先。
- ending 动感落点但镜头不动（光束定格/粒子沉降）；"calm hold" 仅降级兜底。
- 情绪特效层（燃/桃心眼/怒焰）每集 3-6 镜点缀；特效拍环境道具仍锚定。〔执法:beats_enrich 校验 / director_prompt.txt〕

## 4. 续写律（S2/S3 图真锚）

- beats 第一拍从**已渲 K2 图的 VLM 冻结瞬间描述**续写（图真锚；VLM 不可用退画面句）。
- 画面句必须描述 **t=0 确定瞬间快照**（writer 契约"画面句=动画起点帧"；fallback 镜弧措辞进软警告）。
- 位移行进收窄版：人物可走出/走入画面（有明确目的地）、弯腰拿取交互；禁画框内原地行进。〔执法:beats_enrich / scene_writer 契约 / director2 collect_warnings S3〕

## 5. 构图多样性（跨镜）

- 微空间变奏铁令（1008）：同大空间换微位 + 景别必差一级 + 角度变。〔执法:constitution.py 相邻景别角度必变 / validate_shot_size_variance〕
- 严禁"同场景机位不变"续镜；前后镜主体名词重叠 >50% = 违规。
- 景深配额（0926）+ 人物配额（1014 一把尺 zone_quota）。〔执法:final_gate.validate_final〕

## 7. 注入纪律（ID-095 具象词军规）

- 任何书级/全局注入字段（圣经 era_anchor/motion_style、提示词壳常量、风格卡）**禁写具体场景名词与物件词**（卧室/窗帘/旗帜/家具），只写性质词——具象名词是画物邀请函（curtains swaying / 1940s卧室 / same room 三案实锤）。
- negation-induced hallucination：禁句里点名禁物 = 越禁越长（串旗实锤）。
- 豁免边界：**镜级画面句**允许且应当具体（微叙事黄金范例合法）。〔执法:h3.py AMBIENT_LIFE/era 锁中性化 / 圣经字段编辑自律〕

## 8. 素材线（Wan/i2v）运镜律（分宗，勿混）

来自 docs/teardown/参考片复刻兵器谱.md，适用素材匹配线，**不适用 H3 管线镜**：
- 运动三型：A 纯运镜最稳 / B2 空间扫掠弃用；只用推进、拉远倒放；滑轨弃用。
- 运动提示词只写镜头+环境，**不写首帧没有的内容**（ID-100 §4.3 的最早思想源头）。
- 动态全有或全无定律。
