# 拆书导演模型 · 句型寄存器 — 定稿

> 2026-10-09 用户裁决。起因: 卓有成效 ep2 新架构(道法术器)实弹, 德鲁克出镜 42/47 镜(89%),
> 台灯 16/47 镜, 概念画面 0 镜 — "就算是 MTV 超级偶像都不敢这么排分镜"。
> 用户裁定大框架道法术器成立, 但吸收了过多影视剧概念; 拆书要有拆书自己的导演模型。
> **MTV 手法 (1009 用户令)**: 歌虽是歌手唱的, 但主要画面是电影; 歌手有出镜, 绝不能成为
> 主力出镜, 电影画面优先。**作者 = 歌手, 定妆主角 ≠ 每集绝对主角, 作者绝对不等于万能临时演员。**
>
> ⚠️ **1013 勘误 (用户原意追认)**: 上段"电影画面"= **有人物有情节的电影化叙事** (如电影类MTV
> 的故事段落), 不是无人物件世界。本模型曾把"歌手不刷屏"错译成"概念场无人" (§一隐喻镜默认 +
> 器层概念域禁人物注入), 致 ep1 全空镜事故。正解: **MTV手法只约束讲述人出镜密度 (≤25% 帽),
> 概念世界的画面以人物在概念场景中行动为主** (用户认可基线: HBO 61种人物/46镜, 定位 45种/57镜)。
> 落地: config/anim_constitution.json person_quota (hook/mid 下限 0.6) + scene_writer.WRITER_SYS §6。
>
> **结构**: §一~§九 = v1 定稿 (镜级/场级寄存器模型, 已落地); §十~§十五 = v2 附录
> (书级立意层: 世界库书级 + 标签切场, 已设计待立项)。

## 一、根因复盘 (为什么法层失效)

文稿是一篇**说理文**, 概念是主角 (ep2: 概念句 55%), 人物全是功能角色
(德鲁克仅 3 句 8%, 引用语境)。法层按**戏剧 coverage** 规划 — 每镜必填
blocking.character + 一场一实景 + 灯具光源入画, 于是:

| 倒挂 | 文稿占比 | 画面占比 |
|---|---|---|
| 概念 (记录/删减/合并) | 55% | **0 镜** (沦为桌面摆件) |
| "你" (痛点主角) | 10% | 0 镜 |
| 德鲁克 (被引用的权威) | 8% | **89%** |
| 老谭 (品牌框, 原子槽已对齐) | 8% | ✓ |

三宗罪: ① blocking.character 必填 → DP 无处表达空镜/隐喻镜; ② 道层 world.exists
只有 6 个实景办公室, 与立意层 visual_metaphor 断链 (A4 筛网 → 办公桌+台灯);
③ P7 七道校验无一查主体密度 → 无声全绿。

## 三、导演模型: 讲座图文导演 (essay coverage)

口播是主线 (歌手), 画面"讲到什么给什么" (电影画面)。规划单元从
"场 × blocking" 换成 **句型 × 主体寄存器**。

**默认反转**: 现默认 = 实景+人物 (所以德鲁克灌满); 新默认 = **隐喻镜**。
特殊句型才切寄存器 — 德鲁克被结构性钉死在引用句配额内 (ep2: 3 句 → 2-3 镜,
89%→~6%), 不靠配额补丁, 句型本身就是围栏。

### 寄存器表 (subject_type)

| register | 对应句型 (规层打标) | 画面主体 | location 来源 | ep2 配额 |
|---|---|---|---|---|
| `metaphor` 概念隐喻镜 | 概念句 (**默认**) | 概念世界实体在发生 (沙漏下/筛网滤/金流聚) | **本弧 visual_world** (world_library 收编) | ~28 镜 |
| `pain_point` 痛点镜 | 钩子区概念句 (zone=hook) | "你"/观众替身在困境 | 实景痛点场景 (泛化人物) | ~4 镜 |
| `case_narrative` 案例镜 | 案例句 ("举例/一位高管/某公司/书里举了") | 案例人物 mini-drama | 实景, 微位/视线链/coverage 全套在此适用 | ~4 镜 |
| `author_cite` 作者镜 | 引用句 ("书里原话/德鲁克在书里强调") | 德鲁克+书页 (执笔/翻页) | 书房; **德鲁克唯一合法寄存器** | 2-3 镜 |
| `host_brand` 品牌镜 | 品牌句 (is_brand_text 原子槽, 已存在) | 老谭 | 品牌卡 (现有链) | 2-3 镜 |
| `contrast` 对比镜 | 互动句 ("评论区/你站哪边") | 双立场同屏对比 | 概念世界或分屏 | 1-2 镜 |
| `recap` 展馆镜 | 总结/预告句 ("三步/下一集/第7集等你") | 工具陈列推进/下件工具亮相 | 概念世界 (展馆) | ~4 镜 |

人物约束: 德鲁克只准入 author_cite; 老谭只准入 host_brand; 案例人物只准入
case_narrative (有圣经卡用卡, 无卡泛化人物); metaphor 世界的"小人物"是隐喻
构件 (沼泽木板上的人), 不带定妆 look。

## 四、三级拆解 (大纲 → 集 → 镜)

- **书级 (道)**: 工具宇宙 — 五件工具各绑一个概念世界 + 一件道具 (props 生命周期已有);
  world 双域: `world.exists` (实景, 案例/痛点用) + `world.concept_worlds` (概念世界注册表);
  人物三班制: 老谭(框架)/德鲁克(客串歌手)/案例人物(每集客串) + "你"(观众替身常设);
  寄存器配比是书级气质参数 (本书≈ 隐喻60:痛点10:案例15:其他15, 案例重的书自动倾斜)。
- **集级 (法)**: 规层先打句型标签 → 法层在寄存器内做镜头语言设计 (节奏/光影/微位),
  location 按场的主寄存器选域: 概念场选概念世界, 案例场选实景。
- **镜级 (术/器)**: 术层按寄存器填槽; 器层按寄存器选组装模板。

## 五、落点 (层间职责, 遵守格式统一五原则)

### 1. 规层 — 新模块 `registers.py` (零 LLM)

- `tag_sentences(text) -> [(句, tag)]`: 品牌句复用 `shots.is_brand_text`;
  cite/case/interact/teaser/pain 走关键词规则; 未命中 = 概念句。
- `assign_registers(doc) -> int`: 逐镜按 narration 句型 + zone 钉
  `shot.register` + `shot.reg_ref`:
  - brand→host_brand; cite→author_cite; case→case_narrative; interact→contrast;
    teaser/总结→recap; zone=hook 的概念句→pain_point; 其余→metaphor
  - metaphor 的 reg_ref = 本弧 `visual_world` (world_library 同名条目);
    cite 的 reg_ref = 句中点名的角色 (缺省 = 引用句实证推断的作者 — 引用句型句中
    点名频次最高者, 不裸信 characters[0]); case 的 reg_ref = 句中人物 (**排除作者** —
    "德鲁克举例子，一位高管…" 主体是高管; 圣经卡命中则带 look, 未命中泛化)
- 幂等: 已有 register 且 only 未点名则跳过。

### 2. 法层 `shooting_script.py`

- `_summarize_dao`: 下发 `world.concept_worlds` (缺省收编 shots.json world_library)
  + 角色三班制说明。
- `generate` 输入: 各弧 visual_world/visual_metaphor + 该弧句型分布
  (规层打标聚合, 如 "A4: 概念×5/案例×2")。
- `_SHOOTING_SYS` 重写: DP 职责收窄为 "寄存器内的镜头节奏设计" —
  ① 每场主寄存器判定 (概念场/案例场/引用场…) → location 按域选
  (概念场 location=概念世界名; 案例场从 world.exists 选实景);
  ② 镜头节奏 (size/angle/micro_position, 相邻差一级不变);
  ③ 光影方案 (mood_map; 概念场光源=光效语言); ④ blocking.character **可选**,
  仅案例/痛点场填, 德鲁克只出现在引用场。
- `validate_report` + 3 项 (见 §六)。

### 3. 术层 `creative_slots.py`

`_CREATIVE_SYS` 按寄存器分支:
- metaphor: action=「隐喻过程推进到哪一刻」(沙粒正漏下/大石留在筛面), detail=概念世界内细节;
- case/pain: 现行人物动作链 (承接前镜);
- cite: action=执笔/合上书页/抬眼, detail=书房书页细节;
- contrast: action=两侧动态对比; recap: action=工具/展台推进。
输入区新增 `本镜寄存器/主体锚 (reg_ref)`; character 参数不再喂旧 keyframe 残文
(修 1008 遗留: `character=str(shot.get("keyframe_zh"))[:50]` 错喂)。

### 4. 器层 `assembler.py`

- `assemble_k2_prompt` 按寄存器选模板:
  - **metaphor**: `{size}，{angle}，{概念世界}·{微位}，{光效语言}，{术.detail}，{术.action=过程}，{道具}` —
    无实景 location、无人物 look、无灯具;
  - **case/pain**: 现行链 (location+光源+人物 look+动作链);
  - **cite**: 书房锚 + 德鲁克 look + 书页道具;
  - **host_brand**: 品牌卡链 (现状不动);
  - **contrast/recap**: 概念世界 + 对比/陈列构图词。
- `_light_phrase` **全局去灯具**: 只出方向/色温/光比 (侧光45度, 4500K, 补光比1:3),
  灯具实体 (台灯/面板灯) 一律不进 keyframe — 想要灯只能经术层 scene_detail。
- fa 钉标加 `register`/`reg_ref` (页面灰标签直读)。

### 5. 链路接线 `planner.py`

- 分镜续跑/单场重规划: `plan_scene → assign_registers → fill_creative_slots →
  assemble_episode` (术层吃 register 分支; 器层吃 reg_ref 锚)。
- 已产物镜 (img_done/approved/anim_done) 与品牌卡镜照旧跳过 — 磨合成果不冲。

## 六、确定性闸 (validate_report 新增三项)

1. **主体围栏**: 德鲁克 look 串出现在非 author_cite 镜 keyframe → WARN;
   author_cite 镜数 > 引用句数×2 → WARN (引用句数由规层打标得出)。
2. **人物密度**: 单一角色出镜 > 全集 25% (案例 run 内豁免) → WARN;
   同一角色连续 >2 镜且非案例 run → WARN。
3. **隐喻对齐**: metaphor 镜 keyframe 未命中本弧 visual_world 的
   world_library 关键词 (取世界名+映射实体词) → WARN。

P7 页面徽章自动渲染 (v.items 泛化消费, 零前端改动)。

## 七、落地顺序

| 步 | 内容 | 验证 |
|---|---|---|
| 1 | registers.py 打标+钉寄存器 (纯函数) | ep2 文稿 60 句打标人工抽检 + 单测式自跑 |

| 6 | ep2 全集重跑 (法→术→器) | 德鲁克出镜 ≤3 镜, 台灯 0 镜, 概念镜 ≥25 镜 |

## 八、验证口径 (1009 定)

- 德鲁克出镜 = author_cite 镜数 ≈ 引用句数 (ep2 预期 2-3 镜, 现状 42);
- 台灯/灯具实体不出现在器层组装的 keyframe (经 scene_detail 例外);
- 概念镜 (metaphor+recap+contrast) ≥ 全集 55% (对齐文稿概念句占比);
- 概念镜 keyframe 命中本弧 world_library 关键词;
- 景别/角度/微位变奏纪律不回退 (P7 原四项保持全绿);
- 人物一致性压力随出镜数下降为副产品收益。

**实弹结案 (1009, v1 已落地验证)**:
- ep2 旧病态 doc 过新增三闸**全报 WARN** (主体围栏/人物密度/隐喻对齐);
  `assign_registers` 补钉 + 重组装后 P7 报告 **11 项全绿** — 围栏零 LLM 生效。
- **s53 实锤**: 旧 fa 层 38/40 镜 `blocking.character` 写德鲁克 — 器层照读 =
  寄存器围栏虚设; 故 `_char_for_register` 实景域人物**只认 reg_ref** 不认
  blocking.character。
- **headless 陷阱**: 脚本直跑 replan/续跑须先 `init_db(load_config().app.database_url)`,
  否则 `session_maker=None` 死链 (无报错堆栈直达 NoneType)。

## 九、不做什么 (防走样)

- 不动立意层 (visual_metaphor/visual_world 已正确, 是本次的救兵);
- 不给 DP 加"配额"话术靠 LLM 自律 — 围栏全在规层/校验 (确定性);
- 不改品牌卡链/音频装包/时间轴 (已是成熟资产);
- 不推翻 v3 五原则 (subject_type 在规层定义一次, 器层查表组装, 引用不重复描述)。

## 十、问题实锤

**① 世界库逐集漂移 — 同一本书四套词汇**:

| ep | world_library (节选) |
|---|---|
| ep1 | 霓虹书山 / 能量迷宫 / 决策天平 / **要事筛网** … |
| ep2 | **时间筛网** / 时间账房 / 时间熔炉 … (10 个) |
| ep3 | 心智阶梯 / 天平称重场 / 信息流广告墙 … (12 个) |
| ep5 | 能量熔炉 / 双轨传送带 / 圣殿巡礼 … (12 个) |

同一工具跨集换皮 (时间筛网≠要事筛网), 隐喻锚质量逐集抽签; 道具生命周期
(五件工具书级弧线) 没有稳定的世界 counterpart — **工具宇宙的脊柱断在立意层源头**。

**② 切场 LLM 与稿件结构脱钩**: plan_arcs 每集全量 LLM 切场是单集最大的一次
LLM 调用; 而文稿【段落标签】自带秒级时间标注, ep2 标签切出 7 块与现有 A1-A6
粒度几乎一致 — 切场答案本来就印在稿纸上。寄存器逐镜钉标后, 弧的负载已大降
(visual_world 分组 + fa 节奏容器 + 页面分组), 更不需要 LLM 自由发挥。

## 十一、世界库升书级 (①)

### 11.1 schema: 圣经扩 `world.concept_worlds` (道层 productize 最小切片)

```json
"world": {
  "exists": ["现代化开放式办公室", "…"],
  "concept_worlds": [
    {"name": "时间筛网",
     "visual": "多层金属筛网，粗筛留大石、细筛漏沙粒",
     "concept": "删减过滤",
     "tool_ref": "Focus_Block",
     "quota": "主打世界, 全书≤2集"}
  ]
}
```

- 生成时机: 圣经生成时 (艺术圣经页), 喂 L0/总纲 + 道具表 + 樊登稿气质 —
  **书级一次生成, 与圣经同锁** (复用现有"圣经复用·书级锁定"机制, force 才重掷)
- 现有书迁移: 一次性收割脚本 — 并集各集 world_library, LLM 去重合并一版
  (时间筛网/要事筛网→一条), **人审后落圣经**
- `registers.world_map` 改读顺序: 圣经 concept_worlds → 退化 ep world_library
  (迁移期兼容, 全量收割后删退路)

### 11.2 立意层每集只做"选用"

- 每弧 `visual_world` **只准从注册表选** (LLM 挑选, 不再造世界)
- 立意 LLM 从"切场+定隐喻+建世界库"瘦身为一小调用/集: 标签弧 + 每弧
  选世界 + 一句隐喻定稿; `concept_only` 立意人闸保留 (立意.md 人工确认)
- `characters[].role` 入 schema (`author|host|avatar|case`): registers.py 的
  作者判定从"引用句实证推断"升级为读 role — 实证推断降级为无 role 旧书的兜底
- `identity.register_mix_target` 书级配比 (如 隐喻60:痛点10:案例15) 入 schema,
  法层输入下发 + 密度闸按书校准

### 11.3 校验新增

| 闸 | 规则 |
|---|---|
| 世界注册 | 弧 visual_world ∉ concept_worlds → WARN |
| 跨集轮换 | 同世界相邻两集复用 → WARN; 单世界全书 >quota → WARN |
| 配比漂移 | 实得寄存器分布 vs mix_target 偏差 >20% → WARN |

## 十二、标签切场 (②): 立意 LLM 退役大半

### 12.1 规层新函数 `arcs_from_labels(script_text) -> arcs`

- 解析【…】标签: 兼容两种形态 — `【0-28 秒｜钩子】`(秒｜名) 与
  `【钩子】`/`【核心概念拆解（一）｜撞墙测试】`(名｜注, 以首段是否匹配
