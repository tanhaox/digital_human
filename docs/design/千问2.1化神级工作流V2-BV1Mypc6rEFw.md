## skill vs 提示词 界定 (UP 主原话, 值得记录)

- 完善描述只改单词 → **提示词**; 一套规则交给 LLM 去完善提示词 → **skill**
- skill ≈ 提示词域的**风格 LoRA** (6:56-7:01)
- 文本框管提示词本身; 反推节点管处理规则; 换千问 3.0 只需维护新 skill → 反推节点自适应 (6:00-6:15)
