# 合规统一词库 · 全系统禁用词入口

> 2026-08-22 建立。**唯一事实源 → 全系统赋能**：拆书/新闻线/未来衍生系统共用一套禁用词，加词只改一处。
> 关联：`docs/design/合规审查Pass-设计方案.md`（合规 Pass 方案）、`docs/design/蒸馏产物schema设计.md`（拆书 L0）。

---

## 1. 架构

```
config/compliance_common.json（唯一事实源：6 类禁用词 + 替换建议）
  └─ app/services/compliance.py（统一入口：load_common_rules / build_redline_prompt / check_text）
       ├─ 拆书 facing-units（源头注入，生成时规避）
       ├─ 拆书逐集 GateB（硬约束 1~10 + 统一限流词）
       ├─ 新闻线洗稿（llm_service._load_prompt_template 全局注入）
       └─ 未来系统 → 直接 import compliance，禁用词自动赋能
```

核心原则：**去掉"绝对化"（最/唯一/顶级）、"医疗化"（治愈/治疗/根治）、"承诺性"（保证/100%有效），用"个人感受+参考建议"的温和表达最安全。**

## 2. 6 类禁用词（categories）

| 类 | 关键词（节选） | 替换 |
|---|---|---|
| `absolute_claims` | 最/唯一/顶级/天花板/史上最强/独一无二/全网最低 | 值得一读 / 口碑很好 / 独具特色 / 质量很高 |
| `healing_medical` | 疗愈/治疗/治愈/根治/心理诊疗/消炎/增强免疫力/防癌 | 觉察 / 梳理 / 看见 / 舒缓 |
| `guarantee_promise` | 保证有效/100%有效/彻底解决/脱胎换骨/一次见效/无效退款 | 或许有帮助 / 值得试试 / 效果因人而异 |
| `superstition` | 好运/辟邪/转运/旺运/招财/化解小人 | 讲书不承诺运势 |
| `finance_promise` | 赚钱/稳赚/必涨/暴富/抄底/高收益/理财导师 | 启发财富思维 / 不构成投资建议 |
| `external_link` | 微信/VX/公众号/二维码/私信我/完整版在xx | 不做站外引流 |

## 3. 统一入口 API（app/services/compliance.py）

- `load_common_rules()` — 读词库（带缓存）
- `build_redline_prompt(categories=None)` — 组装成**生成提示词注入块**（源头规避，LLM 生成时就避开）
- `check_text(text, categories=None)` — **生成后检测**兜底，返回命中词列表

## 4. 各产线接入

| 产线 | 接入点 | 机制 |
|---|---|---|
| **拆书 facing-units** | `facing.py` _run_one（units 时） | 源头注入 build_redline_prompt() |
| **拆书逐集** | `orchestrator.py` GateB | 硬约束 1~10（书规则）+ 统一限流词 |
| **新闻线洗稿** | `llm_service.py` _load_prompt_template | 模板加载后追加统一限流词（laotan-tech/geo 自动带）|
| **未来系统** | import compliance | 自动赋能（源头规避 + 检查）|

## 5. 加词流程

**加新禁用词 → 只改 `config/compliance_common.json` 一个文件** → 拆书/新闻线/未来系统全部自动生效（LLM 生成时规避 + 检查兜底）。

## 6. 双保险策略

1. **源头**（生成提示词注入）：facing-units / 逐集 / 洗稿模板 —— LLM 生成时就规避
2. **检查**（生成后）：GateB 硬约束 + compliance.check_text —— 命中兜底
