## 1. 架构

> **1019 观念修正 (用户令)**: LLM 一对一比抖音公开传播松 — **prompt 注入只算减量辅助, 出口确定性替换是唯一安全边界**。

```
config/compliance_common.json（唯一事实源：6 类禁用词 + 替换建议 + substitutes 四表）
  └─ app/services/compliance.py（统一入口：load_common_rules / build_redline_prompt /
        check_text / substitute_text）
       ├─ 拆书 facing-units / 逐集 / 新闻线洗稿（源头注入 = 减量辅助）
       ├─ 【主闸】substitute_text() — 拆书逐集生稿落盘口（episode_gen, 终检前）
       ├─ 【主闸】substitute_text() — 动画字幕轨人工花字口（anim_service.update_text_layer）
       └─ 未来系统 → 直接 import compliance，禁用词自动赋能
```

核心原则：**去掉"绝对化"（最/唯一/顶级）、"医疗化"（治愈/治疗/根治）、"承诺性"（保证/100%有效），用"个人感受+参考建议"的温和表达最安全。**

## 1.5 substitutes 四表（1019 抖音字幕限流词, 出口确定性替换）

| 表 | 内容 | 例 |
|---|---|---|
| `platform` | 平台名缓冲词 15（案例提及语境，非导流） | 微信=绿泡泡 / 小红书=小红薯 / B站=小破站 / 拼多多=拼夕夕 / 字节=某互联网巨头 |
| `violence_phrase` | 暴力组合词书面化 21 | 杀死=遇害 / 尸体=遗体 / 自杀=轻生 / 毒品=违禁药物 / 赌博=赌局 |
| `single` | 孤立单字万金油 5 | 死=离世 / 杀=行凶 / 血=鲜血 / 枪=枪支 |
| `protect` | 含敏感字但整词安全 9（替换单字前先占位保护） | 血压 / 心血 / 血本无归 / 杀菌 / 死板 |

三段式防误伤：protect 占位（私有区字符）→ 平台/组合词按长度降序替换 → 剩余孤立单字兜底。
裁量：裸词"头条"多新闻头版义不处理（只禁全词"今日头条"）；抖音平台自指豁免；Gate0.5 书级长句映射不共表（粒度不同源）。

## 2. 6 类禁用词（categories）

| 类 | 关键词（节选） | 替换 |
|---|---|---|
| `absolute_claims` | 最/唯一/顶级/天花板/史上最强/独一无二/全网最低 | 值得一读 / 口碑很好 / 独具特色 / 质量很高 |
| `healing_medical` | 疗愈/治疗/治愈/根治/心理诊疗/消炎/增强免疫力/防癌 | 觉察 / 梳理 / 看见 / 舒缓 |
| `guarantee_promise` | 保证有效/100%有效/彻底解决/脱胎换骨/一次见效/无效退款 | 或许有帮助 / 值得试试 / 效果因人而异 |
| `superstition` | 好运/辟邪/转运/旺运/招财/化解小人 | 讲书不承诺运势 |
| `finance_promise` | 赚钱/稳赚/必涨/暴富/抄底/高收益/理财导师 | 启发财富思维 / 不构成投资建议 |
| `external_link` | 微信/VX/公众号/二维码/私信我/完整版在xx | 不做站外引流 |

## 3. 统一入口 API（app/services/compliance.py）

- `load_common_rules()` — 读词库（带缓存）
- `build_redline_prompt(categories=None)` — 组装成**生成提示词注入块**（源头规避，减量辅助；1019 起尾部附缓冲词/书面语行）
- `check_text(text, categories=None)` — 检测命中词列表（**当前零调用方** — 检测职能已并入 substitute_text 出口闭环，保留备用）
- `substitute_text(text)` — **【主闸】** 出口确定性替换，返回 (替换后文本, 命中词表)；上游凭命中表记日志，不阻断

## 4. 各产线接入

| 产线 | 接入点 | 机制 |
|---|---|---|
| **拆书 facing-units** | `facing.py` _run_one（units 时） | 源头注入 build_redline_prompt() |
| **拆书逐集** | `episode_gen.py` 终检 snapshot 前 | 源头注入 + **主闸 substitute_text()（静默替换+日志）** |
| **动画字幕轨** | `anim_service.update_text_layer` | **主闸 substitute_text()（人工花字与生稿同标准）** |
| **新闻线洗稿** | `llm_service.py` _load_prompt_template | 模板加载后追加统一限流词（laotan-tech/geo 自动带）|
| **未来系统** | import compliance | 自动赋能（源头减量 + 出口替换）|

## 5. 加词流程

**加新禁用词/替换词 → 只改 `config/compliance_common.json` 一个文件** → 拆书/新闻线/未来系统全部自动生效。画面层禁区另走 `config/compliance_visual.json`（1019 v2.1: 12 类 181 禁词 + 叙事替身）。

## 6. 双保险策略（1019 修正）

1. **源头减量**（生成提示词注入）：facing-units / 逐集 / 洗稿模板 —— LLM 生成时就倾向规避；**不担安全责任**
2. **出口主闸**（生成后确定性替换）：episode_gen 落盘口 + 字幕轨口 —— substitute_text() 静默替换+命中日志；**唯一安全边界**
3. **观察固化**：跑两周按命中日志扩充词表（backlog ID-119，窗口至 2026-11-02）
