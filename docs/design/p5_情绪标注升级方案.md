## 一、核心架构: 三层分工

```
P1(标意图) → P2(标意图) → P3(标意图)   ← 轻量情绪意图, 供 P4 参考
  ↓ 意图随稿传给 P4
P4(纯精修) ← 回归现状, 不标情绪, 保留全部铁律(信息守恒/数字锚定/开头锁定/多音字/主观句中立化)
  ↓ 定稿 (文字稳定)
P5(标情绪, 新增) ← 拿统一字典, 对定稿挨段标「段落 + 情绪 + 强度档(弱/中/强)」→ 唯一下游标注源
```

- **P1-P3 标意图**: 各层句式选择本身就是情绪决策, 轻量标注(一段一个意图标签), 供 P4 精修时有上下文
- **P4 纯精修**: 不承担情绪标注, 避免双任务过载; 现有铁律全部保留
- **P5 标情绪**: 新增工序, 输入 P4 定稿, 只读不写文字, 输出结构化标注; 可复跑(调情绪只重跑 P5)

## 二、统一情绪字典 (各链路共享)

| 情绪 | 8维向量 | 情绪基准α | 强度档(弱/中/强) | 视觉意图 | 画面搜索词 |
|---|---|---|---|---|---|
| calm | 平静主导 | 0.4 | ×0.7/×1.0/×1.3 | 沉稳/冷峻 | 城市/建筑/街道 |
| serious | 愤怒0.5 | 0.4 | ×0.7/×1.0/×1.3 | 紧张/严肃 | 会议/芯片/机房 |
| angry | 愤怒0.8 | 0.4 | ... | 张力/对立 | 冲突/抗议/数据 |
| surprised | 惊讶0.7 | 0.6 | ... | 爆点/冲击 | 特写/震撼画面 |
| happy | 高兴0.7 | 0.6 | ... | 升华/上扬 | 光/成果/前景 |
| ... | ... | ... | ... | ... | ... |

**关键设计**:
- P4/P5 只填「情绪标签 + 强度档(弱/中/强)」, **不填 TTS 参数**
- α = 情绪基准α × 强度档系数 × 音色系数 (音色只是参考坐标, 系统映射)
- 情绪集定死白名单 (基于实验: 平静/严肃/愤怒/惊讶/高兴 + 必要扩展)
- 各链路查字典: TTS 查向量+α, _intent.py 查视觉意图, 画面搜索查关键词

## 七、α 坡度验证与修复 (2026-08-13, 实验定稿)

### 发现: 段落情绪突变 = 断层 (不可用)

- 切情绪类型(惊讶→平静)段级拼接 → 语气断层/挫裂感 (e2e_full / e2e_modules 验证失败)
- indexTTS 一次合成一个情绪参数, 段间直接切 = 突变, 无渐变

### 定稿: 同一情绪基调 + α 强度坡度

- **不切情绪类型**; 整篇/大段一个情绪基调
- **α 坡度**: 0.30~0.60, 0.05 步进, 平滑升降 (0.6→0.55→...→0.30→...→0.6)
- **去掉"平静"** (2026-08-13 用户验证): 平淡叙述会让人划走 → 低强度段(叙述/身份)用 **惊讶/1(0.3)** 替代. 惊讶 0.3 不拖慢语速(惊讶向量非低落).
- **P5 强度档 1-7**: `α = 0.30 + (档-1)×0.05` (1→0.30 ... 7→0.60), 相邻段差 ≤2 档 (坡度平滑), 主体惊讶低档, 关键段 4-7 档
- **语速维度: 不接入** (2026-08-13 用户决定) — atempo 变速段内部有爆破音 artifact("噗"), 且 α 坡度已够"有情绪"

### 修复: 句尾破音 (每段"噗")

- 根因: `_tts_text` 把**句号后的 || 清掉** (`句1。||句2。`→`句1。句2。`), 气口丢失 → 句尾破音
- 修复: `_tts_text` 加 `keep_breaks` 参数, indextts 路径**保留 ||** (indexTTS 识别为停顿, 实测 +0.6s)

### 修复: 段拼接破音 (段尾音+段首紧贴)

- 根因: 直接 concat 时段尾音与下段起音紧贴 → 拼接处"噗"
- 修复: `_concat_wavs_with_fade` — 段尾淡出(st=段尾, **afade out 必须指定 st**, 默认 st=0 整段静音!) + 段首淡入, **无静音 gap** (用户验证 gap=0 停顿最舒服)
