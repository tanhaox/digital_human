# 动态先行派生架构 — 设计方案 v0

## 状态

**设计中**（2026-10-21 用户令：先设计流程/需求/产出/安全闸，**不动代码**；A+B 不做；
产线当前虽不好但基本能用）。旧资产（OCR/VLM/负词/圣经/角色台等）一律**改造复用，
不舍弃**。

## 动机

- s21 实锤（1021）：并行产出两字段脱锚——画面句无马、动效凭空造马；文字事件泄进
  motion 散文（h3_text_event 空字段）；且 fallback 产物不过闸漏网。
- 结构性根因：当前 writer 一次并行产五件套，画面句是宿主、动效是配角 → 动效模板化
  （尘土浮动+轻微推近）、文字落点留白靠自觉常漏、脱锚只能靠闸事后抓。
- 派生关系（K2 = freeze(H3)）在结构上消灭脱锚：动态说有马→首帧画马→马动合法；
  文字事件落点在派生时自动预留。

## 目标架构（六层）

```
L1 立意规划 (不变: 每场一世界+隐喻+轮换宪法+轮换自修+人闸)
     ↓ 场口播 + 视觉世界实体体系
L2 动态设计层 (新·源头)
     每镜动态提示词 = 过程叙事(谁做什么) + 秒级事件表 + 文字事件 + 运镜
     ↓ 派生: t=0 冻结 + 细腻化 + 圣经 + look 串
L3 首帧派生层 (新)
     keyframe 串 = 构图/光色/实体布局/文字落点留白 (比 L2 更细腻, 遵守圣经)
     ↓
L4 K2 生图 (复用+挂点改造: 组装串/翻译/守门 OCR+VLM 全保留)
     ↓ 首帧
L5 H3 视频 (复用+改造: 直接吃 L2 动态提示词) + h3_text_event 渲字
     ↓
L6 后处理链 (不变: erase / text_pass / 出口闸 / 发布)
```

## 三线进入方式（完整版关切）

| 线 | 进法 | 复用件 |
|---|---|---|
| **人物图** | L2 只写**行为**（谁做什么，禁外貌词）；L3 派生时注入 look 锁定串（服饰/脸/道具）；L4 组装复用现有角色纪律注入 | 角色台/定妆照/圣经 characters/_scene_eff 角色段 |
| **规划** | L1 世界+隐喻喂 L2（动态必须在世界的实体体系内展开）；法层脚本（镜头序/光影/连续性）改挂 L2——连续性从"画面连续"重定义为"动作连续" | 立意层全套（审计/自修/人闸）、shooting_script 改锚 |
| **负词** | 三族（系统级/书级 neg_learn/判决回流）**前置到 L2**（防动态设计出"红旗飘扬"级违禁动作）+ L3/L4 通道照旧；判决回流双挂（L2 剔词 + L4 剔子句） | neg_learn 回路/词库全复用，加视频侧判决来源 |

## 迁移路径（不动产线的验证序）

1. **影子试点**：1-2 镜离线手工走 L2→L3→L4→L5（跑 ComfyUI 出首帧+视频），
   与现有同内容镜对比，图说话
2. **单场旁路**：产线旁路跑一个场（不动正式链）
3. **单集试点** → 4. **全量切换**；每步设回滚条件（质量/成本指标不达标即停）
5. 老五件套链保留为永久降级路径

## 开放问题（设计期待决）

- 单镜 LLM 成本 ×2（两级调用）vs 质量收益——影子试点量化
- H3 视频模型对长动态提示词的服从度（现 H3 壳有缓速对冲机制，需实测）
- L2 输出 schema：结构化秒级事件表 vs 散文+事件字段混合
- 圣经注入粒度：L2 防材质违例（动态设计"半透明皮肤人"）vs 仅 L3 渲染词
- 老链退役节奏（先并行共存，后收编）
