# 设计-拆书稿多步生成管线 (0908 用户架构令)

> 状态: **设计定稿待实施** — 源自 0908 与用户的两轮架构讨论; 新闻线「直接生成→多步引导」同源经验。
> 关联: 已归档: ../archive/进行中-20260908-拆书总纲方向修正.md (内容层方向, 后被 0913 拆解三步调度取代); 静读书**不迁移** (维持单步, 隔离铁律)。

## 一、原则 (用户令)

1. **LLM 注意力有限, 多身份叠加互相稀释** — 禁"一个提示词升级所有"; 每步只对一个维度做设计。
2. **每层 = 厚专家人格, 不是功能模块** — 薄身份浅激活; 高规格身份 (资历锚+决策域+自验收+红线) 深激活, 才出精品。
3. 步间产物结构化 (骨架 JSON) → 可确定性校验, 不靠提示词求 LLM 守规则。

## 一点五、Gate 0.5 合规过滤层 (0908 用户令: 只把合规的往 Step1 传导, 阻断层层传递)

```
L0 料池 ── Gate 0.5 确定性过滤 (代码层) ──→ Step 1 选料池
              green 料: 原文直入
              yellow 料: Gate A 安全版替换后入
              red 料: 出局; 重要案例降级转述入 (不可转述→标注"有料不可用", 结构避开)
```

- **过滤是代码不是提示词**: 组装 Step 1 user prompt 时做替换/剔除 — 确定性、零注意力、导演根本见不到敏感原文
- **改写源头做一次** (Gate A 蒸馏审计已产敏感→安全映射), 下游永远只见安全版, 不层层重复判断
- **待结构化**: Gate A 备注现为文本 → 解析/重产为 `{orig, safe_version, action}` JSON 映射表 (distiller 升级)
- **现存漏洞同步堵**: quotes.py 选句 (B-Q1 字幕上屏) 也吃 L0 池未挂合规 — 同走此过滤
- Step 3 审稿人含合规复检 = 第三道保险 (兜底非主审)
- 既有资产: Gate 0 书级定档 (assess_book_risk) / Gate A 蒸馏审计 / Gate B 稿件注入 / compliance_common.json 禁用词 — 位置不变, 0.5 是它们与 Step 1 之间的确定性阀门

## 二、三层流水线

```
书级 (已有): L0蒸馏 → facing三面 → 迁移视角 → 总纲(灵魂三问)
                                    ↓
Gate 0.5 合规过滤 (确定性阀门)
                                    ↓
Step 1 结构导演 (课程线总编剧): 路线图+书料 → 本集骨架 JSON
Step 2 讲述人 (老谭): 骨架 → 口播稿 (人设+词句约束)
Step 3 审稿人 (双率审片人): 稿 → 修订清单 → (不合格回 Step2 重写, ≤1轮)
```

### Step 1 结构导演 — 「课程线总编剧」
- 资历锚: 头部知识付费机构总编剧, 拆过 300 本、主导 50 个爆款系列, 完播率数据说话
- 决策域 (只此域):
  - 灵魂三问定位 (书的核心/帮谁/听的收益)
  - 书中论证选料与顺序 (≥60%), 集间边界 (正交+承接, 对照前集 coverage 防同义反复)
  - 迁移视角选择 (从「本书迁移视角」清单选 1-2/概念, 禁单一)
  - 培训三件套点位 (暂停练习=具体到业务账本 / 口诀≤14字 / 微行动5分钟)
  - ep1 特例: 卖书+导览 (概念一=系列导览, 概念二三=一口预演禁展开)
- 产物: 骨架 JSON {各段: 段职能/书料引用/视角/练习/口诀/微行动}
- 确定性校验 (代码层): 三件套齐备 / 书料占比(引用条数) / 视角分布 / 与前集 coverage 重叠度
- 红线: **写一句正文 = 失职**
- 落点: episode_gen 拆 `_gen_outline(db, book, ep) -> outline_json` (落 ep 级新列或 input_json)

### Step 2 讲述人 — 「老谭」(厚化现有 laotan-book 人设)
- laotan-book.txt **瘦身**: 只留人设/口吻/词句约束 (每句≤20字/金句独立成行/转场极简/比喻对应/过来人佐证)
- 增从属边界: 骨架怎么定就怎么讲, 可润语言无权改结构
- 结构性规则 (书主体占比/视角/三件套/ep1特例/同义反复) 全部迁去 Step 1 — 提示词不再堆叠
- 红线: 改结构决策 = 越权

### Step 3 审稿人 — 「双率审片人」
- 资历锚: 平台内容质检出身, 审过千条知识类视频, 只认数据不听情面
- 实测项: 书内容占比 / 视角分布 / 三件套齐备 / 同义反复 (vs 前集+集内) / 忠实性 (引用 vs L0) / 灵性金句锚定(已有)
- 产物: 修订清单 [{定位, 原因, 修法}] — 不改稿; 不合格回 Step2 带清单重写 (≤1 轮防循环)
- 红线: 自己动笔 = 立场污染

## 三、实施清单 (待排期)

0. Gate 0.5: distiller 合规备注结构化 (orig→safe 映射 JSON) + 选料组装器过滤函数 + quotes.py 挂接
1. episode_gen 拆三步 (`_gen_outline` / `_write_episode` / `_audit_episode`), 骨架落 Episode 新列 outline_json (JSON)
2. 三个专家提示词新建 (config/laotan_outline_director.txt / laotan_auditor.txt; 讲述人复用瘦身版 laotan-book.txt)
3. laotan-book.txt 瘦身迁移 (结构性规则迁 Step1; 瘦身期间单步模式保留可跑, 不空窗)
4. 骨架确定性校验 (代码层, 不依赖 LLM 自觉)
5. ep1 重生成用新管线首发验证 (vs 旧单步产物对拍)
6. 静读书零改动 (隔离铁律: 公用件副本化)

## 四、成本

每集 LLM ×2-3 (~5-10min/集, 原单步 2-5min); 拆书后台批量可接受。骨架 JSON 额外收益: 页单规划器未来可直接吃骨架 (金句/练习点位预知)。
