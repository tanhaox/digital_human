# 动画产线"道法"两层架构设计 v1 — 盘点与计划

> 2026-10-07 用户定稿方向: 道法术器四层, 现有术器, 补建道法。
> 每本书 = 一个电影IP(蝙蝠侠/超人/阿甘), 每一集 = 这个系列的一集。
> 目标: 每段文字像看电影一样有沉浸感(阿甘的羽毛串联多镜), TTS 是旁白感。

### 1.2 缺失清单

| # | 缺什么 | 属于哪层 | 影响 |
|---|---|---|---|
| 1 | 调性身份声明 | 道 | 全系列没有"这部片子是谁"的定义 |
| 2 | 视觉世界规则 | 道 | 不知道什么存在/什么不存在 |
| 3 | 光影哲学 | 道 | 每镜自由发挥光影, 无统一方案 |
| 4 | 色彩-情绪映射 | 道 | "焦虑=紫漩涡"还是"焦虑=深蓝阴影"没有定论 |
| 5 | 镜头哲学 | 道 | 机位/景别/构图没有约束 |
| 6 | 禁区清单 | 道 | 靠负面提示词打补丁, 不是源头规则 |
| 7 | **道具体系** | 道 | "时间管理=沙漏"这种核心概念↔视觉符号映射 |
| 8 | 字体/文字规范 | 道 | 大字卡风格每集可能不一致 |
| 9 | **镜头序设计** | 法 | 每场戏没有"远→中→近"的递进逻辑 |
| 10 | 光影方案(每场) | 法 | 每场的具体光源/方向/变化没有计划 |
| 11 | 色彩节奏(每集) | 法 | 情绪弧线↔色调变化没有映射 |
| 12 | 机位语法(每场) | 法 | 相邻镜的机位关系(左→右/仰→俯) |
| 13 | 连续性约束 | 法 | 人物位置/道具位置/视线匹配跨镜追踪 |
| 14 | 切镜/转场规则 | 法 | 什么时候切、怎么接、有没有 match cut |
| 15 | **旁白节奏同步** | 法 | 画面节奏与TTS旁白的节奏不匹配 |
| 16 | **系列视觉母题** | 道 | 阿甘的羽毛=贯穿全系列的视觉符号 |

## 三、法层设计: 视觉叙事总控 (Visual Narrative Controller)

### 3.1 定位

- 每集一份, 在"规划(立意闸)"阶段生成
- 输入: 道文档 + 本集稿件 + 音频manifest
- 输出: 本集的"拍摄许可证" (shooting permit)
- 导演LLM、增强器、K2、H3 都必须遵循

### 3.2 结构 (v1)

```json
{
  "ep_index": 2,
  "ep_title": "一次只做一件事",

    "opening": "快节奏钩子(0-28秒), 画面用快速切换",

```

### 3.3 生成方式

- 在现有"规划(立意闸)"阶段, 切场完成后、逐场分镜之前
- 输入: 道文档 + 切场结果(arcs) + 稿件
- LLM 生成"拍摄许可证"
- 人工审核(在立意.md中展示) → 确认后逐场分镜
- 导演LLM 在写 keyframe_zh 时, 必须引用法文档的 shot_sequence/lighting/continuity

### 3.4 与现有流程的整合

```
现有流程:
  规划(立意闸) → 切场 + 立意.md → 人工确认 → 分镜续跑 → K2 → H3 → 装配

改造后:
  规划(立意闸)
    ├─ ① 切场(不变)
    ├─ ② 立意.md(不变)
    ├─ ③ [新增] 视觉叙事总控生成 ← 输入: 道 + 切场 + 稿件
    │   → 输出: 拍摄许可证(镜头序/光影/色彩/连续性)
    ├─ ④ 人工确认(立意 + 拍摄许可证 一起审)
    └─ ⑤ 分镜续跑(导演LLM 按拍摄许可证写分镜)
         → keyframe_zh 必须遵循法文档的:
           shot_type / camera / lighting / color_mood / continuity
```

### 3.5 与增强器的整合

```
增强器 pass1(画面丰富度):
  现在: 自由发挥补光影/氛围
  改后: 必须按法文档的 lighting + color_mood 写, 不自由发挥

增强器 pass2(动画层):
  现在: 自由发挥写运动
  改后: 必须按法文档的 connect_to_next + continuity 写
```

## 四、道具体系 (道层的核心新增)

### 4.1 设计原则

每本书的核心概念, 对应一个**可画的实物道具**, 全系列贯穿:

| 书 | 概念 | 道具 | 何时首现 | 何时收束 |
|---|---|---|---|---|
| 卓有成效的管理者 | 时间管理 | 木制沙漏 | ep2 | ep6(金沙收束) |
| | 贡献导向 | 黄铜天平 | ep3 | |
| | 发挥长处 | 放大镜 | ep4 | |
| | 有效决策 | 航海罗盘 | ep5 | |
| | 整合行动 | 精装手册 | ep6 | |

### 4.2 道具的视觉母题作用

```
阿甘的羽毛 = 串联全片的开场和结尾

我们的金沙 = 
  ep2 开场: 从木桶裂缝流出(时间在流失)
  ep3 中段: 沙漏中流过(时间被记录)
  ep4 砍除: 金沙汇成一股(时间被整合)
  ep5 决策: 金沙落入罗盘中心(时间用于决策)
  ep6 收束: 金沙装订成册(时间成为系统)
  
观众看到金沙就知道在讲时间, 不需要字幕解释
```

### 4.3 与现有 prop_lock 的关系

```
现有 prop_lock: 每场独立定义道具, 跨场可能不一致
道具体系(道): 全系列统一道具, prop_lock 只是引用道的道具定义

改造:
  prop_lock 写 "沙漏" → 系统自动注入道层定义:
  "木制沙漏, 高40cm, 上下玻璃腔, 框架为深棕实木, 
   沙粒为金色, 光线下微微闪光"
```

## 五、旁白感(TTS)的配合

### 5.1 现状 vs 目标

```
现状: TTS 念稿 = 朗读感(每个字力度一样)
目标: TTS 念稿 = 旁白感(有节奏、有留白、有情绪起伏)

改造不在 TTS 引擎, 在两个上游:
  ① 稿件写作: 段落间留气口(已有 拍点标记 -Xs-)
  ② 法层: 画面节奏与旁白节奏同步
     旁白说"1966年" → 画面切到年代感的场景
     旁白停顿(气口) → 画面给远景/空镜
```

### 5.2 法层的旁白同步

```json
"narration_sync": [
  {"text_segment": "今天我们要讲的这本书", "visual": "书封面特写", "rhythm": "开场"},
  {"text_segment": "管理学的奠基之作", "visual": "书房全景, 书桌上摆着这本书", "rhythm": "定场"},
  {"text_segment": "彼得·德鲁克", "visual": "德鲁克角色卡入画", "rhythm": "人物引入"},
  {"text_segment": "1966年", "visual": "年代感场景(老式打字机/黑白电视)", "rhythm": "时间锚点"},
  {"text_segment": "(气口 0.8s)", "visual": "窗光空镜", "rhythm": "留白"}
]
```

## 七、验证标准

改造后 ep2 应达到:

| 指标 | 现有 | 目标 |
|---|---|---|
| 相邻镜机位连贯 | 无约束 | 有递进逻辑(远→中→近) |
| 场内光影一致 | 每镜自由发挥 | 按法文档方案, 同场同光 |
| 色彩情绪映射 | 随机 | 焦虑=深蓝, 专注=暖黄(道层定义) |
| 道具跨集一致 | prop_lock 可能不一致 | 道层统一, 全系列同一沙漏 |
| 视觉母题 | 无 | 金沙贯穿(阿甘羽毛) |
| 旁白画面同步 | 无 | 旁白说1966→画面年代感 |
| 整体沉浸感 | 独立画面拼接 | 镜头有语法, 叙事有节奏 |
