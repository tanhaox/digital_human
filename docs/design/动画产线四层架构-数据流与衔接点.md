## 四层架构总图

│  ↓ keyframe_zh 分发到两个分支                        │
├────────────────────┬────────────────────────────────┤

│         ↓         │              ↓                  │
├────────────────────┴────────────────────────────────┤

│  ┌───────────────────────────────────────────┐      │
│  │ INPUT:                                    │      │
│  │   ① K2 的 PNG → first_frame (i2v锚定)   │      │
│  │   ② opening_desc → "首帧该长这样"        │      │
│  │   ③ beats.motion → "动画该怎么动"        │      │

## 五个衔接点 (手递手)

| # | 衔接 | 传什么 | 断了会怎样 | 当前状态 |
|---|---|---|---|---|
| 1 | 圣经→导演 | bible_block(风格/色板/质感/铁律) | 导演写的场景跟圣经风格不一致 | ✓ 已修(圣经改为明亮卡通) |
| 2 | 导演→K2 | keyframe_zh(场景描述) + style head/tail + 负面 | K2 渲染的不是导演想的 | ✓ 已修(容量红线+渲染锚+负面) |
| 3 | 导演→H3 | opening_desc(英文场景) + beats(运动) | H3 动画的场景 ≠ K2 画的 | ✓ 已修(中英同步规则八) |
| 4 | K2→H3 | PNG 图(首帧视觉) | H3 视频第一帧 ≠ K2 图 | ✓ 已修(style 统一 page="k2") |
| 5 | K2→H3 | 光影(从 PNG 继承) | H3 光影跳变 | ✓ 已修(负面提示词 + style统一) |

## 已识别的改进空间 (用户 1007 提出)

| # | 问题 | 现状 | 改进方向 |
|---|---|---|---|
| 1 | **圣经无 lighting_plan** | 光影全靠导演 LLM 每镜自由发挥 | 圣经加全局光方案(光源/方向/时段) |
| 2 | **H3 无光影动画** | beats.motion 只写运动不写光影变化; 视频光影=K2首帧光影冻结5秒 | beats 里补光影微动("阳光缓慢移动") |
| 3 | **18层注入复杂度** | 圣经+风格库+导演+增强器+渲染锚+负面... 修一层漏一层 | 精简层数或统一注入源 |
| 4 | **中英双语双份维护** | keyframe_zh(中文,K2用) + opening_desc(英文,H3用) 需人工同步 | 单一事实源或自动同步 |
| 5 | **page_overrides 三层隔离** | base/k2/character 各自覆写 head/tail/LoRA/h3_style | 需确认覆盖完整、无遗漏 |

## 关键配置 (2026-10-07 定稿)

| 配置 | 值 | 说明 |
|---|---|---|
| K2 cfg | 2.0 | 负面提示词通道生效 |
| K2 负面 | blue/glowing/transparent skin, black/empty background, multiple people/crowd/child, deformed, text, watermark | 治蓝皮肤+黑虚空+多人幻觉 |
| K2 LoRA | 无 (page_overrides.k2.lora=null) | 治抽象流体渲染 |
| H3 LoRA | 无 (同上) | 与 K2 一致 |
| H3 style | page="k2" → "3D cartoon animation, bright saturated colors" | 与 K2 出图风格统一 |
| 镜间 free | H3 run_batch 每镜完成后 free_memory() | 防碎片爬行 (4x提速) |
| 圣经 style_prefix | "3D cartoon animation style, solid matte cartoon skin, bright saturated colors" | 源头统一 |
| 圣经色板基底 | "暖白" (不再是"深空黑") | 源头改色 |
