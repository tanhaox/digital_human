# 规层设计: 平台合规 — 一本字典五道闸 (零 LLM, 零 token)

> 2026-10-08 用户定稿方向。核心关切: 大字典走 LLM 会耗费大量 token。
> 解法: **数据集中(一本字典), 执法分散(五道闸), 前三道零成本, 后两道有 VLM 但可控**。

---

## 一、设计原则

```
❌ 错误做法: 把 100+ 违禁词塞进每个 LLM prompt
   → 浪费 token (100词 × 每镜 × 每层 = 大量)
   → 稀释注意力 (更多规则 = 更低遵守率)
   → 反向诱导 (LLM 看到"国旗"可能反而画出国旗)

✓ 正确做法: 一本字典 + 五道确定性闸
   → 前三道(道法术): 字符串匹配, 零 token, 微秒级
   → 后两道(器/视频): VLM 检查图片/视频, 不查文本
   → LLM prompt 不注入违禁词清单 (只注入 top 10 高频词到负面提示词)
```

## 四、成本汇总

| 闸 | 方法 | Token 成本 | 时间成本 | 需要新代码 |
|---|---|---|---|---|
| ① 道 | 字符串拼接 | 0 | ~0ms | 补 forbidden 字段 |
| ② 法 | 正则匹配 | 0 | ~1ms | validate +3行 |
| ③ 术 | 正则匹配 | 0 | ~1ms | fill后扫描 +5行 |
| ④a 负面 | 模板常量 | 0 | 0 | negative prompt +1行 |
| ④b VLM图 | VLM后检 | ~100 tok/图 | ~1s/图 | 扩展 _HARD_VIOLATIONS |
| ⑤ VLM视频 | VLM帧检 | ~300 tok/视频 | ~3s/视频 | 扩展 video_qc prompt |
| **合计** | | **~400 tok/镜** | **~4s/镜** | **~20行新代码** |

对比方案 A(全走 LLM):
- 每镜注入100+违禁词到prompt → ~500 extra tokens/镜
- 45镜/集 × 7集 = 315镜 → ~157,500 extra tokens/书
- 且注意力稀释 → 遵守率下降

本方案每集仅 VLM 检查花费 ~18,000 tokens (45镜 × 400), 且不影响 LLM 创作质量。

## 五、与道法术器的关系

```
规 不是道法术器的第五层, 是横切关注点 (cross-cutting concern):

  道 → 产出世界规则 (含风格禁区 + 合并平台禁区)
  法 → 产出镜头脚本 (出口被规扫描)
  术 → 产出创意槽   (出口被规扫描)
  器 → 渲染         (负面提示词 + VLM 后检)

  规 = "什么不能做" (平台红线, 跨书统一, 走确定性检查)
  道法术器 = "怎么创作" (书个性, 走 LLM + 参数)
  两者正交, 互不干扰
```
