## 一、角色生成归角色设计台 (用户裁定)

**病象**: 角色卡突然手动 — 圣经生成器提示词字段描述里有 characters 角色锁定卡, 但
"输出严格 JSON"契约只列 6 字段漏了 characters → LLM 守契约永不输出 → 每本书角色卡
必空 (《定位》5 卡=生产期手工攒, 掩盖断链)。同族病=宪法文本与结构契约打架。

**架构**: 圣经页只管视觉身份 (风格/色板/质感); 角色台管 cast。characters 字段仍是
**存储** (角色台编辑器回写圣经 json), 只是**生成**换了地方。

**derive_characters 喂料** (用户判词"最好围绕每集稿件"): 各集 roadmap 贯穿人物
(硬覆盖) + 各集成稿节选 (空气真相, 有则喂) + 故事库节选 (服饰道具细节)。L0/樊登
全书池被否 — 麦克纳马拉×7/丘吉尔×5 稿件零提及实锤。

**覆盖校验是确定性代码不是 LLM 自觉**: 剥括号注释+剥"某公司/某"前缀+按顿号切人名,
逐人比对卡 name/role (全名或名首二字命中), 缺口随响应回前端 toast。
笔误教训: 括号注释不先剥会切出"反而成就盖世奇才）"假人名。

## 二、定妆照风格分叉根治 (铬人四连败 → 白底令 → LoRA 摘除)

**病象**: 定妆照渲出全息液态铬人 (皮肤头发服装铬面虹彩=0925 琉璃人禁区) vs 圣经试渲
哑光黏土 3D 卡通 — 同配方两幅画风。

**四连败战报** (先一张循环×4, VLM 逐掷眼验): 材质铁律入 _scene(LoRA 0.65→0.35) 一掷
哑光=种子运气 → 白底尾(0.35) 铬人复辟 → LoRA 0.15+头部换哑光词 铬人照旧且 **look
遵从度也崩** (老者画成卡通男孩举怀表, VLM prop_mismatch=遵从度崩的可观测信号)。

**定案**: 纹理型风格 LoRA 在定妆照短句人物提示词上吞掉整个生成, 文字锚任何强度都
压不住 (叙事长句能稀释同 LoRA=圣经试渲哑光的原因; K2 无负面通道 cfg=1)。

**终案 `_char_recipe` 三件**: ①风格 LoRA 整体摘除 (空 lora→跳节点; 家族纹理归正式
分镜全配方, 定妆照职责=look 复现人物锚) ②头部纹理词确定性消毒 (液态金属→哑光黏土/
霓虹→明亮/流体→干净, "3D卡通人物"形态轴保留) ③尾=纯白无缝背景 (**用户令"给最简单
的白背景, 以后也是如此"** — 定妆照=人物参考图, 背景永久最简纯白)。

第 4 掷 VLM 四判全绿: 纯白无地面 / 哑光黏土无铬虹 / look 原样落地 / 全身 3D 立绘。

**流程令 (用户令"生成一张, 对了再批量")**: designAll 无定妆照时只试渲第一张,
有了再点=补缺批量 (render_missing 首张不重渲)。
