## 二、三层画面心智模型（PPT 三层，宪法级定稿）

用户四轮复述确认的最终形态：

| 层 | 载体 | 职责 | 铁律 |
|---|---|---|---|
| **第1层 背景图** | K2 首帧 | 代入感 | 具象纪录片式（真实年代/地点/场景，弃抽象隐喻）；**全灭字**（AI 生图必乱码）；**视角生图时锁死**；**信息完备**（动画要用的元素/接触关系全部在首帧就位——"双手已扶墙"） |
| **第2层 动画层** | H3 | 沉浸感 | 环境物品原地动（车/人/烟/旗/光/水）；**运镜白名单只有 固定/极轻微推拉**（横移跟拍摇全禁）；**特效时序：先移动→静止→再触发**（绝不同时）；大面积重绘禁（换装/变形→光效+色彩反转，几何大改靠切镜） |
| **第3层 文字特效层** | H3 入画 + 剪映后期 | 内容主角 | 关键词**中文短词 2-4 字**优先（标准/搬运工/美剧之王）；数字/年份/标志保持数字拉丁（365/1972/90%/HBO）；**每镜一种艺术字体**（书法/手写/复古装饰/描边立体，**黑体禁用**）；字色融场景色板；避让主体不压字；随口播节奏出场；中文长句走 text_layer 后期 |

**切分标准**：场 = 叙事段落（不按时长算术）；镜 = 画面单元（句子是参考不是法律）；每场一组（组退化为容器）。

**正反教材**（进纪律）：✅ 巨大的暖琥珀金艺术字"HBO"在他头顶怯生生地亮起闪烁；❌ 红色"LIVE #1"平淡字体=垮、横移+边走边变身=抖废片、墙从远处移到人身上=新接触大重绘。

**人物规范**：卡通脸全放开（含历史名人——强风格化变形，靠标志特征识别，不做写实肖像）；双约跨镜一致；表情特写/双人表情反差是高级武器。

**系列风格锁**：一书一系列。ep2+ 整集规划自动注入 ep1 当前 doc 锚（`director2._series_lock_block`：配方/画面策略/场叙事/场景语言/文字风格/角色跨集一致）；磨合 ep1 即刷新锚；第1集未规划=新书自由。

## 三、基建修复（本夜排障全记录）

### H3 花屏根治（z21）
- 根因：H3 模型栈 51GB > 物理内存 47.6GB，ComfyUI 默认 pinned-RAM 卸载超卖 → 硬错（`HostBuffer.read_file_slice failed`, WinError 1450）或**静默脏权重→噪声废片**（码率 10-12Mbps vs 健康 1-2Mbps——**码率即废片试纸**）
- 修：ComfyUI 启动加 **`--fast-disk`**（磁盘页缓存背书，为模型>内存的机器设计）双处生效（`_specs.py` + `run_nvidia_gpu.bat`）；**相位边界卫生**（每 GPU 批前 POST /free 卸上一相位模型栈）

### LLM 供应链（z22/z24）
- 事故：kimi 周配额尽（403）+ deepseek 队列饱和（HTTP 200 + 错误体 "900-second timeout"，无 choices → KeyError）
- 修：**三级链 kimi → qwen(token-plan 套餐, enable_thinking=false 省配额) → deepseek**；200+错误体→RuntimeError 清晰报错；ReadTimeout 不重试直接换厂商（旧 bug 300s×3=15min 卡死）；**供应商熔断器**（失败后 5 分钟跳过，deepseek 挂时秒切 qwen）
- DeepSeek 官方文档四页学习存档记忆（定价忙闲双档/思考模式默认开/KV 缓存前缀匹配/多轮无状态）

### 单场重规划与逐场流水（z19/z26）
- 🔁 场头按钮 = `plan_scene` 单窗版；整集重规划 = 逐场流水（有产物的场保留，其余走同管线）——后按用户令改三级清障（见下），流水代码保留待命

## 附: 剪映迁移丢件根治 (0915 深夜定案)

**症状**: 装配草稿里的静图转换件 (标题底图/S00c/S00d/品牌卡定格) 在剪映 2026 打开后整段消失, 时间轴塌缩 → 音画错位 (最初误判为对齐 bug)。

**排除过程** (三连败+终胜):
1. 中文文件名 → 改 ASCII 哈希名, 死 ❌
2. faststart+GOP → 死 ❌
3. 拷贝到 anim/ 与生成件同夹 → 死 ❌
4. **ffprobe 全字段对比 s27(活) vs 转换件(死): 唯一恒定差异 = 颜色元数据全空 (color_space/primaries/transfer=None, range=None)** → 转换件完全仿 VHS 档案后复活 ✓ (视觉亲验: 1353 草稿 slot1=标题底图本尊)

**⚠️ 1404 更正**: 上节「颜色元数据」是伴随修复非根因 — 真根因是**段数组顺序≠时间顺序** (开场套件在镜头循环之后追加, 数组里排最后): 剪映 2026 迁移按数组顺序校验, 起始时间早于前段结尾的段被摘下重挂到时间轴末尾 (用户在 3:45 处找到全部开场件)。根治 = script.save() 前全轨 segments 按 target start 排序。视觉自验必须用中性提问 (诱导性提示词会被模型迎合, 曾致一次假阳性)。

**根治** (anim_draft.py _as_video_path): 静图转 mp4 统一 VHS 档案 —
```
libx264 -preset medium -crf 19 -pix_fmt yuv420p -r 24
-colorspace bt709 -color_range tv
-x264-params colorprim=bt709:transfer=bt709:colormatrix=bt709
-movflags +faststart
```
**纪律**: 凡产出要进剪映草稿的视频, 编码必须带完整 bt709/tv 颜色标签; 新增转换器时用 ffprobe 对标在活件。旧缓存件 (无标签) 一律清空重生成。

**方法论沉淀**: GUI 亲验必前置窗口 (后台窗口不重绘=假画面); analyze_image 走 MCP 截图 URL 通道; 逐变量排除时用「全灭样本 vs 全活样本」的恒定差异定位。

**实现** (anim_draft.py 开场块, pyJianYingDraft 原语):
