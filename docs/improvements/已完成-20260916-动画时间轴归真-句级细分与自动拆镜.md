# 动画时间轴归真 — 句级细分与自动拆镜 — 0916 完成

> 状态：**已完成**（用户诊断"网页端规划时时间轴没算明白"，多层取证后根治）。
> 成果：ep1 归真后 34 镜全 ≤10s、零轴隙零丢镜零漂移；草稿 `HBO的内容战略_动画_ep1_0916_0025`（caption_drops=0，定格补差只剩 2 处老视频短的待重 roll + 3 处 0.1-0.3s 可忽略）。

## 症状与用户诊断

用户报：动画和音频对不上，系统靠"加长图片（定格补差）又截一段"硬凑，多处出现 → 规划期时间轴就没算明白。实测 ep1：7 处定格补差（s11 +9.2s 冻帧）+ s04 反向截断。

## 取证链（四层病根，层层剥开）

1. **表层**：8 镜 anim.duration_s 被钉在 10.00（H3_MAX_SPAN 物理上限）而口播槽 12-19s → 视频先天短 3-9s；QC 拆镜阈值 25s 与 10s 上限脱节，19.3s 的 s11 招摇过市。
2. **中层**：`_realign_narrations` v1 切点时间用**包内字符比例插值** — 漂移源；切点落包中 = 劈句尾（"用户。"型 ragged narration 遍地）。
3. **根因**：**ep1 音频是老式巨型多句包** — 17 个包里 10 个 >10s（中位 12.9s、最大 23.6s，一包 4-5 句）。"包边=句边"的前提在这集音频上不成立，包内插值是唯一选择 → 必然漂移。
4. **实现坑**（迭代过程实锤）：① doc["groups"] 列表序 ≠ 时间序（S08 开场组在列表尾），按列表序单调推进整组饿死；② 句包 t 值 2 位舍入产生 0.01s 发丝缝，time_to_pos 落缝兜底流尾 → 组锚扔到末端连锁饿死；③ ragged 文本锚"总能命中"但位置漂 — 只配微调不配导航。

## 修法（三层）

1. **句级细分**（anim_draft._sentence_segs）：巨型包文本按句末符切 + **ffmpeg silencedetect 吸附包内真实停顿**（J线 `_caption_bounds_snapped` 同款平移）→ 54 个句级 segs，句边界贴真实停顿 ±0.3s 级，无 wav/失败回退字数比例（标点降权+句尾停顿加权）。
2. **对账 v2**（director2._realign_narrations）：切点 = **时间锚为主**（t_start 反查，天然单调）+ 文本锚 ±25 字内微调 → **吸附句包边界**（时间=句边精确值）；切点严格递增、空镜剔除、**组按时间序处理**、time_to_pos 缝隙容差 ±0.05s。
3. **自动拆镜**（用户令"物理上限不动，一个不够就两个"）：口播超 H3_MAX_SPAN 的镜按整句包贪心分块（每块 ≤10s）；块1 继承原镜 id+素材（已生成视频直接复用），块2+ 新 id（s11b/s11c…）继承视觉基因回 planned 进生成队列；text_layer 按绝对时间分家（字幕/强调词跟句走）。伴随：QC 拆镜阈值 25→10s。
4. **align v2 路径升级**：从"只体检"到"确定性归真"（重跑对账不重规划不花 LLM）— `_sentence_segs` → `_realign_narrations` → save；返回 realigned/split/dropped 计数。
5. **字幕链式游标**（J线铁律平移）：拆镜后 caption 事件贴邻，_render_captions 改链式推起点（start=上段末+1ms）+ 最小段 250ms → caption_drops=0（67/67）。
