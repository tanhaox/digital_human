## 问题 2：字幕有断的内容，不是完全体 → 已根治（根因不在截断）

真实根因（ep1 实测）：**director2 生成的 caption `t_end` 常超镜尾 → 绝对时间与后镜 caption 轨内重叠 → pyJYD `SegmentOverlap` 被 per-shot 容错吞掉、后一条整段丢失**（7/51 丢段）。`anim_draft.py` 渲染处并无 `[:N]` 截断；shots.json 里的 caption 文本本身完整。

伴随发现（同病根，一并根治）：
- **hero 轨从未注册** — `append_tracks` 一直没有 `"hero"` 轨，impact/hero_number/year/title 全部强调字此前每次装配都被静默丢弃（1419 草稿的强调层实际全灭）
- 同帧双层设计（ep1 s29「VS」impact + 「回本难」hero_number 同 a0=19.71s）单轨装不下 → **impact 单开一条文字轨**分轨共存

## 修法（anim_draft.py 结构性改动）

文字层从"逐镜内联渲染"改为**"先收集 → 同轨去重叠 → 再装配"**：
- `_collect_text_events(shots)`：text_layer → caption/hero/impact 三桶事件（绝对时间），每桶内排序后**截尾去重叠**（砍前条尾巴不推后条 — 字幕跟口播，时间锚不漂；50ms 缝；0.3s 病态窄窗保底）；品牌卡仪式句 fallback 一并迁入
- `_render_captions`：`wash_subtitle_text` 洗涤 → `split_subtitle(30)`（横屏断句上限，J线 job_draft 同款）→ 按字数比例分时上轨
- `_render_hero`：强调层分档样式原样保留，impact→"impact" 轨、其余→"hero" 轨
- `append_tracks` 补注册 hero/impact 两条文字轨
- `build_history.jsonl` / 返回值新增对账字段：`captions` / `caption_drops` / `hero_texts`
