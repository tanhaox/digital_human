## 问题 (ep5 实锤)

旧版三件套 (0921 纯程序调取) 素材错位:
- 钩子句出现 **3 次**: 标题(首句) + 简介(开场块含全文) + 评论引导(整段引用)
- 主题出现 2 次: 红字 + 评论引导话题行
- 两块都以「评论区聊聊」收尾 — 双 CTA
- 红字 = 主题整串 = 说明性标签 (「一次只做一件事：霍普金斯的极简工作秘密」), 无钩力

## 方案: 一料一位 (零 LLM 不变)

| 位 | 正源 |
|---|---|
| 标题 | 钩子首句 (不变) |
| 红字 | **钩子破折号后段**(剥「秘密是/答案是/其实是」壳词+引号) > 主题后段 > 主题子句收口 |
| 简介 | 开场块正文, **剔除与标题/钩子重叠的行**(归一化剥标点后前缀匹配) + 限 3 行 |
| 评论引导 | **秘籍短名**(括号前, 此前三件套无家) + 讲稿互动句三级抓取 + 收藏向收尾 |

互动句三级: ①问句 ≥8 字(「你站哪边？」类短问弃用) ②自查句(可。结尾, 剥「先自查：」前缀) ③通用兜底; 报到/续集向句子永不入位置顶评。covers 分支同链升级, 页面编辑框手改仍最优先。

## 验收 (全 7 集)

红字: ep2「时间记录会打你的脸」/ ep3「这个问题90%的人从没问过自己」/ ep5「撇开一切」/ ep6「没有替代方案的决策就是赌博」/ ep7「明天上班就能用」; 简介零钩子复读; 评论引导各集有专属问句 (ep4 自查句「你招人时，是先挑毛病，还是先找这人最擅长干什么」)。
