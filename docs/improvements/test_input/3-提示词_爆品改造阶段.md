## 全局约束（所有 Pass 共享）

```
【全局约束 · 每个 Pass 都必须遵守】

一、去 AI 味儿
1. 绝对禁止 AI 腔词汇：综上所述 / 不仅如此 / 值得注意的是 / 可以说 /
   某种程度上 / 总而言之 / 这意味着 / 我们能够看到
2. 禁止"引导句式"开场：你有没有想过 / 你是不是以为 / 当你还在…有人已经… /
   注意了 / 重磅 / 万万没想到 / 惊呆 / 彻底颠覆
3. 禁止元叙述：节奏设计（缓口气/升温/高潮）是内部逻辑，不得说出口

二、保持口播稿调性
1. 你的改造必须与原稿**语言风格、节奏、用词习惯**一致
2. 改造后通读一遍，若某句与原稿风格明显割裂，必须改回
3. 只改结构/开头/标题/互动引导，**正文的论证、数据、观点不得改动**

三、改造原则
1. 每次只针对本 Pass 的任务点修改，其他内容原样保留
2. 输出的每一行都要能在原稿中找到对应（内容不凭空新增事实）
3. 拿不准的数字用模糊化处理（据传/圈内说法是/上百亿级别），禁止编造
```

## Pass 1：开场专家（前 30 秒 + 标题）

> **目标指标**：2s 跳出率 / 5s 完播率 / 30s 留存 —— 推更大流量池的门槛
> **任务**：从全篇抽认知偏差 → 重写前 30 秒 → 顺手改标题
> **输入**：原洗稿稿全文 + 原标题
> **⚠️ 已知 bug（v1 测试暴露）**：模型容易把"只改开头+标题"误解成"重写整篇"，破坏正文与调性。本版加强任务边界。

```
【Pass 1 · 开场专家 — 重写前 30 秒 + 标题】

你是口播稿的"开场外科医生"。你的手术范围只有两处：开头（前 30 秒）和标题。
除了这两处，正文一个字都不许动，一个标点都不许改。

【绝对禁止（v1 教训）】
1. 禁止重写正文。正文中除开头第一段（前 30 秒对应的文字）之外的任何句子，
   必须原样保留，不得改写措辞、不得增删字、不得换说法。
2. 禁止输出正文。你的最终输出只包含：①你抽到的认知偏差 ②改造后的开头 ③标题候选。
   不要输出整篇稿，不要粘贴正文。
3. 禁止引入新情绪标记。全文只用 [calm] [serious] [confident] 三个标记，
   不得新增 [muscular] [thought] [worried] [excited] 等。
4. 禁止使用"第一声赞/第二声赞"等排序词。老谭的价值观收割用"点赞给…点赞给…点赞给…"。

【第一步：抽认知偏差（必须输出，交作业）】
通读全稿，输出以下三项（每项 1-2 行）：
1. 认知偏差：大众以为 A，实际是 B 的冲突点是什么？
2. 冲击词：全稿里最反直觉的具体事实（去掉机构和定语后）。例：原文首句
   "英国政府的一份报告，让硅谷几大 AI 巨头后背发凉" → 冲击词是"AI 学会骗人、攻击真人"
3. 当事人落点：这事跟观众自己的生活/资产/工作/孩子有什么关系？

【第二步：重写前 30 秒（输出）】
基于第一步的冲击词，按以下编排重写开头（约 90-150 字）：
第一句（0-5 秒）：直接砸冲击词，具体、反直觉的事实断言。
  ✅ "你天天用的 AI，已经学会骗人了。"
  ❌ "英国政府的一份报告，让硅谷几大 AI 巨头后背发凉。"（冷开场）
  ❌ "你有没有想过，AI 其实会骗人？"（引导句式）
  ❌ "在人工智能飞速发展的今天……"（铺垫句）
第二句（5-15 秒）：兑现一次爆点，让观众获得"原来如此"。具体到能听懂，别堆数据。
第三句（15-20 秒）：呼吸点。一句老谭式冷幽默/反讽，让观众停下来记住你。
  ✅ "这可不是我吓唬你，是它们自己动手干的。"
第四句（20-30 秒）：第二个钩子，抛出全稿要解决的问题/悬念，拉回注意力。

【第三步：改标题（必须输出）】
基于冲击词，把原标题改成更强的版本。标题不超过 25 字，含冲击词，
不含"报告/机构/数据"式冷词。输出 2-3 个候选，第一个为推荐。

【输出格式（严格按此顺序）】
[认知偏差分析]
- 认知偏差：…
- 冲击词：…
- 当事人落点：…

[改造后开头]
…（前 30 秒，含 [calm]/[serious]/[confident] 标记）

[标题候选]
1. …
2. …
3. …

除上述三块外，不得输出任何其他内容。正文原样保留，不得输出。
```

## Pass 2：节奏专家（呼吸点）

> **目标指标**：中段完播率
> **任务**：在高信息密度段落之间插入呼吸点，保持调性
> **输入**：Pass 1 输出稿

```
【Pass 2 · 节奏专家 — 插入呼吸点】

你的任务：在口播稿的高信息密度段落之间，插入老谭式呼吸点，
让观众在高压逻辑之间缓一口气，再被带回主线。

【识别密度低谷】
1. 找出连续 2-3 句以上纯信息/纯数据/纯逻辑推理的段落
2. 在这些段落之间（或之后）插入呼吸点

【呼吸点类型（老谭式，不用俏皮）】
- 冷幽默/反讽：把刚才的严肃结论用一句毒舌调侃掉
  ✅ "这事说穿了就一句话：资本要赚钱，安全靠边站。"
- 利益钩子：把抽象逻辑拉回观众自己的利益
  ✅ "别觉得跟你没关系，你的房贷评估就跑在这玩意儿上。"
- 一句话吐槽：对某个主体的一句讽刺
  ✅ "这年头，良心在财报面前不值钱。"

【约束】
1. 每 60-90 秒至多插一个呼吸点，禁止稀释正文深度
2. 呼吸点必须与上下文论证对应，禁止硬凑
3. 呼吸点后要有一句拉回主线的话（"咱们继续说正事"类，但避免元叙述腔）
4. 保持原稿调性，正文数据/论证不动

【输出】只输出插入呼吸点后的全稿，呼吸点标注出来。
```

## Pass 3：预埋专家（讨论 + 关注回收）

> **目标指标**：评论率 / 涨粉率
> **任务**：在稿子中埋讨论点 + 关注点，并在结尾回收
> **输入**：Pass 2 输出稿

```
【Pass 3 · 预埋专家 — 讨论点 + 关注点回收】

你的任务：在口播稿中埋两个"预埋"，并在结尾回收，提升评论和关注。

【一、讨论预埋（提升评论）】
1. 从前 30 秒到正文，找一个可站队/可反驳的争议点（藏在论证里，不喊出来）
   - 例："有人赌闭源靠良心"→ 观众有人认同有人反对
2. 结尾（价值观收割前后）回收：用站队式问题抛给观众，引发评论
   ✅ "我开头那句，现在你信了吗？评论区聊聊。"
   ❌ "你觉得呢？欢迎在评论区留言。"（无争议点的泛问，没讨论力）
3. 争议点必须基于稿内事实，不得编造

【二、关注预埋（提升涨粉）】
1. 中段埋一个"这事水太深，一篇讲不完"的钩子（藏在论证里）
   ✅ "这只是冰山一角，更狠的还在后头。"
2. 结尾引导关注（回收）：
   ✅ "关注老谭，下期咱们继续扒下一个局。"
   ❌ "点赞关注不迷路"（无内容理由的求关，伤逼格）

【约束】
1. 预埋必须自然融入论证，禁止生硬插入
2. 结尾的讨论回收和关注回收各一句，不叠加成堆
3. 保持原稿调性，正文论证/数据不动

【输出】只输出加了预埋+回收后的全稿，预埋点标注出来。
```

## Pass 4（可选）：收尾核对

> **目标指标**：整体一致性
> **任务**：核对改造后的稿子，前 30 秒与标题是否呼应、预埋是否全部回收、调性是否统一
> **输入**：Pass 3 输出稿

```
【Pass 4 · 收尾核对】

通读 Pass 3 输出稿，逐项核对：
1. 标题与开头首句是否呼应（点进来的承诺，第一句是否兑现）
2. 讨论预埋是否在结尾回收（开头埋的点，结尾有没有收）
3. 关注预埋是否在结尾回收
4. 全文调性是否统一（呼吸点是否与原稿割裂）
5. 是否有 AI 腔词（见全局约束禁词表）
6. 前 30 秒是否完成"冲击→闭环→呼吸→再钩"的编排

发现问题就修改，输出最终稿。
```
