## 排雷方法论

### 最大教训: 验证前先确认镜在重出
s06 一直是 img_done → K2 批跳过它 → 旧图残留被当作"修复无效"的证据 → 全天一半时间在追一个不存在的 bug。**每次试射前: `s['status']='planned'`**

```
prompt diff → seed diff → workflow diff → ComfyUI 缓存 → 直接提交验证 → 跳 planned 状态(真凶)
```
