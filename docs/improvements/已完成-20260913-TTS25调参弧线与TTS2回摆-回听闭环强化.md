## 二、块生成验证（用户提案，验毕待产品化）

**结论**：块（六段结构）为单位生成成立，方案 = **客户端句边界分包 ≤160 字 → 每包独立完整解码（mtok=600）→ 客户端拼接**。拆解块 351 字 v2 实测 98% 完整/零语气词/三包语速 4.4-5.3 一致带。

**两个判死/危险（在案）**：
- **服务端自拼接判死**：mtok=200 让服务端自己分段再拼 → 接缝 1s 死气口 + **生成劣化胡话**（「线路带宽客户名单」→"都哭哭呜呜崩满呗"），两版不同采样同位置翻车 = 文字侧顶针「铺满的那天。铺满那天」+ 顿号三连列举触发自回归重复环；同句在逐行模式干净（短上下文不触发）
- **静默截断**：mtok=600 + 长文本（351字）→ 服务端不报错返回半截音频（31s/11.3字/s 物理不可能）——**max_text_tokens_per_segment 安全线 ≤200 token（≈170字/段）**，服务端硬上限 600

## 四、回听闭环强化（当日五件）

1. **错音修复预算动态化**：`_MAX_FIXES=6` 静态 → `max(12, 行数//8)`（TTS2 吃字率高，EP2 7 行 fix_budget 饿死实锤）
2. **ASR 百分号归一**：whisper 把「百分之九十」写成 "90%" → 三行假吃字冤案；`_normalize_asr` 补 `%`→中文读法（财经稿满地百分比必复发）
3. **bleed 匹配同音容差**：精确子串匹配被同音换字（头→投）一个字打瞎 → `_bleed_hit()` = 精确 OR **纯同音滑窗**（无声调拼音逐字相等；故意不用 _syl_similar 的 n/ng 容差——撞墙/赚钱邻韵误报回归实锤）；双向判据接线，回归 9/9
4. **EP2 实战清零**：bleed 3 行（11/15/42）+ 吞字 7 行批量单行重合成 10/10 净；行17 尾巴串 018 头（用户人耳发现、检测器漏检——即第 3 件的案发样本）单行重合成根治
5. **单行重合成 = bleed 结构性根治**：批边界串句只在批合成发生，单行无边界（EP2 三发全验证）
