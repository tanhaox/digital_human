### H3 生视频 (两种模式)

**Mode A 定焦 (已验证稳定)**

| 项 | 值 |
|---|---|
| 节点 | `MiniMaxH3ImageToVideo` (本地模型, 非 ComfyCloud 包装) |
| 输入 | 1 张 keyframe (first_frame) |
| Sampler | `MiniMaxH3TurboSampler` |
| Sigmas | 6 步: `1.0, 0.95, 0.88, 0.75, 0.55, 0.3, 0.0` (4 步抖, 6 步稳) |
| 耗时 | ~76-89s / 5s 视频 |

提示词关键:
- physical_lock 里写 **"Locked camera on tripod, absolutely no camera movement, no panning, no zooming, no drifting"**
- beats 里只写画面内微变 (光影渐变/水面渐静/天色渐变)
- **禁 ambient life** (风/漂浮物指令会让水彩纹理全屏抖动)

**Mode B 首尾帧 (已验证稳定)**

| 项 | 值 |
|---|---|
| 节点 | 同上, 加 `last_frame` 输入 |
| 输入 | 2 张 keyframe (起点状态 + 终点状态, 同场景不同景别) |
| workflow 改法 | 复制 Node 136 (ImageScale) → Node 137, 连 133.last_frame |

提示词关键:
- physical_lock 写 **"Same scene in both frames: same shop, same tower, same water... Only the camera distance and framing changes"**
- beats 写 **"camera smoothly pulls back from [start state] to [end state]"**
- H3 在两帧之间插值 → 稳定运镜

**H3 禁忌 (实锤)**
- ❌ 自由运镜 ("camera pans left" 让 H3 自己画) → 全屏抖动
- ❌ AMBIENT_LIFE ("breeze keeps hair in motion") → 水彩纹理游泳
- ❌ 4 步 sigma → 抖 (改 6 步稳定)
- ✅ 定焦 + 画面内微变
- ✅ 首尾帧插值

## 二、动画导演引擎 (scripts/anim_director.py)

### 已跑通的流程

```
输入: 确认稿 + TTS manifest + 灵魂三问 + 受众地图
  ↓
模块A: 美术圣经 (LLM pro, 书级资产, 一次生成全系列)
  ↓
模块B: 叙事弧 + 运动设计 + 分镜规划 (LLM pro, 读 manifest 时间块)
  → 输出 arcs[] + shots[] (含 keyframe_zh / motion_zh / camera / text_layer)
  ↓
模块D: 确定性校验
  - 时间轴连续 (相邻镜间隙 ≤0.5s)
  - 时长对齐 (镜时长 = 音频段时长)
  - K2 文字禁令 (keyframe 禁可读文字/数字, 色号排除)
  - H3 运镜约束 (禁"猛然/急速/飞速/瞬间")
  - 弧内连贯 (bigram 重叠 ≥5%)
  - 密度合规 (每镜 ≥2s, ≤25s)
  ↓
模块E: QC 面板 (qc_plan.html, 人眼验收)
```

## 三、K2/H3 技术禁忌汇总 (所有后续镜必须遵守)

| 禁忌 | 原因 | 替代方案 |
|---|---|---|
| K2 画文字/数字/字母 | 模型不渲染文字 | text_layer 后期叠加 |
| H3 自由运镜 | 抖动失控 | Mode A 定焦 / Mode B 首尾帧 |
| H3 ambient life 指令 | 水彩纹理游泳 | 只写光影渐变/水面渐静 |
| H3 4步 sigma | 不够稳定 | 6 步 `1.0,0.95,0.88,0.75,0.55,0.3,0.0` |
| 快推快拉 | 糊帧 | 缓推/缓拉, 快变靠切镜 |
| VAE 名无 000_ 前缀 | 400 报错 | `000_qwen_image_vae.safetensors` |
