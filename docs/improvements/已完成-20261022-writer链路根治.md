## 五、方法论沉淀

- **六层病理叠加时逐层修必失败**——三路审计（代码/变更史/产物日志）交叉定位全层后开方。
- **闸与产线能力脱节的修法**：闸拦得住≠LLM 学得会——正例教学（示例镜）与执法（闸）必须成对。
- **救援网的经济学**：每道网都是真 LLM 调用，无预算帽时 5.4 倍于内容本身的成本；口径并闸（一次暴露全部问题）是唯一根治，救援网只兜尾部方差。
- **劣化保护的方向性**：带病 writer 优于整场合规 fallback（模板句质量塌方）；比较必须前置到一切落盘路径之前。
