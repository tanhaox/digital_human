### 核心设计决策 (勿推翻, 都是用户令)

1. **书级选线**: `outputs/动画/_资产/产线绑定_书名.json` = `{"line":"v3"}`; 缺省 v2 零扰动; 回退=删文件。
2. **上屏文字七类** (内容性质) × **渲染方式** (正交两维, 卡对象 `kind` + `style`):
   | kind | 默认渲染 | 落点 |
   |---|---|---|
   | 金句 / 口诀 | 金句卡 | 剪映后期 |
   | 结论 | 事件字 | H3 视频层浮字 |
   | 标题 | 标题卡 | 剪映后期 |
   | 提示 / 总结 | 清单卡 | 剪映后期 |
   | **图示** | **PNG** | 公式/图表/流程/表格 — 唯一出图类 |
   > 纯文字一律走剪映 (可编辑, 改字不重渲染); 只有图示出 PNG。
3. **图示渲染走 HTML 引擎**(非 ComfyUI): `card_render.py` 复用 `cover_render` 的纸纹/色板,
   Playwright 截图; 脑图/流程图用**本地 ECharts 5.5.0** (`web/vendor/`, 零新依赖)。
4. **图示数据由 LLM 产出**: 分诊 `img` 建议必须带 `diagram` 树形结构 (2-3 层/节点≤10字/总≤12),
   `sanitize_diagram` 清洗兜底。
5. **v2 零扰动铁律**: 入口是**并排双钮**(橙 v2 原样 + 绿 v3 新增), 禁换链式覆盖 (有回归哨)。
6. **v3 停用图内字通道** (1105 用户二令): `in_image_text` (K2 在空白载体上二段合成文字) 在 v3
   **不再使用** — 上屏字统一走剪映卡, 图示走 PNG。因此:
   - 不报「整场零申报 in_image_text」(宪法 10d 的场级配额在 v3 不执行; **v2 线不动**);

### 关键技术坑 (实锤, 别再踩)

| 坑 | 现象 | 解法 |
|---|---|---|
| CSP `script-src 'self'` | 内联 module 静默被拦, 页面卡「加载中」 | 逻辑全外置 `.js` |
| CSP `style-src 'self'` | `style=` 属性被拦, 布局失效 | 类名 / CSSOM (`el.style.x=`) |
| kimi 插件 | 调试层吞页面 POST, 请求 in-flight 永不完成 | **前端验收只用 Playwright** |
| 无头 Edge | `--dump-dom` 返回空; `--virtual-time-budget` 抢跑截图 | 同上 |
| ECharts tree | `data` 传对象 → SVG 空壳 | 必须传**数组** |
| ECharts headless | canvas 截不到内容 | `renderer:'svg'` + `animation:false` |
| ECharts 叶子 | `leaves.symbolSize` 不生效, 红点压字 | 数据级 `symbolSize:0` |
| 中文文件名进 URL | UnicodeEncodeError | 卡图文件名用 ASCII `v3_{cid}.png` |
| 相对导入 | `from .triage` → 保存恒 500 | 用绝对路径, 有回归测试 `exec` 真解析 |
| 保存按钮重建 | `innerHTML` 重建丢焦点 | `#save-label`/`#n-dirty` 常驻节点 |
| **字面 0x08 冒充 `\b`** | 正则 `r"^(s\d+)\b"` 被历史替换写成退格符 → 永不匹配 → 载体/引号**全部豁免失效**, 一片假红字 | 修字面并留注释; 扫描 `chr(8)` 全仓清零 |
| 「空白板面」跨词 | 「空**白板**面」的 空白 骑在载体词上, 前后文窗口看不到 → 假警报 | 加 ±2 含词窄窗口 |
| v3 假时间轴 | 假镜 `t_start=0` → 34 镜全判 hook 区 | 用 `est_s` 累加成假时间轴 |
| LLM 漏字段无人管 | 立意 prompt 要了 world, 漏了没人查 → 6 条叙事弧空世界, 画面句退化成通用办公室 (s2 铁证) | 生成后**自查+定点补全** (`fill_missing_worlds`, tag=`v3_arcs_world`), 页面只留「🔧 系统补全」按钮 |
