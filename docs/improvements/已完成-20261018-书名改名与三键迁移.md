## 背景: book_title 是全产线的磁盘 key

建书时书名从书库蒸馏 txt 文件名带入 (books.js createBook 只剥 `.蒸馏.txt`),
此后 L0 蒸馏、拆书留档、动画 ep 树、_资产、封面缓存、剪映草稿全部按书名落盘。
改名 = DB 一行 + 十类磁盘产物同步迁移, 漏一类就出"孤岛"。

首版端点只迁 3 处 (L0/拆书留档/封面缓存) → 连环漏三案:
① anim 页全空 (动画 ep 树 + _资产 没迁) → ② 品牌镜空白 (shots.json 内容里的
`image_file/video_file` 相对路径没改) → ③ 剪映草稿素材丢失 (草稿目录名 + 内部
绝对路径没迁)。四连修补齐。

## 实现

- `POST /books/{id}/rename` (routers/books.py): 校验(空/非法字符/同名409) → ① 简单对 rename+回滚 → ② 动画侧 (ep 树逐项合并, 同名冲突留 mtime 新者旧者进回收站; 三键 `_rename_assets`/`_rename_keyed`; `_rewrite_doc_titles` JSON 级改字段+路径值) → ③ 剪映草稿 (明文修+改名, 加密报备) → DB commit。失败逆移回滚。
- 前端 books.js: shell 标题旁 `✏️ 改名` 按钮 (prompt+confirm), 改后 loadBook 重渲染。
- 三键 repl 映射: `raw/_anim_safe/_cover_safe` 旧→新, 匹配时长键优先。
