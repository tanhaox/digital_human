## 系统件清单

0. **voice 轨逐包口播**（0916 用户令升级，0417 稿）：整段 voice_full → 逐包 AudioSegment（17 段按真实包时长从 tc 贴轴 + intro 两段 = 19 段，空文本静音包不入轨；每段 -2ms 防毫秒取整越界；失败兜底回整段）。字幕/镜头与口播的对应在剪映里逐段可见可调。
0b. **硬补帧全撤**（0422 稿用户令）：视频短于槽不再垫定格帧、未生成不再垫占位卡——**差额留空（黑位）**，生成素材照贴（超长截到槽）；空额只记审计日志不动轨（ep1 实测 12 处黑位、占位卡 0）。
0c. **填色卡诊断层**（0425 稿用户令二稿）：空位（整槽无素材/差额）恢复用**大填色卡**补（镜号/时间/口播摘要），与逐段音频/字幕三轨同轴——重新生成后一眼定位缺什么；**绝不用生成内容垫**（定格/首帧图禁用）。
0d. **品牌卡仪式句锚定**（0432 稿，两 bug 修复）：①拆镜 deepcopy 曾把 `brand_card` 旗标复制给分身镜（s07b 缺失镜错播登山客品牌卡实锤）— split 现在 `pop("brand_card")`；②品牌卡改为**按仪式句「我是老谭」在镜内的时位锚定**：首句型（s07 开场仪式）铺镜首，尾句型（s18 收尾仪式）先填色卡后品牌收尾（修复"缺失卡和品牌卡颠倒"）。
0e. **有稿必有字幕**（0436 稿用户令）：caption 事件改**句级稿直出**（`_sentence_segs` 音频句轴+停顿吸附，100% 覆盖），不再依赖 LLM text_layer 完备性（实锤 10/54 句无字幕：导览句被并条、作者译者句被漏）；text_layer 只供强调词降维锚定与音效 cue。54/54 句句有字幕、零丢弃零跳句。
1. **`anim_pipeline/covers.py`**（新建模块）：`wall_covers()` 静态 top10 墙 / `extract_book_cover(书名)` epub→OPF cover-image 提取（幂等缓存 00_本书_*.jpg）/ `render_wall_scroll(书名)` 书墙滚动 mp4 预渲染（11 张=前8+本书+第9/10，槽 480px 首帧 4 本，缓出扫 3120px）/ `wall_scroll_end_frame` 末帧 jpg。
2. **`_intro_voice`**：缺料自动合成（IndexTTS2.5 @7866 合成→双向裁静音→atempo 1.5×），幂等缓存 ep 目录 opening/；TTS 未在线留痕跳过（开场回退无人声轴）。
3. **统一音量（全音效）**：`sfx.sound_loudness`（ebur128 实测 LUFS 缓存 _loudness.json，**取末值**——首值是积分启动前 -70 占位）+ 动画线 `_attach_sfx` 统一挂载口：vol = 0.9×10^((-18−L)/20) 只衰减。Victory -6.5 LUFS（全库最热）→ 0.24；J线 attach_sound 未动。
4. **素材双轨制**：top10 静态固化不换（资本论/经济学原理/贫穷的本质/富爸爸/薛兆丰/国家为什么会失败/浪潮之巅/塔勒布/智能革命/MBA十日读）；本书封面每书 epub 提取。源 zhihailib 中图法 F 类（投资/股票/交易类筛除，备池 50 张）。
