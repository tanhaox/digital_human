## Ⅳ. 工程坑台账 (换本地必读)

1. `-ub 512` 大图/大包 non-causal assert 崩 → 4096 (已修进产线+bat)
2. Qwen3-VL 视觉编码器 + FA = CUDA 非法访存 → **必 `-fa off`**
3. **Qwen3.6 Aggressive 思考焊死**: `--reasoning off` / `--reasoning-budget` / `--chat-template-kwargs enable_thinking:false` / 消息级`/no_think` 四开关全被模板无视 → 凡 max_tokens 限段的 patch 型 stage (hygiene/cta/dedup) 必废 (实测只回 74-129 字); 解法=chat 层加思考余量(+8000)并空 content 重试 (`ep2_replay.py` 方案可移植)
4. `creation_common._parse_json` 遇空 content 直接抛 (思考型大输出偶发), 产线换本地须加 reasoning 兜底
5. `_l0_dir` 相对路径依赖后端 cwd — 离线脚本必须 `os.chdir(digital_human)` 否则 L0 料仓+樊登稿**静默全丢** (本次实踩)
6. Ctrl+C 关 bat: llama-server 同进程组收信号即退显存即释放, `Terminate batch job (Y/N)` 的 Y 只管批处理剩余行
