## 三、关键决策

1. 排重主防线在**调取筛选层**, prompt 软禁令被实证无效 (ep7 看着覆盖清单仍复用)。
2. LLM 对"同业双条"顽固违反 (海尔/格力、汇川/中控、格力/美的 三轮实锤) → 产库后
   人闸核对不可省; 检测词典里的滴滴/字节保留 (识别用非推荐用)。
3. 字数不是硬伤, 超 7 分钟包络才算 — 验收闸 (05c 长度差) 与执法闸同步降级。
4. CLI 验证需 `set_config(load_config())` 否则 get_config 抛错把 try 内逻辑静默吞
   (假象型 FAIL 两起); orchestrator 跨模块转口改动后要活体打一次。
