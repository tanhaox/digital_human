# 已完成 20260913b · 拆书线段落割裂根治 — 拆解三步调度 + 路标句铁律 + 段间承接检测

> 触发: 用户验收《HBO的内容战略》ep2 — "三五句的感觉挺好，但是几个段落几个段落的看，
> 总觉得割裂"。诊断与三层修复一次落地。

## 一、病理切片（ep2 实稿证据）

- **句级无病**: 每行一句的锤式短句（≤20 字/句）局部自洽 — 用户原话"三五句挺好"。
- **段级三处断裂**（对照 ep3"先看第一档→第二档→第三档"的干净走位）:
  1. **拆解一总览完三档**: "头一档…《浩劫后》…另一档，终端用户买单，下段细说。再一种，
     平台补贴…" — 一块装了整张表的目录，补贴档被挤扁后再没走过；
  2. **拆解二新设问重启**: "你的绩效，到底谁说了算？" — 不接路标不咬上块尾句；
  3. **拆解三换轨 + 回环**: 讲的是调研偏差（配套工具）不是第三档，结尾又第二次点名
     《付费主体判定表》；"这是六步转型的第二步"全稿说两遍。
- **语言层无胶水**: 车轱辘禁令禁掉一切回指 + "转场极简"禁铺垫 + 每段自带开头结尾
  （模板逐段组件清单）→ 段间只剩结构承重，结构一错位就散。

## 二、根因

一次 LLM 调用出全稿，拆解三块的内容分配**全靠模型即兴**；总纲构件调度只管
开场/论证序/金句/结尾四维，拆解区无人管；校验层只有句级（字数/车轱辘/复读段），
语篇层零检测。ep3/ep4 不割裂是秘籍天然三段顺走的运气，不是管线保证。

## 三、三层修复（三件一起上）

### 1. 总纲层 — 拆解三步调度（导演分配，生成器只执行禁自选）
- `config/laotan_series_director.txt`: 新增【拆解三步调度】— 每集秘籍按形态切三步
  （判定表→三档各一步/清单→逐项/三条线→一线一步/叙事→三幕），步间禁重叠禁跳步、
  禁第一步总览完三步（ep2 实锤写进规则）、每步一颗书证钉；输出 schema 加
  `"拆解三步": ["①…+钉", "②…+钉", "③…+钉"]`。
- `series_outline.py`: `_norm_steps` 归一（list/分隔串→3 条）+ `_validate` 硬校验
  （非 3 条短语=拒绝）；落库白名单加 `拆解三步` 与 `构件`。
- **顺手修死bug**: 旧白名单漏 `构件` → 导演输出落库即丢，episode_gen 永远读空
  （构件调度 0910 起实际从未生效）；且 UI 总纲保存（只提交 8 字段）会把空串覆写
  `构件` — 从 RoadmapRow/update 映射摘除，导演字段归导演。

### 2. 生成层 — 路标句铁律 + 回指豁免 + 表名配额（laotan-book.txt）
- **0b 路标句铁律**: 拆解区每块第一句=步骤路标句（"第二档，租来的太多"/"再看回收
  窗口线"式），一句完成"接住上块尾+报出本步"；禁新设问重启块；本步的钉/机制/行动
  只在本步讲，禁第一块总览完三步，禁回炒。
- **0c 表名配额**: 工具名全称全稿≤2 处（拆解区开场定名 1 + 末尾三件套点名 1，
  点名用"这张表"回指）。
- **000 回指豁免**: 半句回指（"刚才那面墙"/"回到第一档"）不算车轱辘 — 车轱辘禁的
  是重讲判断，指路不算；段间胶水全靠它。
- `episode_gen.py`: 注入"本集拆解三步（禁自选禁换序）"；旧总纲无此列时
  `derive_breakdown_steps` 从秘籍 ①②③ 标记确定性兜底切步（HBO 全 6 集实测可切）。

### 3. 校验层 — 段间承接确定性检测（creation_common.py）
`section_flow_issues(text, book_title)`，接入主稿/重试稿/压缩 pass 三处验收点：
- **承接断层**: 拆解块首句须含路标词（第X步/档/盏灯/招三/先看/再看/回到…真语料
  形态全收录）或与上块尾句共享 ≥2 内容 bigram；系统注入身份句（"我是老谭…"）跳过
  ——否则挡在段尾造成误报（实库回放实锤后修）。
- **工具名配额**: 《…》≥4 字（书名白名单除外）>2 次 → 打回。
- **系列句配额**: "六步转型的第X步" >1 次 → 打回（回顾段/总结段二选一）。
