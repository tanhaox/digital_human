## 一、弹药与蒸馏纪律

106 句是"组句展示型"弹药 (一句里同一字出现多次、不同读音), 不能整句照收——词表机制是**全文子串替换**, 只能收"词级恒定读法" (沿袭 0903 审计原则):

- **收**: 喝彩→`<喝|HE4>`、供给→`供<给|JI3>`、卡脖子→`<卡|QIA3>脖子`、宁死不屈→`<宁|NING4>死不屈`、吐蕃→`吐<蕃|BO1>`、单于→`<单|CHAN2>于`、疟疾→`<疟|NVE4>疾`……约 230 条
- **不收**: 孤立单字 (行/着/卡 单独出现) — 依赖语境, 归 `tts_verify` ASR 回环逐行兜底 (回环侧有 `_polyphone_ambiguous` 护栏, 宁可不修不可修错)
- **自升级补充** (域内高频, 非弹药): 尽管/尽快/尽早/尽量→JIN3, 应用/应对/应聘/应答/应变→YING4, 答应→DA1, 振兴/兴建/兴起/方兴未艾→XING1, 提防→DI1, 地壳/外壳→QIAO4, 过分/分外/分量/处分→FEN4, 颠倒→DAO3, 倒计时/倒数/倒挂/本末倒置→DAO4, 强劲/劲敌/劲旅/刚劲/苍劲→JING4, 行情/内行/外行/行列→HANG2, 传记/自传/列传→ZHUAN4, 埋没/湮没/出没于→MO4, 露面/露脸/露头→LOU4 (lù 保护词先行), 应用等
- **轻声 5 调启用**: 暖和→HUO5、思量/打量→LIANG5、寒伧→CHEN5 (vocab 有 5 调族)

## 三、保护词先行机制 (排序纪律)

有反例但高价值的词, 不弃收, 改用"**长词先匹配打断邻接**"化解: 前序规则替换后, 短词的字面邻接已被标注打断, 后序规则自然失配; 且保护词自身标注的是该词恒定正确读音, 语义零副作用。

| 保护词 (先行) | 被保护词 (后置) | 反例 |
|---|---|---|
| 学校 / 高校 | 校对 / 校正 / 校准 / 校验 | 学校对口帮扶、学校正门、高校准备 |
| 双重 / 多重 | 重创 | 双重创新 (chuàng ≠ chuāng) |
| 出差错 | 出差 | 难免用出差错 (chā ≠ chāi) |
| 便宜行事 | 便宜 | biànyí ≠ piányi |
| 崭露头角 / 抛头露面 / 暴露 / 披露 / 揭露 / 透露 | 露面 / 露脸 / 露头 | 崭露头角、风险暴露面 (lù ≠ lòu) |
| (既有) 泄露 / 银行 | 露面系 / 行列 | 泄露面、银行列表 |

**纪律已写进词表 `_comment`**: rules 应用序 = json 文件序 (dict 保序), **加词必须先过反例审查、保护词必须排在被保护词之前**。
