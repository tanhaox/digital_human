> 创建：2026-08-07

## 任务目标

升级素材生命周期策略：合成成功后**不再删除** slot 素材，保留 `slot_retention_days`（默认 7 天），使「重试同类 / 换素材重合成」不返工。

## 已确认的事实（核心矛盾）

- 原策略（ID-031 v3 引入）在合成成功后无条件 `shutil.rmtree(slots/)` 删除**全部** slot 产出。
- 而 `retry_by_workflow` / `retry_slot` 只重置**部分** slot 的 DB 记录。
- 两者不一致 → 用户「重试同类」局部重制后，其余 completed slot 的 `output_path` 指向已删除文件。
- compose 的 REPAIR 补齐逻辑（L424-466）被迫用**新素材 + 新搜索**补齐 → 画面与用户当初选定不一致 = **返工**；REPAIR 失败还直接触发「合成线程崩溃」。

## 用户决策（阶段 4 确认）

| 决策点 | 结论 |
|--------|------|
| 保留期限 | **7 天**（`slot_retention_days: 7`） |
| 素材库 GC | 本次不纳入 |
| 磁盘失败残留 | 一并清理 |

## 策略设计（保留什么 / 清理什么 / 何时清）

### 保留（核心）
- `composition_output_root/<job_id>/slots/*` 全部 slot 素材（超 7 天前保留）
- `slot.output_path` DB 引用与磁盘文件保持一致
- 成片 `director_<job_id>.mp4` + `composition_manifest.json` 永久保留
- host/hf 输出位于 slots/ 外（ComfyUI output / hf_visual），零搬运，本策略不改

### 清理
| 清理对象 | 时机 | 方式 |
|---|---|---|
| 合成中间件 concat_list/concat_raw/with_audio/normalized | 每次合成后 | 现有 `_cleanup_intermediates` |
| `silence_fallback.wav`（此前遗漏，0f1f7ed3 有 84KB 残留） | 每次合成后 | `_cleanup_intermediates` patterns 追加 |
| 过期 job 的 slots/ | completed 超 7 天 | 新增保留扫描（main.py） |
| 对应过期 job 的 hf_visual/<job_id>/ | 同上 | 保留扫描 |
| 被替换 slot 旧目录 | purge_replaced 时 | purge 连带删 |

### 删除 slots/ 的唯二出口
1. **用户删 job** → `_cleanup_job_files` rmtree 整个 job 目录（含 slots/）。现有代码。
2. **保留扫描** → completed 且 `completed_at` 超 `slot_retention_days` → 清 slots/ + hf_visual + 孤儿中间件，**保留成片**。新增。

**合成成功路径不再触碰 slots/**（删除 Step 7 整段）。

## 并发安全

- `_composing_lock` + `_composing_jobs` 保留，防重复写成片。保留 slots/ 后不再有 rmtree 删输入的竞态。
- 保留扫描只处理 `status=="completed"`；任何重试先把 job 置回 `reviewing`（retry_by_workflow）→ 移出扫描范围，不会重试中途删素材。
- `onupdate=_now()` 自动刷新 `updated_at` → 幂等守卫正确识别「有 slot 变了需重合成」。
- purge 已有 executing 拦截，新增删目录同请求内，无额外竞态。

## 边界情况

| 场景 | 行为 |
|---|---|
| 重试同类（核心痛点） | slots/ 保留 → 复用其余 slot 文件 → **不重跑不返工** ✅ |
| 换素材重合成 | 覆盖同名文件，其余复用，守卫识别 updated_at 后正常重合成 ✅ |
| 取消/合成失败 | 非 completed，扫描不触及；旧成片保留 ✅ |
| 被替换 slot | 旧行保 output_path，purge 删旧目录；新 slot 新 id 新目录，无碰撞 ✅ |
| 超 7 天 | 清 slots/ 留成片，重试同类时其余 slot 走 REPAIR（用户已接受此权衡） ✅ |
