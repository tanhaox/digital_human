## 一、政治敏感画面禁区 — 五层防线 (已落地并实战)

**词库单一事实源**: `config/compliance_visual.json` (28 词: 中国地图/五星红旗/国旗/国徽/天安门/人民大会堂/国家领导人画像 + 中国历任领导人名)。改词库即全链生效。

| 层 | 位置 | 机制 |
|---|---|---|
| 1 宪法 | director2.DIRECTOR_SYS「政治敏感画面绝对禁区」 | 源头规避: LLM 设计时就不画 (含卡通/剪影/变形/演员扮相, 变形不改性质) |
| 2 规划软警告 | collect_warnings + visual_ban_scan | keyframe/motion/text_layer 命中 → plan_warnings 亮灯 |
| 3 生成闸门 | anim_service._phase_gpu (k2/h3 前) | 命中拒跑, 指名单镜🔁 (与时间纪律闸门同址) |
| 4 K2 引擎防尾 | k2.PROTECT_TAIL | 每次生图物理注入"没有地图/旗帜/国徽/政治人物", 不依赖 doc 状态 |
| 5 词库服务 | compliance.check_visual (compliance.py 扩展) | 全系统共用枢纽, 缓存加载 |

**边界裁定 (待用户可否决)**: 国旗/国徽按"任何国家"禁 (用户令未限定); 领导人=中国历任 + 现任外国元首; **书中非领导人历史人物 (尼克松/肯尼迪/诺思) 不禁** — 否则本书 A4/A5 无法视觉化。要扩大到全部外国历任领导人, 词库加名字即可。

**实战**: 上线即抓 3 真命中 (s23/s24/s25 尼克松辩论/伊朗门听证的"美国国旗"背景, 旧宪法设计) → 单镜🔁 新宪法重设计 (电视屏幕/光柱替代) → 重扫零命中 → K2 only 重生成 ✓ (备份 bak_shot_20260917_0422*)。

## 二、前端审计 (web/anim.html, 707 行自包含; 明细见探查报告)

### P1 功能性 bug (建议尽快修)
1. **loadShots 未定义** (anim.html:500/:509 调用, 只定义了 load :216) — 标/剥品牌标、重排镜号成功后看板不刷新。修: 改调 load()。
2. **🎞动画编辑死 UI** (:636 读 s.anim.beats, 但 GET /status 不回 anim 字段 anim_service.py:824-838) — 逐拍编辑永远"该镜无动画节拍"; 后端 POST /shot/{sid}/anim 本身完好。修: status 加 anim.beats 摘要。
3. **reroll 连坐**: doReroll :464 / doAiFix :482 发 /h3 {reroll:[sid]} 不带 only → h3.run_batch(only=None) 跑**全部** approved 镜 — 逐场工作流下 reroll 一镜连坐烧其他场 GPU, 与文案"重新生成该镜"(:271)不符。修: reroll 时附 only:[sid]。
4. **花字 kind 塌缩**: 前端花字列默认 hero_number (:584), 后端 update_text_layer 只认 title/caption (anim_service.py:789) → 保存即变 caption, 花字/字幕语义合并落盘。修: 后端白名单加 hero_number/impact。

### P2 脱节/僵尸
5. qc_sheet ↗ 死链 (:247-249) — web 产线不生成 qc_sheet.html, 仅 CLI `python -m app.services.anim_pipeline.run qc` 生成 (run.py:112)。
6. 僵尸函数 doFixText (:466-474, 无按钮; 端点 anim.py:195 无前端活入口, 已被 🩹AI修 取代)。
7. ✅全部过审不受 running_job 门控 (:243, 其他按钮 :239-246 都查) — GPU job 持锁时点击 5s 后 AnimBusyError。
8. 死参数 pos (:338/:377 传, cardHtml 不读)。

### P3 轻微
9. SSE anim_started 未处理 / anim_progress.phase 未用 — 有 3s 轮询兜底, 无害。
10. 缺 book_id 时 BASE 空段 404, 仅"加载失败"无引导。

### 前后端对照结论
前端 19 个调用点全部命中路由 (body 匹配); 失配集中在**数据形状** (status 不回 anim、kind 归一化、reroll 批范围) 与**两个未定义/无引用函数**。路由有而 UI 无入口: fix-text (僵尸)、jobs/running (供 scripts/restart_backend.py 安全重启守卫, 设计如此)。"粉卡三态"实为副标题三态 (:230-234)。
