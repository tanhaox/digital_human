## 一、ep1 收官形态 (本轮定稿的全部机制, 详见 CHANGELOG 0914b-q)

- **开场链**: 书级冻结打字卡(三承重/零上下文) → 权威梯六拍(报书名→宣言作者→
  地位×2→说实话自谦→承诺无集数→L1认领) → P1-P3 樊登稿逐字钩子后移进场 →
  缝 → 元问题深挖 → 系列导览(每行一钩) → 收尾
- **三声部教义**: ep1 只有观众处境/书的事实/工具承诺三个声音 — 老谭第一人称
  职业回忆零出场 (persona_anchor_issues 执法); 手裁两处违规锚 (回顾段+拆解三)
- **确定性执法**: 打字卡骨架/冻结一致 + 报书名先于逐字段 + 逐字校验(引号等价/
  数字从严) + 段间承接 + 人设锚禁令 — 全部不赌模型自觉
- **视频层**: 固定开场 0-5.5s (打字卡+定格+书揭示件), 封面书库 epub 自给
  (storyboard_draft --book 自动备料)
