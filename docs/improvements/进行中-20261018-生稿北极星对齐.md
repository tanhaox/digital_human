## 一、北斗星原则（用户令 2026-10-18，生稿线一切闸/pass/打分的配权依据）

1. **稿件 = 拆书线 P0 源头**：TTS/分镜/剪映草稿全由稿派生；源头闸最严，确定性可修的病不进人闸。
2. **集型使命不乱**：ep1=全书总钩子 / 2..N-1=详解 / 末集=总结收官；任务完成度按集型分尺。
3. **稿为账号数据服务**：吸粉 > 观看时长 > 互动(收藏>评论>点赞) > 人设；字数带只是约束 LLM 完成板块任务的弹性工具，非目标。
4. **六层裁决序**：运营 > 讲清本集内容 > 有趣/降理解难度 > 案例融会贯通 > 人设口播 > 字数限定；修复删改从链底往上。
5. **平台带**：单条视频 > 4分30秒 且 < 7分钟。语速真值实测（替换 0912 的 4.6 估算）：《定位》7 集 × full_paragraph.wav（老谭·说书 TTS2，2026-09-22~10-04）→ median 4.974 ≈ **5.0 字/s**，区间 [4.82, 5.31]。

1. **字数弹性带（语速锚 5.0）**：相对软带 [0.90,1.08]×cap、相对硬线 [0.80,1.20]×cap（cap=target×5.0）；绝对包络 [1433, 2025] 字（270s×5.31 下限保 >4:30，420s×4.82 上限保 <7:00）；生效带=二者取交。注入 +40 字由软带上浮吸收。语速常量 SPEECH_RATE=5.0 / RATE_FAST=5.31 / RATE_SLOW=4.82 落 creation_common 顶部全链唯一引用。生成前 target 时长闸 (270,420)s，越带 issue 不代改。
2. **集型任务卡 v1**（现有闸归队+2 新闸）：ep1 卡=打字卡+六拍/fd锁段入终检+导览命中(记录级)+下集预告；工具集卡=黄金三秒钩子**落位闸**(新)+工具名配额+锚段+品牌+承接+双CTA；收官卡=行动册回指(记录级)+完结结尾。
3. **裁决序边界**：tier-2 可破软线至硬线，禁砍讲解骨架/数字锚/⟦⟧/标签凑字数；压缩删序=人设修饰→案例细节→趣味修饰，禁动钩子/CTA/讲解骨架。
4. **ep1 双开因**：六拍③去作者（作者由 fd 锁段第1段独占引入），车轱辘 lint 不变兜底。
