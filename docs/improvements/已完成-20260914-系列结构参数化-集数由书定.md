## 一、设计定稿: 结构不变量 + 书定参数

```
不变量 (系统守):  第1集=大钩子集 (承诺+书三件套+导览, 不教工具)
                  末集=行动册集 (纯干货装订, 不讲新论证)
                  中间=工具集 (一集一件工具, 完整交付)

                  禁凑数拆件/一件劈两集, 近亲可并一集)
总集数 = K+2 ∈ [5,9]
```

旧框架: 六集写死 (校验 ≠6 拒绝/导演模板六集措辞/收官集=实战倒转/ep1=生死集

## 五、ep1 拼装式开局 — 樊登前三段一字不改 (同日, 用户想法)

> 用户: "樊登稿质量已经非常高了。前三个段落可以一字不改，后面的大钩子完全也
> 可以从这个钩子里提。另外还有大纲，还有蒸馏。这个质量是能保证起来的。"

病根: ep1 原来是"樊登切片当拐棍 + LLM 用老谭方式重讲" — 成品文过一次传话游戏,
只能降质。P1 本身就是系列级大钩子 (365户→90%份额, 搬运工→标准制定者),
P2-P3 正是元问题深挖 (媒介权力), 生成层的价值只剩缝合与 L1 代入。

落地 (episode_gen + creation_common):
- **逐字段注入**: ep1 取樊登稿 P1-P3, ⟦⟧原话保护包裹 (复用既有"见标记一字不改"
  机制), 摆放定位: P1=打字卡后开场口播 (宣言+书地位锚), P2-P3=拆解区元问题深挖;
  P4-P13 降级背景参考 (是工具集的正菜, 禁整段复述/剧透); ep1 常规"重讲"切片拐棍
  让位 (避免诱导重写)。HBO 实测: 3 段 672 字 ≈146s, 留 ~150s 给生成缝+导览+收尾。
- **拼装式开局提示**: 打字卡 → P1(逐字) → 代入/痛点/缺口/共情(生成缝, L1 现造)
  → 作者拍(蒸馏) → P2-P3(逐字)+一口预演 → 系列导览 → 收尾承诺。
- **确定性校验** fandeng_opening_issues: 每段去空白(含⟦⟧)须为成稿连续子串
  (标签行只许插句号处); 换词/缺段打回, 主稿/重试/压缩pass三验收点全接
  ("只删不改"的压缩删了逐字段=废)。
- 无樊登稿的书: 走原八拍路径, 零改动。
