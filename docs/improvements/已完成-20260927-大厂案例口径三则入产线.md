## 三则

1. **不评企业好坏**: 只描述管理动作, 不说这家企业伟大/失败/强弱;
   收口句式 = "这个管理动作, 印证了书中XX思想"。
2. **信源限定词**: 引入大厂案例的句子必带 公开报道 / 当年对外披露 / 早期 之一。
3. **选题避雷**: 禁近两年热点争议事件, 选已沉淀的公知商业史。

按"机制=宪法+结构注入+确定性闸+回喂四层同向"铁律落地 (对 0926 品牌放行裁决的口径收紧,
与 config/laotan-book.txt 品牌守则同族不冲突 — 守则管"能不能提品牌", 三则管"提了怎么说话")。

### 确定性闸设计 (工程口径)

- **不评企业**: 判词 19 个 (伟大/神话/奇迹/传奇/碾压/吊打/衰落/没落/败局/塌房/翻车/
  救星/罪人/英雄/帝国/最强/最牛/完败/垃圾) 出现在品牌名 ±邻窗 (前10/后12字) → 打回;
- **限定词**: 大厂 (新增 `_ZH_BIGTECH` 23 名: 字节/字节跳动/腾讯/阿里/阿里巴巴/蚂蚁/
  华为/美团/京东/小米/百度/拼多多/网易/比亚迪/宁德时代/大疆/快手/抖音/滴滴/携程/
  顺丰/B站/哔哩哔哩) **首次**出现的句子, 含案例动词 (推行/推出/提出/实行/宣布/做法/
  战略/打法/文化/制度/组织/内部/曾经/起家/发家/转型/改革) 而无限定词
  (公开报道/公开资料/当年/早期/对外披露/披露/财报/公开信/访谈/传记/官方) → 打回;
- **选题避雷**: 品牌与 2024+ 年份同句 → 打回;
- **豁免 (零误报设计)**: 平台自指/生活动作句 ("点个美团外卖"/"刷抖音") 无案例动词
  天然放行; 假设句 (品牌名之前有 你/如果/假如/假设/要是/想象) 放行;
  只查大厂**首次**出现句 — 后续行文不反复要求。
