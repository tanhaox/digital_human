## 一、整体数据流

```
文章 → 洗稿（LLM 直接产出 70-100 字最终口播稿）
         ↓
    自动分段（LLM 切 4-6 句，自动选/自动排）
         ↓
    整段 TTS 生成（IndexTTS2 / 7862）
         ↓
    Whisper forced alignment → 词级时间戳
         ↓
    大导演 Agent 出 slot 工序单
         ↓
    各 slot 并行执行 + 导演审核替换失败 slot
         ↓
    合成最终 9:16 视频
```

## 六、风险与缓解

| 风险 | 缓解 |
|---|---|
| Whisper 对齐精度不够 | 先用 large-v3 模型；保留人工微调接口 |
| LLM 导演输出 slot 时间越界 | Pydantic 校验 + 后端 clamp 到 [0, total_duration] |
| LTX23 按片段生成 host 时音色/嘴型不连续 | 音频是整段生成后切的片段，嘴型只跟片段内音频；允许微秒级随机差异 |
| Pexels 素材时长不够 | 循环播放或 fallback 到本地/host |
| 所有 slot 都失败 | 黑场+字幕保底，不阻塞合成 |
