## 三、五件新能力（全部存量回测/真机实证）

1. **prompt_gate.py**（观察模式）：扫真正发给 CLIPTextEncode 的拼装终串——补 visual_ban_scan 只扫 doc 字段的盲区。743 镜存量回测 3% 真漏网（HBO ep1 s56/57 军装人物实锤）。口径修正两例：`16:9横幅构图` 画幅豁免；《定位》小旗彩旗是合法隐喻道具，"旗帜"撤出词根集。
2. **PROTECT_TAIL 换词法**（k2.py）：旧否定尾每条提示词常驻 14 个禁区词根（图像模型对否定不敏感、对词根敏感——老李 V6.9.5 实锤同款）→ 换词版零词根+正向民用锚。首批真数据：定位 ep3 K2 批 52 镜 **hard_roots 零命中**。旧版存 `PROTECT_TAIL_LEGACY` 可回滚。
3. **video_qc.py**（观察模式）：H3 出片后抽 3 帧（首部避淡入/中点/尾部避截断）过 glm-4v-flash 查崩坏/乱码伪字/首帧漂移（首帧 vs K2 原图水平拼图对比）。口径两轮眼验迭代（白名单匹配→花字逐拍轮播片段对不上全句假阳；载体判断→glm-4v-flash 执行不稳 9/9 假阳；终版只查乱码）→ 66 镜回测 **1 真阳性（ep7 s67 红底伪字，4.5v 眼验实锤）0 假阳性**。产物 video_suspect 字段 + qc 卡片🎥徽章 + 看板徽章。
4. **打回负面词直接应用**（用户令推翻 LLM 转译案，纯确定性）：打回弹窗填"墙"→ `k2.strip_negative` 把画面句含墙**子句**整体剔除（词级删除留"砖"残片反向诱导）→ 双写 image_prompt_zh+keyframe_zh（防单镜重规划带回，同 auto_fix_banned 先例）→ 留痕 `[负面词剔除: 墙 去2子句]` → 换 seed 重生成。**s18 端到端实证：新图零墙**（背景砖墙→天窗顶光光晕，台秤/托盘/人物全保留）。K2 负面通道物理无效（cfg=1+ConditioningZeroOut），子句剔除是"应用"负面词的唯一可靠路径。
5. **购物篮「🎨重做到生图」+ 立意面板收起**：redo-queue 加 to_image 路线（LLM重设计→生图停 img_done 走人检，不自动过审不跑 H3）；立意面板加状态行（⚠ 还有 N 场待分镜——A6 校验两轮败时信号可读）+ ▾收起/▸展开。
