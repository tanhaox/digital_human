## 关键设计

### 1. Router 不拆包
每个 router 保留 `router = APIRouter(...)` 属性,main.py `app.include_router(x.router)` 注册(L290-304)。超限函数为纯逻辑 → 下沉 `app/services/*`,端点保留原处。

### 2. 双 ComfyUI 客户端协议(不合并)
- `comfyui_client.submit_prompt`/`poll_history`: **raise RuntimeError + 中文消息**(dhv 用)
- `comfyui_client.submit_and_wait`/`persist_outputs`: **返回 dict + 英文消息**(comfyui submit 用)
- 错误消息逐字保留: 英文 `ComfyUI unreachable at {base_url}`、`/prompt HTTP {code}`、`timeout after {sec}s`;中文 `ComfyUI 不可达`、`响应异常`、`task errored`、`task timeout after {sec}s`

### 3. Publish 回调 DI
`voice_service` 不导入 `app.routers.jobs._publish`(消除 service→router 反向依赖),router 经 `publish=_publish` 参数注入。

### 4. GPU session 锁作用域
- 单条合成 `synthesize_voice` 包一次 `with get_gpu_service_manager().session(...)`
- 抽卡 `_run_carnival_worker` 外层包一次锁(原始行为,避免双重加锁),内部调用不管理 session 的 `_tts_synthesize`

### 5. 遗漏调用点修复
`roles.py` 原本 `from .comfyui import _find_workflow, _load_workflow_json, _inject_inputs, submit_and_wait`,但 comfyui 重构后这些函数已下沉。改为 `from app.services import comfyui_service` + `comfyui_service.find_workflow/load_workflow_json/inject_inputs/submit_and_wait` 调用。
