# 待改进 20260925 — 建书流程书皮提取 + 内容库页缩略图

## 需求 (用户令 0925)

- 背景: 开场前 5 秒剪辑用书皮素材 (书墙滚动 + 主书封 reveal), 但书皮提取
  (`anim_pipeline/covers.extract_book_cover`, 幂等缓存 `00_本书_*.jpg`)
  只在视觉渲染阶段 (anim_draft) 才发生 — 提错要到最后剪辑才发现。
- 需求: 建书流程里直接把书皮提取出来; `books_content.html` 页显示缩略图,
  提取错了能及时知道。
- 实锤: 当日新书《卓有成效的管理者》epub 在书库、封面未提取。

## 技术方案

| 文件 | 改动 |
|------|------|
| `app/services/anim_pipeline/covers.py` | 增公开 `book_cover_path()` (缓存路径计算复用) |
| `app/routers/books.py` | ① `_extract_cover()` helper; ② `create_book` 同步路径 + `_run_prepare` 后台路径 auto_fill 后提取; ③ `get_book` 响应加 `cover:{ok,path}`; ④ `GET /books/{id}/cover` 出图 (老书按需补提); ⑤ `POST /books/{id}/cover/reextract` 删缓存重提 |
| `web/books_content.js` | 输入补全面板上方加书皮卡: 缩略图 + 状态徽标 + 落盘路径 hint + 「重新提取」按钮 |

- 存量书零迁移: `<img>` 打页面即触发按需补提。
- 缓存 jpg 为幂等缓存产物, reextract 直删即红线例外。
- 提错的人工修法: 手工替换同名 jpg (开场产线吃同一文件)。

## 预期结果

新建书后 books_content.html 顶部见书皮缩略图; 未提取到显示原因 + 重提按钮。

## 影响范围

建书链路 (快, 秒级 zip 读), 页面只读展示; 不动 anim_draft 消费侧。
