## 七、重构蓝图(打包结构优先,聚焦 8 个严重文件)

> 现项目已有 `app/services/`、`app/routers/`、`app/models.py`、`app/schemas.py` 分层。蓝图在**保持现有 FastAPI 项目布局**前提下引入 `domain/`、`infrastructure/`、`application/`,避免推倒重建。

```
digital_human/app/
├── domain/                        # 纯业务逻辑,零框架依赖
│   ├── __init__.py
│   ├── slot_planner.py           # 来自 director_parser: 规则引擎/降级判定
│   └── tagging_policy.py         # 来自 video_tagging_service: 维度枚举/清洗策略
│
├── application/                   # 用例层: 编排服务,薄
│   ├── __init__.py
│   ├── director_plan.py          # create_director_plan(拆自 249行→3个用例)
│   └── composition.py            # compose_director_job(拆自 287行→管线分步)
│
├── infrastructure/                # 技术实现: 外部依赖全部下沉
│   ├── __init__.py
│   ├── db.py                     # get_session 统一 Session 生命周期(替代30+重复)
│   ├── ffmpeg.py                 # render_clip / mix_audio / loudnorm(去重4处)
│   ├── pexels_client.py          # 拆自 pexels_service: 纯 HTTP 客户端
│   ├── llama_host.py             # _ensure_llama_server 探活/启停(三分合一)
│   └── tts_engines/              # 拆自 tts_client 1140行
│       ├── __init__.py
│       ├── base.py               # TTSEngine Protocol + _split_wav_by_silence
│       ├── fish_speech.py        # 拆自 L479-530
│       ├── f5_tts.py             # 拆自 L541-593
│       ├── indextts.py           # 拆自 L594-649
│       └── orchestrator.py       # synthesize_lines / synthesize 调度
│
├── routers/                       # 现有,保持 thin(<150行/文件)
│   ├── director.py               # 现有 864行 → 拆出 _background.py 后台任务
│   └── library.py / voices.py     # 保持,提取 service 方法
│
└── services/                      # 现有,只保留薄门面转发(向后兼容)
    ├── slot_workflows.py         # → 转发到 application/composition + infrastructure
    └── director_prompt.py        # → 转发到 domain/slot_planner
```

**关键拆分决策**(按硬约束):
1. **`tts_client.py`(1140行)** → 按 TTS 引擎策略模式拆分(`dict[str, TTSEngine]` 分派,替代 6 个 `if engine == ...` 分支)+ 静音切分入 `infrastructure/audio.py`
2. **`slot_workflows.py`(920行)** → 8 个 `execute_*_slot` 各为独立 UseCase,共享 ffmpeg 渲染提取; `prepare_comfyui_storyboard` 单独成模块
3. **`schemas.py`(864行)** → 拆成 `schemas/` 包(`__init__.py` 汇总 + 分文件),每个 <250 行
4. **`director.py`(864行 router)** → 路由保持薄,后台编排抽到 `application/`,只留 handler 转发
5. **`composition_service.py`(593行)** → 合成管线拆为 `pipeline.py`(分步)+ `assets.py`(素材回填)+ `audio.py`(混音)
6. **`video_tagging_service.py`(845行)** → 队列线程 + llama 探活 + 单素材管线三分,探活并入 `infrastructure/llama_host.py`
7. **`models.py`(610行)** → SQLAlchemy 模型拆 `models/` 包,保持现有 import 路径兼容
8. **`pexels_service.py`(552行)** → `PexelsService`(466行类) 拆 `pexels_client.py`(HTTP) + `pexels_repo.py`(DB/缓存) + 降维搜索策略
