## 一、改造前四层断裂实锤

| 层 | 断裂 | 实锤 |
|---|---|---|
| 文档 | 讲书稿本有【A-B秒｜段名】六拍标记, 但人工修稿入口整稿覆盖零防护 | `books.py edit_episode` — ep1(三轮人审)/ep2(0917 晨修稿)全裸稿, ep3-9 未人工动过标记健在 |
| TTS | 分包只按字数贪心(≤140字句末收包), 标记完全不参与 | `lines.py _group_lines_semantic` — 19 包与六拍零对应; 唯一语义断包=情绪墙 |
| 切场 | plan_arcs 让 LLM 自由切 4-9 场, 标记只当"估算参考" | `director2.py` 旧 prompt "场边界**参考**包边界" |
| 分镜 | LLM 自报 t_start/t_end/duration_s → 贪心落位→字符流对齐→stretch_beats 三层覆写 | 提示词自认"你给的 duration_s 只是初值" — 时间输出生来就是给覆写准备的 |

**附带排雷**: `_LABEL_RE` 不认 `【0-28 秒｜钩子】`空格变体 → ep3-9 进产线时标签剥不掉, TTS 会念出"零到二十八秒钩子"(ep1/2 裸稿反而因祸得福)。

**新闻线对照**: 0916 新闻线 segment_refs 零复写协议(句编号表+引用, token 降 ~70%, 28 slot 零漂移)早已验证正解 — 本次平移到动画线。H3 侧"LLM 只填内容不发明结构"哲学(h3.py 拍壳)终于贯彻到规划侧。

## 二、架构定案

```
讲书稿(六拍标记必出)                    ← 生成侧 <6 段进打回链自动重试
   │ module_map.parse_modules → Episode.module_json [{idx,name,tail}]  (tail 锚=模块末行文本)
   ▼
TTS: 模块墙强制断包(复用情绪墙机制)      ← 模块内句贪心; 模块尾气口 1.5s; manifest 每包带 module_id
   │ 包级时长实测 = 时长真相源(标记内秒数弃用)
   ▼
切场: 场=模块, module_windows 系统定界   ← LLM 零时间输出只填隐喻; 单模块>70s 按包界分窗
   │
   ▼
分镜: refs 协议 — 句级表(编号|实测秒|文本) LLM 只出 "refs":"c01-c03"
   │ expand_refs_groups 查表回填 t/narration + 密度执法(<4s 并邻镜)
   ▼
核验/装配: 时长核验表按模块分组; 镜界=句边(闸门与规划同一张句表)
```

关键设计决策:
- **tail 锚而非行号**: 模块边界锚=末行文本, 任意文本形态(原稿/清洗稿/Segment 行/改字后稿)重定位, 免行号口径漂移(物理行≠Segment 行的坑实测过);
- **墙定位下沉 TTS 入口**(`tts_service.generate` 在 tts_adapt **之前**纯文本上定位 — 拼音标注会改文字致锚失配); 墙是派生值不落库;
- **确定性修复优先**: refs 越界 clamp/漏句并邻镜/乱序排序/<4s 并镜全是系统兜底; refs 整体不可解析才回退旧路径(半查半猜最危险);
- **兼容**: 无 module_id 的旧 manifest → TTS/切场全走原路径零影响; 老库自动迁移 module_json 列。

## 三、落地清单(12 文件改 + 4 新测试)

**A 文档层**
- `app/services/book_service/module_map.py`(新): 解析器(容错空格/全半角竖线)+`find_walls`(顺序贪心锚匹配, 失配如实报)
- `episode_gen.py`: 生成后落 `ep.module_json`; <6 段进打回链(与字数/概念校验同链自动重试)
- `books.py edit_episode`: 修稿丢标→保留旧模块表+返回 `module_warning`(元凶入口堵死); 进产线: 旧集现解析回填
- `script_parser.py _LABEL_RE`: 空格变体容错(排雷) + 六段校验段名规范化
- `models/book.py Episode.module_json` + `database.py` 迁移

**B TTS 层**
- `scripts/tts_lib/lines.py`: `synthesize_lines(module_walls, module_breath_sec=1.5)` — 墙并入 walls 集合(与情绪墙同机制断包); `_apply_breath_pauses(module_final)` 模块尾气口取 max 不叠加; `_stamp_module_ids` 包标 module_id
- `tts_service.py generate(module_json)`: tail 锚在当刻行序列定位(tts_adapt 前)
- `audio.py`: script_id→Episode→module_json 透传

**C 规划层**
- `director2.py module_windows()`: 模块界=场界, >70s 包界分窗
- `plan_arcs` 模块化分支: 场列表系统固定, LLM 只填 narrative/隐喻/motion, arcs/groups 系统定界零归一; planner_flow 标"模块总线"
- `director2.py refs_parse/expand_refs_groups`: refs 解析(c 区间/列表/裸数)+查表回填+漏句并邻镜+密度执法(_SHOT_MIN_SPAN=4.0)
- `plan_scene`: prompt 给场窗句级编号表+refs 输出制(禁 t_start/t_end/narration); 展开成功走精确时间, 失败整场回退旧路径
- `planner.py`: manifest 挂 `sent_table`(=`anim_draft.sentence_table` 包→句静音吸附版, 0916 归真设施升格公共); module_id 透传
- `anim_draft.py`: fetch_episode_audio 透传 module_id; `sentence_table()` 公共包装

**D 执法层**
- 密度下限 4s 确定性并镜(在 expand_refs_groups 内, LLM 想碎也碎不了)
- `duration_audit/write_duration_sheet`: 场级表加模块列

**测试**: `test_module_map.py`(6: ep3 真稿六墙全定位/ep2 裸稿空表/修稿恢复/清洗排雷) + `test_tts_module_walls.py`(3: 墙断包/归属/字数贪心让位) + `test_module_windows.py`(4: 模块界=场界/超长分窗/旧 manifest None) + `test_refs_protocol.py`(7: 解析形态/漏句/并镜/回退/越界/窗过滤) — 全套 **212 passed**, 改动行 ruff 错误 **0**(存量 101 不受影响)。
