## 二、核心架构 (链路)

```
plan (LLM 两步: 导演+转译)
  → shots.json (单一事实源)
    → k2 (ComfyUI 2ST 配方 ~15s/镜)
      → qc (qc_sheet.html 人检)
        → approve (--ok s01,s02 / --redo s03)
          → h3 (节拍式提示词 ~102s/10s镜)
            → anim/*.mp4
```

状态机: `planned → img_done → approved → anim_done`
打回: `img_done → planned (换seed)` / `anim_fail → retry (换h3_seed)`

## 五、导演提示词精华 (62 镜实测, director_prompt.txt 全量)

### 安全动作词 (全部实锤可用)
- `slow push-in` / `dolly in & dolly out` (拉近拉远) / `quick zoom-in burst` (急推定格)
- `orbit` 环绕 (s59 实证) / `camera holds fixed` (定焦, 内容必须动)
- `glow gently` / `fade one by one` / `screen-only change`
- 微表情: brow furrows / shoulders drop / 眉梢一扬 / 嘴角微扬
- 走出/走入画面 (s60 实证) / 弯腰拿取道具 (s60)
- 角色从光门走出 (s45/s11) / Q版变身 (s36) / 燃烧小宇宙 (s12)
- H3 可渲染中文/英文/数字, 且可控字体 (s62/s27/s07 三实证)

### 禁令 (全部实锤翻车)
- ❌ 全场景几何形变 → 改阴影/亮度变化
- ❌ 元素巨变生长 → 改渐显/发光
- ❌ 分屏结构重排 → 改光晕呼吸
- ❌ 原地行进 (跑步机鬼畜) → 改走出画面
- ❌ 长距离框内位移+道具 → 改镜头推近
- ❌ 长垂直上推 >1.5s (s24 卡顿) → 改推近+主体变化
- ❌ 急推+转身/特效叠加 (s62 卡顿) → 一镜一事件
- ❌ 露脸不钉长相+表情 (s59 变老脸) → 双约
- ❌ 整拍纯静止 (H3 自由发挥穿模) → 每拍至少一个可见变化
- ❌ 镜面反射 (同步错位重影) → 反射面静止模糊

### 关键纪律
- **微叙事黄金范式**: 时段氛围 + 人物姿态(背影/侧影/无脸) + 道具讲故事(3块屏各有内容/咖啡冷掉) + 冷暖光色对比
- **情绪曲线管理**: 禁全集哀愁化; 巅峰段必须给金色盛午, 全集低谷 ≤1/3
- **隐喻轮换**: 同道具最多 2-3 镜; "空间耗尽"可用走廊/容器/电梯/楼梯/水池/门/胶卷/钟
- **page_type**: C=全帧动画页(钩子/隐喻/结尾, 2-3/集) / B=稳定落点页
- **短视频节奏**: 0-25s 段长 2-3s; 25-60s 2-4s; 60s后 3-5s; 每镜首拍 1s 内有可见变化
