## 一、案情与根因链 (ep2 音画错位)

用户实锤: 剪映时间轴切镜点在语音正中间 + 58.5-60.3s 超长静音+粉卡。三层根因:

1. **装包吸附边缘落空** (s42/s43): `_comma_split` 比例切点距停顿 1.202s, 超吸附窗 1.2s 仅 **0.002s** → 落回比例点切在语音正中。60s 特区硬界同理切在"书/里"词中间 (s11/s12, 真实停顿就在 0.4s 后, 但 -30dB 检测档下微顿不存在)。
2. **气口引擎三宗罪** (超长静音): ① apad 不幂等 — 批 resume 重跑=全包再垫一轮 (008 尾 1.63s ≈ 0.8×2, 尾静音全是纯数字零 `-inf` 峰值铁证) ② 叠加律 — `max(档位) += -Xs-标记` 加法 ③ reroll 新包不垫 (043 尾 0.13s 裸奔)。**复检流程盲区**: 逐条听单包听不到接缝, full 拼接产物无人听 — 病正好藏在唯一没人听的产物里。
3. **restamp 隐雷**: 句级表孤引号/纯符号残句 norm 后为空 → `not all(norms)` 静默炸掉整集重钉 (ep3 51 镜全不动, 插桩才现形)。

## 三、气口治理栈 (用户四层定标, 三入口同一份规则)

**档位** (1010 定标, 废止 0918 档): 接缝地板 **0.3** / 段落 **0.7** / 问句 0.8 / 模块界 (钩子/解读大段落) **1.0** = 绝对上限; `-Xs-` 标记 **max 融入** (废止加法)。

```
治理栈 (幂等): ① 全包切头尾静音留 0.03 (幂等锚 — 垫的纯零必被切掉, 重跑 N 次恒定)
              ② 非末包垫 max(地板, 问句, 段落, 模块, 标记)
              ③ manifest duration 回写 (下游单真相源不变)
```

三入口接线: **批合成尾** (lines.py, lines=None 走 manifest breath_pause 档) / **reroll 尾** (单包, 放 whisper 复检后防静音进语速) / **🔄rebuild_combined** (全量过站+DB duration 同步 = 用户点的"对齐时机": 改包→点重拼→切垫对一步到位)。幂等实测: 重跑漂移 +0.02s (25 包帧级抖动, 非累积)。

**装配层配套** (anim_draft.py): voice 接缝静音闸 `_wav_edge_silence` + `_VOICE_SEAM_GATE=1.2s` (前包尾+后包头连缀超线 → 账本 content_mismatch + 警告; 阈值依据: 设计内 0.8 标记+自然气口 ≈1.1s 封顶)。`_as_video_path` 旧卡档被剪映锁 → 警告跳过不炸稿。
