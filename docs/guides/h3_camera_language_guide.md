# H3 运镜写法规范（定稿 v2.3 · 2026-10-24，九轮实验+行业调研）

> 依据：MiniMax-H3 官方 prompt 指南（`skills/h3-prompt-writing/references/base-en.txt`）+ HF 官方讨论 #47 + fuser.studio API 实测 + Wan2GP issue #2279（24 帧抖）+ 本地两轮网格（ab_cam_steps / ab_cam_lang，卓 ep6 s19/s27）。
> 状态：规范条目除标"待验证"外均为外部实证；本轮 ab_camv3 网格验证结果见文末。

## 一、已证伪（勿再试）

| 死路 | 证据 |
|---|---|
| prompt-only 离画布大幅摇 | 两轮网格：官方裸句 / 画外揭示锚 / 视点反向描述，全部被执行成**内容运动**（船开向灯塔式） |
| 堆步数求稳 | 8 步已够（官方 turbo 卡 6–8 档顶格）；10/12 步无感 |
| 链式运镜（pan→tilt→zoom 一镜连招） | 官方 expander 直接拆成多镜硬切 |
| 堆否定句禁抖（"no wobble no shake..."） | 模型把具象词当正向用（同 1012 negation 教训） |

## 二、画布铁律（24 帧周期抖）

- **任一轴 mod 64 ≠ 0**，双轴皆被 64 整除 → 横摇每 24 帧（1s）规律顿跳。
- 16:9 底图禁用 1024×576（双轴 %64=0，踩雷），**用 1024×608**（Wan2GP #2279，okkazoo 24 renders 实测表）。
- 产线节点 136 `scale_to_side longest 1024` + `round_to_multiple 32` 会把 16:9 落到 1024×576 —— 运镜镜需预裁或改参。

## 三、prompt 结构（官方两段式）

```
Part 1 instruction 行:
  I2VA: "For the target video, at 0.00 seconds, Picture 1 is fully referenced."
  FL2VA: "How the reference pictures align with the target video — Picture 1 aligns
          with the 0.00-second mark; Picture 2 aligns with the S.SS-second mark."
Part 2: 主体 → 场景 → 事件 → 镜头 → 声音 (镜头句嵌在事件流里, 非孤立行)
```

### 镜头句四要素（缺一即翻车）
1. **三维句法**：类型 + 幅度 + 速度（medium/normal 可省）：`The camera pans left with large amplitude at slow speed`
2. **嵌动作流**：作从句跟主体动作走（官方 Case 2：`...trucks right with small amplitude at slow speed as she lifts her gaze`）
3. **锚定揭示物**：`...revealing the lighthouse beam into full view`（给模型画外几何的具体目标）
4. **构图收口**：`keeping both figures in frame` / `until the horizon sinks to the lower third`

### 词汇表（勿混用）
| 词 | 语义 |
|---|---|
| pan left/right | 机身不动，镜头水平转 |
| tilt up/down | 机身不动，镜头俯仰 |
| truck left/right | 机身平移（改变视差） |
| zoom in/out | 镜头变焦（无视差，最稳） |
| push in / pull out | 机身前后移 |
| pedestal up/down | 机位升降 |
| 弧线/跟拍 | arc / tracking shot（高失败区，慎用） |

### 幅度控制
- 形容词失控时改**起止构图**：`from the boat centered to the lighthouse filling the left of the frame`
- 大幅配慢速（large amplitude at slow speed）是稳定组合

## 四、离画布大幅运镜 = FL2VA（官方钦定）

- `MiniMaxH3ImageToVideo` 可选入参 **`last_frame`**（本地 ComfyUI 已核）。
- 官方 Case 3 句式：`The camera pulls out with small amplitude at slow speed as she settles into the composition established by Picture 2.`
- **末帧来源（零生图成本）**：1920×1080 高清底图双错位 crop → 首末帧皆真实像素，模型只补中间，视点被两端钉死。
- 帧长落 17k+5 网格（8s=192），节点 134 已处理。

## 六、验证记录

- 第一轮 ab_cam_steps（s19，步数×时长网格，8 产）：全为内容运动 → 用户判"无意义"，停。
- 第二轮 ab_cam_lang（s27，三档措辞）：panleft v1 仍内容运动 → 停。
- 第三轮 ab_camv3（本规范落地，s27，1024×608，8 步 8s，104~120s/镜）：
  - **w1 官方从句式 2/2 全胜**：panleft 左摇正确且干净；tiltup 上摇"几乎无问题"。
  - **w2 JELSTUDIO 横穿式 0/2 双挂**：panleft 变画内动画（镜头没动）；tiltup 变平视→仰视的视角变形。孤立运镜句无动作流锚定 = 模型解析成构图重排。**已证伪，规范不收录。**
  - **fl2v 末帧锚**：panleft 视点右→左穿越达成（两裁切同尺度仍被感知"变焦"，模型脑补副作用）；tiltup 三无（抖/闪/晃）通过，镜头方向未单独点名。
  - **六臂全部无抖动/闪/抖动**——归因三因子：①1024×608 出 24 帧抖雷区 ②运镜配慢速 ③s27 画外内容为海雾天低频纹理（脑补容易）。复杂图（硬几何/建筑/室内）待压力测试。
  - 复盘：本轮执行器曾被中途 /interrupt 打成死锁（CPU 空转/GPU 无载/事件流静默），interrupt+free 无效，重启 ComfyUI 解决——长网格中途停跑需警惕。
- 第四轮 ab_camv4（复杂图压测，ep2 s15 室内硬几何：墙诊断表格栅+人物+工具架抽屉，4 运镜 × 2 臂，101~108s/镜）：
  - **w1 从句式 1/4 干净**：panright 完全合格（持续右转补全画面，空间逻辑正确）；panleft 变环绕+墙遮挡后消失（几何瑕疵）；tiltup 变缓推镜定位右墙画框（方向偏离）+ 画框内容中文乱码；tiltdown 变两次移动（先右移墙再下聚焦）。
  - **fl2v 末帧锚 3/4 到位 / 1 挂**：panleft 合格但用"放大聚焦"实现（变焦作弊）；tiltdown 合格（先上移再顶至底，左右画面被裁）；tiltup 合格（冒出文字卡+定格+回原位+左右裁切）；panright 失败（平移重复了 1 次）。
  - **复杂图结论**：①素材复杂度假设实锤——简单图 2/2 干净，硬几何 1/4 干净；②fl2v 锚的是**终点**不是**路径**（变焦作弊/重复/回弹都是路径自由度）；③模型舒适区仍是 zoom/push 类；④画面含文字格栅 + 运镜 = 乱码风险叠加（tiltup w1 画框乱码、tiltup fl2v 冒文字卡），产线乱码判决回流闸适用。
  - **复杂图运镜建议**：减幅度 / 优先 zoom 类 / fl2v 必须配轨迹 QC（防重复、回弹、变焦作弊）；文字密集镜慎用大幅运镜。
- 第五轮 ab_camv5（可控性种子扫描，3 条件 × +2 seed，96~108s/镜）：
  - **C1 简单图 w1 左摇**：3/3 方向对；幅度 2/3 大幅 + 1/3 缩水画内。
  - **C2 复杂图 w1 右摇**：3/3 方向对（两 seed 自发画外脑补）；1/3 路径突变 pan→orbit（焦点=工具箱，合格）。
  - **C3 复杂图 fl2v 右摇**：3/3 落点对；路径 2/3 干净 + 1/3 重复（原 seed）——**重复未复现=seed 随机，换 seed 可修复**；1/3 轻微主体动作泄漏（抽屉推拉）。
  - **可控性终判**：方向=真控制（9/9）；幅度=偏置（1/3 缩水）；路径形态=掷骰（orbit 突变/重复/变焦作弊/回弹/主体泄漏皆 seed 敏感）；fl2v 锚终点不锚路径。
  - 产线实操含义：运镜失败镜**换 seed 重 roll 即可修复路径缺陷**，不必改方案；要路径确定性只能多 seed + QC 验收。
- 第六轮 ab_camv6（内容控制三连测，A 画外物/B 真文字/C 画框内容，101~108s/镜）：
  - **A 画外内容指定 2/2**：左摇冒出指定"高绿植+玻璃隔断"、右摇冒出指定"带轮落地白板"，均照 prompt 造物。
  - **B 真文字**：英文全对（TIME AUDIT / WEEK 1-3）；中文 11 字乱 1（「计」），其余黑体正常。
  - **C1 fl2v 真像素空白锁：失败**——末帧=原图空白画框裁切 + prompt 明写禁内容，定格后仍冒**林肯画像且画中人眨眼**。**fl2v 锚构图落点，不锚像素内容**；空画框先验 irresistible。
  - **C2 prompt 正向指定：成功**——框内按指定渲染三柱上升折线图（无字）；且**相机停稳后内容动画入场，再 ~1s 停顿**（H3 自发"定格后揭示"节奏，产线可利用）。
  - **内容控制铁律：正向指定 > 负向禁止**（与 1012 negation 教训同构）。要控内容就说"该是什么"，永远别赌"不许出现"。

## 七、内容控制篇（第六轮新增）

| 控制对象 | 可控性 | 手法 |
|---|---|---|
| 画外内容（摇出原画布） | ✓ 2/2 | 运镜句内正向指定具体物体（名词+形态），H3 照造 |
| 英文真文字 | ✓ 全对 | NO_TEXT_POLICY 换成指定文字白名单；text 作为画面物理细节描述 |
| 中文真文字 | ≈90% 字准 | 同上；逐字 QC 必备（乱码闸），1/11 乱码实测 |
| 画框/物面内容 | ✓（正向）/✗（空白锁） | 指定"框内出现 X"成功；锁"保持空白"必被先验攻破 |
| fl2v 末帧像素保真 | ✗ | fl2v 只保构图落点；内容仍会被重绘（林肯反例） |

- 意外红利：**定格后内容动画入场 + ~1s 停顿**——"停机-揭示-留白"节奏是 H3 自发的，定格镜可直接利用。

- 第七轮 ab_camv7（无关图入框，D1 i2v / D2 fl2v，合成雪山照片入 s15 画框，101~108s/镜）：
  - **双败，失败模式自洽**：插入图首帧在场 ✓，但被 H3 当**漂浮物动画化**（D1 飘入画框、D2 卡通人物飞出画框），画框随后被先验重新填充（林肯/卡通人物）。
  - **机理**：①外来像素=风格异常信号，模型倾向"清除/动画化"而非冻结（对比：合成字能冻结——文字无动画先验）；②画框"框内=肖像"先验两连击；③窄条裁切（164×469）放大后细节弱，锚定力不足。
  - **结论：无关图直接合成进首帧 ≠ 内容控制**。可行路线推测（未验）：E1 插图先风格迁移成场景画风再合成；E2 **K2 阶段原生生成**（image_prompt 直接写"墙上挂雪山画"，从头生成而非外来贴图——推荐，合"修因不修果"）；E3 定格幅度减半减少重绘量。
  - 方法论：GLM 全图尺度定位小区域不可靠（合成后全图问"框内是什么"答空白，特写裁切才读出雪山）；像素 diff 是合成落点的地面真值。
- 第八/九轮 ab_camv8/v9（可控素材入镜，PIL 表格合成，F1/G1/G2 + D 组对照）：
  - **"素材飞入"是 H3 的一致处理律（4/4）**：贴入素材（照片或表格、硬贴或羽化、有无自绘框）一律被动画化并送进**场景真容器**，摆正、可读。自绘框无效——模型认原画真框（右侧棕边板，GLM 三次定位互相矛盾，颜色剖面+边缘分析定位）。
  - **alpha 羽化改善落点贴合**（G2 vs G1），无透明伪影——透明假设部分成立。
  - **冻结模式（首帧在场+定格保真）合成路线 0/4 未达成**；要冻结走 K2 原生生成。
  - **产线可用的素材入镜配方（飞入模式）**：素材贴入首帧（alpha 羽化更佳）→ H3 自动飞入场景容器 → 定格可读。本质是"让模型自己完成动画导演"。
  - 方法论补遗：GLM 全图/区域定位均不可靠（坐标三次矛盾），像素颜色剖面+边缘统计是容器定位的地面真值。
- 第十轮调研（1024 用户令 X，网查行业教程）：**素材入镜第三条路=后期叠层，行业标准**：
  - 45k 字 Seedance 2.0 漫剧实操手册（多模态引用/首尾帧/台词嵌入全覆盖）**通篇无"系统界面/图表入镜的生成内方案"**；@引用做的是全图风格/角色一致性，不是素材插入。
  - 漫剧"系统面板弹出"特效生态 = **AE 模板 / 剪映模板 / 特效素材站**（aigei、motionelements、新CG儿、哇噜剧厂等）——全部是**剪辑期合成**，不是生成期。
  - 与本产线已有机制同构：1021 事件字停渲→后期叠字（h3_text_event 仅作数据源）、品牌卡、text_layer。**素材图挂件=同一模式的图片版**。
  - **三路分工定稿**：像素级可控表格/文章/系统面板 → **后期叠层**（H3 出干净定格底 + 剪映装配叠图入场动画）；画内原生内容 → K2 原生生成；软保真装饰性内容 → H3 prompt 正向指定。
  - 措辞规范补充："复现表格图"是元指令，H3 无此概念——只写"可见内容"（C2 句式）：`镜头推近画框，框内呈现【逐项内容】，清晰可读`。
- **产线落地（1024 B-CAM1，bd6ac30 + 4cbe2fa）**：h3.py 运镜镜通道（camera 触发词 → 608 预裁 + prompt 三补丁 + 剥 locked-off，普通镜零变化，+4 测）+ director2 枚举×4/规则×5 解锁。实弹验证 s27 左摇 104s ✓。规划器下集起可发运镜镜；素材入图线封存（B-CAM3 不做，走剪映后期叠层）。
- **B-CAM1 边界实录（1024 ep6 首批实操）**：
  - ✅ h3 工位全通：s12 空镜（拉远）走新通道 ✓（首条产线运镜镜日志实锤）。
  - ⚠️ **r2v 工位未适配**：人物镜（keyframe 命中圣经角色名）路由进 r2v（h3.py:_pick_video_station），r2v.py 有独立 prompt/workflow（4 步 beta 弹匣）——运镜词进去=裸奔（无 608/无补丁，4 步大幅=拖影区）。人物镜运镜 → 挂账 r2v 适配。
  - **操作铁律**：①已完结镜重跑走 `reroll`（`only` 只吃 approved 态，静默空转）；②redo-queue 会重规划覆写手改 camera——运镜补丁必须在规划之后打、直接 H3，永不走 redo-queue。
- **幅度时长边界（1024 ep6 s12 三连实测）**：4.46s 短镜三测（原 seed 不动 / 换 seed 小幅 / 换 seed+起止构图句仍小幅）——**幅度天花板由槽长决定**，"large amplitude at slow speed" 在 <5s 里物理上折中为小幅；8s 镜无需技巧即全幅。**选镜铁律：运镜镜只给 ≥6s 槽**。挂账②（起止构图句）关闭：无效且长镜不需要。
- **第十一轮 ab_camv11（R2V 素材参考图入镜·体外，1024 用户提出路线）：基本成功**。
  - 路线：素材图作 Object reference（`fully_preserved`）+ prompt 角色映射（"shows exactly the table from the first reference image, redrawn in the scene's art style"）+ 定格持镜句。复用产线 r2v._build_workflow 原配方 **4 步 beta** 零加价。
  - **第五条素材入镜路 = 参考图通道**：模型按场景画风重绘参考内容，绕开贴图的风格异常死因（对照 v7/v8/v9 贴图 0/6）。
  - 依据：ethanfel 参考媒体指南（参考角色系统：Object/prop/interface 官方用途）+ 官方 R2VA 多参考。
  - **12 步定稿（R2 实测"完美"）**：4→12 步字清晰度/融合显著提升，无过锐塑料感（4step_v0.1 蒸馏线高步风险未兑现）。跑时 104s→177s（弹性 ~1.7x）。**素材参考镜配方 = Object reference + 角色映射 + 定格持镜 + 12 步 beta**。
  - 参考图规格=短边~800、近目标纵横比。
  - **R3 照片对照（同雪山图跨机制 A/B）：完美**——贴图路线 0/2（飞入+林肯）vs 参考通道 12 步完美。两类素材（文字表 + 照片）双验证通过；照片配方加 "completely static, like a printed poster" 定向疫苗（防画中物动画化）。**⑤路已固化（1024 B-ASSET1，5cea57c+8f7796d）**：镜级字段 `{image(相对ep_dir), anchor_en, content_en, has_text, hold_en}` → 映射句+定格持镜+text-only 分支+12 步档+软超时×2；工位路由显式意图优先；refs=[人物…, 素材, 场景]（ordinal 自动）。**操作铁律：素材镜 reroll 重跑，永不 redo-queue**（规划覆写手改字段）；素材镜宜 ≥6s 槽（settle+hold+可读）。
  - **content_en 枚举铁律（1025 s15 产线首跑实锤）**：content_en 必须逐项枚举素材内容（标题/栏头/行标/数值、"nine cells only, one value per cell"）——只写 "a time-audit table" 一句话 = 结构对但**字级漂变+格子增殖**（10h 满屏、值帧间不稳）。R2"完美"的关键细节就是枚举。
  - **稳定性定律（1024 用户定稿）：入画 > 入文字**——图类素材（照片/图形/图表形）参考入镜最稳；文字是最脆模态（生成 90% 字准、参考通道需 12 步+逐字 QC）。素材能画成图就别写字，逐字精确的文字走后期叠层。- 挂账：①环绕焦点能否 prompt 指定；②幅度锁定（起止构图句）；③白板上写字（画外发明物+物面文字组合技）。

## 附: 官方完整运镜词表 (1105 网络核对, 与产线 6 词白名单的关系)

`Zoom In/Out` · `Push In/Pull Out` · `Pan Left/Right` · `Truck Left/Right` ·
