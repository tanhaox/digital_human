## 四、合规红线（与本产线直接相关）

1. **数字人直播标注**（国家级新规，硬性）：虚拟主播必须显著标注「AI 生成/虚拟主播」并全程披露。本项目若上直播带货，采用「数字人出镜 + 真人后台互动」半无人模式，纯循环话术无人值守会被限流。
2. **站外导流趋严**（自媒体口径，2026「零容忍」趋势）：引流私域卖课/卖资料的路径风险上升，不在主线考虑。
3. **算法权重**：2026-09 算法大更新后短视频完播权重显著提高（自媒体称约 7 成，单一来源低可信）；对产线的含义与既有「完播优先」北极星方向一致，无需调整。

## 五、UNKNOWN（未可靠确认，勿引用为据）

- **中视频伙伴计划 / 创作者伙伴计划**：2026 年确切门槛与分成现状各方口径不一（有说 1 万粉，有说已并入创作者中心账号体系 2025-08）。确认方式：直接看 APP「创作者中心 → 收益中心」本账号实际开放的入口。
- **小程序挂载 500 粉门槛**：单一来源（2026-03 媒体文），动手前以后台为准。

## 六、本项目读书号（book 719051）变现路线

1. **主线**：视频挂车卖书（500 有效粉解锁）→ 橱窗同步铺货 → 1000 粉冲星图正式入驻（广告商单）。
2. **副线**：小说推文（番茄/红果）与讲书视频形态复用度极高；同一条视频双挂（车 + 推文链接）是否冲突需小流量实测。
3. **直播**：200 粉已达标，但先解决数字人标注合规再启。
4. **不做**：付费合集（已下线）、站外导流（风险）、团购带货（不匹配）。
