## 0. 这是什么

**数字人短视频生产流水线**（FastAPI 后端 + SQLite + 本地 GPU）。输入新闻/书/PPT → AI 洗稿/拆书 → 视觉五步 → TTS 配音 → 剪映草稿 → 人工精修导出。当前 5 条产线：**新闻线 / 拆书 / PPT 出片 / 导演(J线/HF) / 动画(黏土)**。

## 1. 技术栈

- Python 3.11 + FastAPI + uvicorn（`run_web.py`，端口 54321）
- SQLite + SQLAlchemy（`data/pipeline.db`）
- LLM：kimi 主力 → qwen → deepseek 三级链（`llm_service.py`）+ 本地 Gemma-4-31B crack（蒸馏线，llama.cpp b11235 + MTP drafter 2.2×，`distiller.py`）+ Qwythos-9B（视频打标，独立 8080）
- TTS：IndexTTS2（主，gpu_service_manager 托管 4090）
- K2 静帧：ComfyUI Krea2 turbo（2ST 配方，本地 4090）
- H3 视频：ComfyUI MiniMax-H3（图生视频，本地 4090）
- VLM 守门：glm-4v-flash（云端免费，`reverse_prompt_service._chat`）
- 剪映草稿：pyJianYingDraft

## 2. 产线地图

```
新闻线: 文章 → 素材包(七层审计+智谱补搜) → 洗稿(laotan-tech/geo) → TTS → 导演 → 剪映草稿
拆书:   书 → 蒸馏(碎节合并) → L0 → facing → 总纲(240s×5-10集) → 逐集稿 → 动画线
PPT:    上传pptx → 每页台词TTS → 元素级拆解(jy2) → 剪映多轨草稿
导演:   音频对齐 → slot规划 → broll/HF/host执行 → 合成 → 剪映草稿
动画:   大纲 → 🎨风格选型 → 📖艺术圣经 → 👥角色设计 → 🧭规划+增强 → 🎨K2 → 🎬H3 → 剪映
```

## 3. 视觉五步流程 (0923-0924 新增)

```
大纲完成 → [讲书页步骤3工具栏]
  ├─ 🎨 风格选型 (style_board.html)
  │   ep1 钩子段切 3 试镜镜 → 风格库全员 + Kimi 新配方提案
  │   → 选择板(排除/留存/重调/选定) → 落绑定(风格绑定_{书名}.json)
  │   → 无绑定动画开工硬挡板
  ├─ 📖 艺术圣经 (style_bible.html)
  │   灵魂三问+受众+选定配方 → Art Director LLM
  │   → 圣经(色板/质感/角色出场策略) — 0928 起只管视觉身份, 不产 characters
  │   → 重掷保卡(缓存里已有角色卡原样带过去) + 角色卡变了自动重渲定妆照
  ├─ 👥 角色设计 (style_characters.html) — 0928 自动化闭环
  │   🎲 从各集提炼: 各集贯穿人物(硬覆盖+确定性覆盖校验)+成稿节选+故事库
  │   → 角色卡(作者卡每本书必含) → 人检改 look → 先渲一张对了再批量
  │   → 定妆照=最简纯白背景人物参考图(风格LoRA摘除+纹理词消毒, 禁铬面/流体上身)
  │   → _资产/角色设计/{书}/ 跨集复用; look 改了重新生成即换装
  ├─ 🧭 规划 (anim.html)
  │   导演 LLM: 叙事/切镜/角色(基础画面句) + 拉片子×故事的解剖内功
  │   → 装包制 DP 切镜(比例罚, 60s 特区 12-18 镜) → 立意人闸
  │   → ▶️分镜续跑 → 一致性巡检 → 分身重设计
  │   → 自动增强: 摄影级视觉层次(光线/景深/空间/氛围, 200-300字)
  ├─ 🎨 K2 批生图
  │   清洁工(剥hex/英文前缀/指纹/手工捏制残留) → 角色确定性注入
  │   → 构图BOOST(中文,三层景深) → 防字尾(换词版: 禁区词根零出现)
  │   → 终串机检 prompt_gate(观察模式: 扫拼装终串, 标记不阻断)
  │   → 违禁守门(OCR+VLM双道) → 政治硬违禁绝不落盘 / 文字软违禁标记人检
  │   → 批跑完自动释放显存(ComfyUI /free)
  └─ 🎬 H3 批生视频(出片后 video_qc 抽3帧机检: 崩坏/乱码/首帧漂移 → 🎥徽章交人检)
      → 🎞装配剪映草稿
```

## 4. 模块地图（app/）

- `routers/`：articles / materials / scripts / audio / **books(含风格选型/圣经/角色/发布卡)** / ppt / library / **anim(/api/anim)** / jobs(SSE) / _sse
- `services/`：
  - `book_service/`：reader / l0 / facing / **distiller(碎节合并+云审计分块)** / orchestrator / series_outline(总纲重修轮) / **fandeng_full** / cover_render / feed_registry
  - **`anim_pipeline/`**（动画产线核心）：
    - **`style_board.py`**：风格选择板(试镜/提案/排除/留存/重调)
    - **`character_sheets.py`**：角色设计台(定妆照/竖版9:16/跨集复用)
    - **`director2.py`**：导演规划 + 提示词增强器(enhance_keyframes) + validate_doc(花字/禁区/时长) + 角色锁定卡注入 + 宪法注入 + 叙事内功(拉片子×故事的解剖)
    - **`k2.py`**：2ST 配方 + 清洁工(_clean_scene) + 构图BOOST + 角色注入(_inject_char_looks) + 打回负面词剔除(strip_negative) + build_workflow_i2i(定妆照垫图旁路, opt-in) + 违禁守门(render_gated: OCR+VLM双道, 硬违禁绝不落盘)
    - **`prompt_gate.py`**：终串机检(观察模式) — 扫拼装终串禁区词根/否定式堆叠/主体锚/超长 (0927 反哺)
    - **`video_qc.py`**：H3 视频产物机检(观察模式) — 抽3帧查崩坏/乱码/首帧漂移, video_suspect 徽章交人检 (0927 反哺)
    - **`h3.py`**：图生视频(节拍壳+时长=槽铁律)
    - **`hook_zone.py`**：60s 特区装包(DP 比例罚, 治1镜60s)
    - **`covers.py`**：书封提取(OPF id→href 查表 + 文件名含cover优先)
    - **`brand.py`**：品牌卡(骨架冻结: 坐山顶看书首帧+红色冲锋衣+单背包)
    - shots / planner / run / tts / comfy / llm / config / qc
  - `anim_service.py`：GPU 相位管理(批跑完自动 free_memory) + 政治禁区软拦截(标记+跳过, 不拦全队)
  - `anim_draft.py`：装配 + 开场白生产(atempo 1.5× 加工步) + 微降速
  - `compliance.py`：统一禁用词 + **visual_constitution_prompt(画面宪法, 五端注入)** + check_visual
  - `llm_service.py`：三级链(kimi→qwen→deepseek) + 熔断
- `models/`：content / book / director / roles / assets

## 8. 蒸馏管线 (0923 提速)

```
书 → read_book(覆盖率94%) → build_batches(碎节合并 ~15k/包, ≤40k 军规)
  → 库全员 + Kimi 提案(卡通红线/家规/人物形态锚/LoRA清单内实选)
  → 4-5 风格 × 3 镜 = 12 张 K2 渲染(同镜同种子)
  → 选择板 → 落绑定

Gate A 合规审计: 池 JSON 切 30k/段, 单段 180s, 失败重试1次后跳过
```

## 9. 分集策略 (0922-0923)

```
单集时长: 老谭读书 = 240s (指标: 1min 及格线 = 进度25%, 收藏最高权重)
集数带: [5,10] (导演按书定, 系统守不变量)
总纲: run_series_outline + 重修轮(校验不过带问题重试)
```

## 10. 违禁守门体系 (0923)

```
正向: PROTECT_TAIL(灭字+政治敏感+军警+文字载体) — K2 层每镜注入
源头: visual_constitution_prompt — 圣经/试镜/提案/重调/分镜五端注入
事后: render_gated —
  ① OCR (真文字, 毫秒级)
  ② VLM glm-4v-flash (伪文字/国旗/国徽/军装/地图/政治人物, 秒级)
  ├─ 文字类(软): 重掷后仍脏 → 保留+标记人检
  └─ 政治类(硬): 重掷后仍脏 → 恢复旧图或删图(绝不落盘)
```

## 11. 提示词增强器 (0923)

```
导演 LLM → 基础画面句(叙事/切镜/角色)
    ↓ 自动触发(规划/续跑/重规划完成后)
增强器 LLM → 补光线/景深/空间/氛围(200-300字, 禁hex/指纹/手工捏制)
    ↓
K2 清洁工 → 剥残留(英文前缀/hex码/指纹/悬空句)
    ↓
build_prompt → 风格头 + 干净画面句 + 构图BOOST + 防字尾 + 轻锚
```

## 12. 前端基础设施 (0923-0924)

- **灯箱**: `web/lightbox.js` 全线统一(点图放大, Esc/✕/点外/←→切换)
- **confirm**: 原生 confirm(保安全确认), 不覆写
- **SSE**: 圣经/试渲/选板/重调/角色设计/规划全接 `/api/jobs/{id}/events`
- **补生图**: 场头按钮(打回/跳过/失败/违禁/拒绝记录 → 精准补漏)
- **打回负面词 (0927)**: 弹窗填"墙/文字/多人" → 画面句含词子句整体剔除(确定性零LLM, 双写keyframe防重规划带回) → 换seed重生成
- **购物篮两路线 (0927)**: ♻️列队重做(一条龙到视频) / 🎨重做到生图(停img_done走人检)
- **立意面板 (0927)**: 状态行(立意闸等待/还有N场待分镜) + ▾收起/▸展开(腾分镜预览区)
- **花字规则**: 相邻镜禁重复 + 禁裸数字 + 禁单字 (增强器+验证器双执行)
