# 选书准入闸 SOP (v1.1, 1103 用户七令修正案)

> 2026-11-03 立。背景: 书单曾由豆包"从窄到宽"人群进阶规划 → **坡度思维判死**
> (抖音每条独立抽签, 观众不陪爬坡 — 与"抖音不吃坡度"同律); 账号人群**永远锁定白领阶层** (1103 用户令)。
> 本 SOP 取代豆包推荐作为选书唯一准入; 产出函数依据: 24 正片实测 — 吸粉率≈常量 98/万播, 播放由选题池宽决定 (白领公约数档=已测顶档, 天花板 11.4k; 老板级/从业者级 2.0-2.4k 均播)。

## 用户七令 (1103, 本 SOP 的法源)

1. 以书进行内容输出是本账号的核心 — 书是内容单元, 不改
2. 书可任意选, 但必须落在白领人群; 尽量涨粉避免掉粉
3. 5s 跳出率是短板, 但与吸粉纯度矛盾 → 解法见 §三 (闸门不动卡, 动时长与卡后钩子)
4. 顾问书全书发完, 双日更 (至 ~11-13); 后续选书池宽可更大, 但主标签粉丝群可接受
5. 单集精简: 5+min → **3-5min** (时长越长越拿不到完播率标签)
6. 三闸 SOP 修正 → 本文件 (四闸)
7. 选书先从库内 (L0 蒸馏库 + 项目库), 不合适再特别加书单找电子书

## 四闸 (任何一书入库/立意前过闸)

### 闸一 · 人群闸 (书级)
- **通过线**: 主读者 = 白领自己 (自我管理/时间/精力/沟通/决策/职业成长/情绪)
- **允许的"更大池"**: 白领邻域 — 心理成长 / 沟通表达 / 思维方法 (泛职场可迁延)
- **禁入**: 老板级 (经营/战略/用人/组织) · 从业者黑话级 (营销方法论/顾问技术/行业纵深) · 纯生活情感 (亲密关系/育儿) · **心理类** (1103 用户令: 抖音对心理学内容有算法压制, 无资质限流风险)
- 判例: HBO=老板级✗ · 定位=从业者级✗ · 顾问=从业者级✗ (发完即止) · 卓 ep2/3=白领级✓ · 蛤蟆=心理类✗ (1103 弃, 算法压制)

### 闸二 · 痛点闸 (书级)
- ≥3 个"每个白领本周就遇到"的痛点 (被会议切碎/贡献不被看见/优先级失守/向上沟通/精力耗尽/职业焦虑)
- **去书名测试**: 痛点句去掉书名后, 还像不像白领的周报吐槽; 不像 → 不过

### 闸三 · 章级立意闸 (每集, 产线内)
- 主角 = "你(白领)"; 名人/公司案例可用, 但痛点必须落回白领自身动作
- 判例: 卓 ep4"拿破仑选将"(主角=管理者) 1,186 播 vs ep2"你的时间去哪了" 11,976 — 同书同产线, 立意视角定池宽
- 产线化(代码批, 待令): 立意层注入视角检测 + 单集立意评分卡

### 闸四 · 时长闸 (每集, 1103 精简令)
- 目标档 **3-5min**; 稿件字数 ~900-1100 字 (4.3字/s 口播), 案例 ≤2 个/集, 拆解保持三步制
- 账: 同均看时长下, 5min→3.5min = 完播率 ×~1.4 → 完播标签获取概率同步抬
- 存量超长稿 (1632字级) 不回改, 增量执行

## 来源优先级 (1103 令七)
1. **L0 已蒸馏未用** (高效能七习惯 / 非暴力沟通 / 赢✗老板级)
2. L0 已蒸馏已用但未发完的存量定稿 (蛤蟆 6 集定稿未发布)
3. 库内 epub 未蒸馏 / 新书单特批 + 找电子书资源

## 回验闭环 (每书 Tx 必做)
- 按档位标签回归: 均播 / 吸粉率 / **掉粉率** / 兴趣聚集 (画像快照)
- **掉粉红线 (令二)**: 掉粉率异常抬升 = 池过宽/标签漂移信号 → 下一本回撤一档 (阈值首标后定)
- 连续一书滑档 → 闸参数复检, 不静默调参
