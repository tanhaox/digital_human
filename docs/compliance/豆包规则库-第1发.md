# 抖音自媒体时政/国际关系/历史/军事/财经解说口播视频 审核规则体系
>说明：本体系基于抖音公开社区公约、网信办监管文件、多模态审核公开技术文档、大量创作者实操复盘整理；**标注确信等级：确定=平台公开规则/技术文档明确；较确定=大量案例反复验证；推测=行业实操归纳，平台未公开文档直接写明**。

## 一、审核机制层
### 机器审核（一审）【确定】
视频上传后立刻执行多模态并行审核，输出风险标签，决定是否放行、直接拦截、送入人工复审队列。
1. **关键词库（规则引擎）【确定】**
    - 作用：精确命中黑名单词条，高危词条直接拦截不予发布；中低风险打上风险标签，压低推荐权重，推送人工复审。
    - 方式：AC自动机匹配；支持子词匹配；会做文本归一化（过滤空格、特殊符号、全角半角转换），干扰符号无法规避匹配。
2. **语义大模型（NLP）【确定】**
    - 作用：不单单看单个词，解析整句、整段上下文语义，识别煽动对立、片面抹黑、谣言、主观极端定性、暗示性表述；**同一个词，不同上下文判定结果不同**。
    - 方式：识别句子立场、情绪倾向、逻辑，区分客观陈述事实vs主观煽动输出；对"把政客行为扩大到整个国家民族"这类句式做风险识别。
3. **画面识别（图像OCR、关键帧识别）【确定】**
    - 作用：识别视频画面、封面、贴纸、花字、片尾字幕的文字；识别敏感符号、错误地图、暴力历史血腥画面、违规影像素材。OCR识别字幕准确率极高，字幕、封面文字权重等同于口播文稿。
4. **语音识别ASR【确定】**
    - 作用：把口播语音完整转写文本，和字幕分开独立审核；**口播说错一个词，哪怕字幕没有，一样触发风险**；同时识别音频情绪烈度，过激情绪会提升复审概率。

>机器审核输出三类结果：①直接拦截，发布失败；②打上风险标签，冷启动有限分发；③送入人工复审队列；④正常进入流量池。

### 人工复审（二审）【较确定】
#### 触发人工复审的条件（满足任意一条即触发）
1. 机器多模态模型判定为**疑似风险**，无法直接放行/拦截；
2. 视频流量快速上涨，进入更大流量池（流量越高复审越严格）；
3. 短时间出现批量举报、大量评论区质疑、高占比"不感兴趣"负反馈；
4. 内容属于高风险类目：时政、台海、军事、国际关系、近代战争历史、宏观财经军费；
5. 重大纪念日、敏感时间节点，平台提升该类内容复审比例；
6. 账号历史有同类违规记录，该类内容默认优先复审。

#### 人工审核员重点看什么【较确定】
1. 整体立场：是否对齐我国官方公开口径；是否煽动民族/国家对立；是否歪曲历史；
2. 区分：批判对象是**政客/势力**，还是扩大到整个国家、全体国民；
3. 事实真实性：史料、国际事件、军费数据、人物言行是否属实，有无编造；信息来源是否可信；
4. 情绪尺度：客观分析批判 vs 人身辱骂、渲染仇恨、极端煽动；
5. 标题、封面、口播、字幕、画面素材是否互相矛盾，一处违规整体处置；
6. 账号历史违规记录，同类反复踩线会加重处置。

### 限流分级形式以及对应违规程度【较确定】
1. **隐性限流（无站内信通知）**
    违规程度：擦边风险、语义有争议、数据来源缺失，没有明确硬性违规。
    表现：视频发布成功，无违规通知；播放量显著低于账号正常水平，冷启动流量池压缩，无法进入中高流量池，可以被粉丝刷到。
2. **仅粉丝可见【较确定】**
    违规程度：中度风险，存在明显表述瑕疵，不适合公域分发。
    表现：外部用户刷不到，仅粉丝主页可看；无公开推荐；可修改重发。
3. **减少推荐（有/无站内信）【确定】**
    违规程度：存在违规，但情节较轻，不直接下架。
    表现：保留视频，公域大幅降低推荐；部分场景附带风险提示标签。
4. **视频下架（删除处置）【确定】**
    - 轻度下架：表述不当、情绪化表述、事实瑕疵；单条下架，不一定扣分；
    - 重度下架：篡改历史、错误主权表述、煽动仇恨、造谣；伴随账号健康分扣除，记录留存账号档案。

>补充：**老视频回溯复审【推测】**；平台会定期存量巡检，旧视频符合新规也会被处置，出现老视频莫名掉播放、下架。

## 二、风险词库层
>重要：不是出现词就必处罚，**结合上下文语义判定；同样词汇官媒与自媒体尺度不同**。
### 分级说明
- 直接删除级：出现，大概率直接拦截发布/视频下架，严重伴随扣分；
- 限流级：不一定直接删，极易触发复审、隐性限流，高概率无法起量；
- 观察级：单独出现风险低，但是和其他敏感表述叠加，就升级为限流风险。

#### 1）时政国际类高危词完整清单
##### 直接删除级【确定】
1. 分裂、台独相关错误表述；模糊一个中国原则，两岸对等化表述；错误地图；
2. 恶搞、诋毁国家领导人、英烈、革命历史；洗白侵略历史、军国主义洗白；
3. 泄露、编造我方未公开军事机密、涉密装备参数；编造我方高层小道消息；
4. 美化法西斯、日本军国主义侵略行为；精日洗白言论；
5. 鼓吹战争、煽动冲突、鼓吹暴力报复；鼓吹无差别仇视他国国民。

##### 限流级【较确定】
1. 网络辱骂代称：拜鬼、鬼子、倭寇；狼子野心、歹毒、丧心病狂；
2. 全盘定性国家："XX国家骨子里就是……""这个民族本性……"，把政客行为等同于整个国家；
3. 自媒体自创绝对铁律：圈里铁律、千古不变、注定、必然、百分之百、永世；
4. 博眼球夸张话术：惊天内幕、绝密爆料、万万没想到、细思极恐；
5. 未经证实消息标签：网传、圈内爆料、外网消息（不写具体来源）。

##### 观察级【较确定】
魔鬼、修罗场、阴谋；霸权（仅限定政策可，全盘扣国家慎用）；崩盘、大乱；（单独使用风险低，大量连续使用风险上升）。

#### 2）分领域专项敏感表述【较确定】
**涉日（近代历史、靖国神社、二战历史）**
❌高风险表述：把参拜靖国神社简化为香火钱做戏谑调侃；全盘定性日本全体国民；美化甲级战犯；否定南京大屠杀等史实；使用"拜鬼"口语代称。
✅安全表述：客观陈述"部分日本政客参拜靖国神社、供奉玉串料"，限定主体为政客、右翼势力。

**涉台**
❌高风险表述：将台军作为国家军队称呼；两岸对等叙事；模糊台湾属于中国的事实；引用境外分裂势力话术。
✅安全表述：民进党当局、台湾地区；台地方武装。

**涉军**
❌高风险表述：自媒体杜撰武器参数、我方军事部署；臆测开战时间；编造境外军事机密情报；渲染战争狂热。
✅安全表述：只能转述国防部、新华社等权威公开发布信息。

**涉美国际关系**
❌高风险表述：全盘辱骂美国民众，把美国全部民众等同于美国政府、政客行为。
✅安全表述：批判美国部分政客、美国某些政策、霸权行为。

**涉近现代历史**
❌高风险表述：篡改、淡化侵略史实；对受害先烈进行戏谑调侃；片面单方面洗白侵略方。

#### 3）情绪化定性词、网络黑话梗、绝对化用语【较确定】
- 情绪化定性：卖国贼（自媒体不要给外国政客扣这个帽子，客观描述行为）、魔鬼、歹毒、狼子野心；
- 绝对化用语：必定、注定、百分百、永远、唯一；
- 网络黑梗：各类网络玩梗代指国际政治历史事件的段子；
>注意：史实陈述可以客观描述历史行为，但自媒体不适合输出网感式骂人标签。

#### 4）谐音/拼音/emoji替换为什么无效，平台如何识别【确定】
1. 平台预处理阶段做**文本归一化引擎**：过滤特殊符号、空格；拼音还原汉字；谐音发音映射；形近字识别；emoji语义映射；把变体还原成本来语义再做匹配检测。
2. 不是简单匹配文字，是**语义模型识别意图**；哪怕全部替换拼音，上下文语义清晰，依旧判定风险；
3. 实操结论：**靠谐音、拼音、emoji规避审核基本无效，反而会被标记为刻意规避审核，加重风险**。

## 三、表述规范层
### 1、哪些主体可以批判、哪些表述方式安全（范式）【较确定】
✅可以批判对象：他国**政客、右翼势力、政府具体政策、防卫省机构、特定政治行为**。
❌禁止批判对象：一个国家全部国民、整个民族。

✅安全写法范式：
1. 转述官方：**直接引用外交部、国防部公开表态原文，标注来源**；不要自媒体二次加工演绎去夸赞官方机构。
>错误：点赞外交部。正确：中国外交部就此事件发表声明，提出严正交涉。
2. 限定主体：永远把主语限定在群体，不要扩大到国家；
>错误：日本在扩军备战。正确：日本部分政客推动防卫省大幅提升防卫预算。
3. 数据带源：所有引用境外媒体、机构数据，标注来源。
4. 行为批判，少人身攻击：批判行为造成的危害，不对个人进行辱骂定性。

### 2、自媒体与官媒的待遇差异具体体现在哪些规则上【较确定】
1. 词汇尺度：官媒可使用的部分强定性词汇，自媒体禁止使用；官媒可以直接使用强情绪批判词汇，自媒体同等词汇会触发限流；
2. 官方机构评价：官媒可以公开赞扬、评价我方部门；自媒体不允许"点赞/致敬外交部"这类表态，只允许客观转述官方对外发布的内容；
3. 信源自由度：官媒可以直接引用各类外媒信息；自媒体引用外媒必须完整标注来源，不能模糊写"外媒称"；
4. 预言、局势推演：官媒拥有局势研判资质；普通自媒体对战争、冲突推演限制严格；
5. 素材使用：官媒可使用部分烈度较高历史影像；自媒体使用血腥暴力历史画面更容易被下架；
6. 处罚容错：同等违规，自媒体更容易触发扣分降权；官媒账号豁免大部分处罚。

### 3、标题、封面、字幕、贴纸各自风险点【确定】
>标题、封面权重**高于视频正文口播**，机器人工优先扫描标题封面。
1. **标题**
高风险：反问煽动、极端预言、夸张猎奇标题；用网络黑梗做标题；把情绪化标签放在标题；
安全：客观陈述事件、陈述反差、讲客观影响，避免情绪煽动。
2. **封面**
风险点：封面大字贴纸使用敏感黑话、煽动性文字；使用暴力血腥历史截图；错误地图；敏感人物图像。
3. **字幕**
风险点：字幕和口播内容不一致，口播有敏感词字幕删掉，ASR语音识别依旧抓到；花字贴纸、片尾小字，全部纳入OCR识别范围。
4. **贴纸/片尾文案**：不要放暗示性文字、网络梗，全部纳入审核范围。

## 四、数据与事实层
### 1、数据来源标注的具体要求【确定，网信办明确要求】
❌不合规标注：网传、外媒消息、有报道称、圈内消息；模糊来源，不写具体机构名称。
✅合规标注格式示例：
1. （数据来源：日本防卫省2027财年预算申请文件）
2. （来源：共同社公开报道）
>要求：**每一组关键数据，就近标注来源，不要只在视频结尾笼统写"素材来源于网络"**；自媒体整合多方信息，需要分别标注。
>无来源的境外军费、财政、政客讲话数据，属于重点整治对象，极易限流下架。

### 2、事实错误的处罚等级【较确定】
1. 轻微事实偏差：视频下架，不一定扣分；修改事实重新发布；
2. 编造、篡改历史、编造境外政客讲话、伪造官方数据：视频下架，扣账号健康分；多次出现账号降权；
3. 刻意编造虚假信息造成大量传播：直接严重处罚，限流封禁，网信办可溯源处置账号。

### 3、预言类内容（战争/崩盘/冲突预测）的红线在哪【较确定】
❌禁止：自媒体给出确定性预言："一定会开战""必然崩盘""几月就会爆发冲突"；渲染战争即将到来的恐慌情绪。
✅允许：只做客观推演："按照当前政策走向，存在XX风险，有相关分析机构提出XX判断"；**必须说明是机构观点，不是博主个人笃定预言**。
>核心红线：自媒体不能输出个人笃定的未来事件判断，只能转述权威机构的分析，区分"客观风险分析"和"个人预言"。

## 五、账号与运营层
### 1、违规累积机制、扣分、账号降权的规则【较确定】
1. 账号健康分满分100分；违规记录**不会自动清零，跨年依旧留存**，多次同类违规处罚叠加加重。
2. 同一条视频删除，**不会消除账号后台违规记录**；申诉前优先设置私密，保留证据，不要直接删除视频。
3. 阶梯处罚逻辑：
    - 第一次轻度擦边：视频减少推荐/下架，警告，不一定扣分；
    - 2‑3次同类违规：扣除健康分，账号整体降权，该账号所有时政类内容复审等级提高；
    - 多次严重违规：投稿限制、禁止直播、账号封禁；关联矩阵账号连带风控。
4. 账号降权表现：该账号所有时政类视频默认进入人工复审，初始播放池大幅压缩；非时政内容流量影响相对更小。

### 2、新号vs老号的容错差异【较确定】
1. 新号（粉丝少，无历史作品）：容错最低，时政类内容只要擦边就直接隐性限流；新号不建议直接做大尺度国际时政口播。
2. 垂类老号，长期稳定合规输出同类内容：同等擦边，更容易放行；但一旦触碰严重红线，处罚同样严厉，老号不会豁免。
>注意：老号历史没有违规，不代表可以随意擦边；重大时间节点全部账号审核标准统一收紧。

### 3、DOU+/千川对时政内容为什么过不了审，机制是什么【较确定】
1. DOU+、千川属于商业投放，商业素材审核标准**严于普通自然流量审核**；
2. 时政国际关系、历史军事类内容，**绝大多数场景禁止付费加热**，即使自然流量可以发布，投放审核也会被拒绝；
3. 机制：投放素材会走一套独立的多模态审核，不参考自然流量是否放行；只要判定属于高风险时政，直接拒绝投放；
4. 结论：不要对时政解说类视频投DOU+/千川，几乎无法过审。

### 4、申诉机制的实际情况【较确定】
1. 申诉入口：创作者中心‑账号检测‑对应违规通知‑前往申诉；需要提交：完整素材、权威来源截图、详细理由，解释哪里合规，而不是单纯喊冤。
2. 现实情况：
    - 事实错误类：拿出权威史料、新闻截图，申诉通过率较高；
    - 语义擦边、主观表述问题（煽动风险、情绪化），申诉通过率很低；平台拥有对语义理解的裁量权；
3. 申诉失败：只能修改稿件，重新发布；删除原违规作品不改变申诉结果。
4. 无站内信的隐性限流：**没有申诉入口**，只能修改文案重新发布。

## 六、动态变化
### 1、近一年规则收紧/放松的方向【较确定】
1. 收紧方向
    ① 自媒体国际时政、历史内容，强化**信息来源标注**，严查无来源境外数据，网信专项重点整治；
    ② 打击煽动民族对立，严格区分政客与普通民众，对全盘抹黑某国全体国民处置加重；
    ③ AI多模态语义模型升级，不再只看关键词，整段语义、情绪意图识别能力增强，谐音规避手段失效；
    ④ 财经军事无资质自媒体，对局势、军备、经济崩盘类预言管控收紧；
    ⑤ 重大历史纪念日，平台专项巡检存量历史视频，老视频回溯处置变多。
2. 放松方向：没有大规模放松；客观理性的历史、国际关系分析，只要来源可靠、立场合规，依旧可以正常分发。

### 2、网信办专项整治与平台规则的联动【确定】
1. 网信办发布自媒体专项整治通知之后，抖音会同步更新内部审核策略，提高对应类目复审比例，扩大巡检范围；
2. 重点整治方向会直接映射到机器关键词库、人工审核重点；例如整治"自媒体乱象"重点：不实国际信息、不标注来源、煽动对立、篡改历史；
3. 专项整治期间，同样内容的审核尺度会比平时严格；专项结束之后，基础规则保留，复审比例回落，但是红线不会取消。
4. 网信办会对平台做巡查，平台有义务处置违规自媒体内容，所以专项期间会主动提高处置率。

>补充：以上全部为平台内容处置逻辑，**不代表创作者所有合规内容一定获得高流量；合规只是拿到分发资格，流量依旧由内容完播、互动等推荐算法决定**。
