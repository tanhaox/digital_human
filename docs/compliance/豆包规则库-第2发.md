# 抖音自媒体时政/国际关系/历史/军事/财经口播视频审核规则体系
> 说明：本整理基于抖音公开社区自律公约、网信办公开监管文件、行业公开复盘材料，**非平台内部绝密文档**，部分机制为行业实践推演；每条标注确信等级：【确定】=公开文档明确写明；【较确定】=大量行业案例稳定复现；【推测】=行业从业者普遍共识、无官方原文直接佐证；【不确定】=平台未披露、存在波动。

## 一、审核机制层
### 机器审核（一审）抓什么【较确定】
> 发生在视频上传发布瞬间，多模态并行校验，输出风险标签，不直接做最终定性，高风险直接拦截，中低风险送入人工复审队列。
1. **关键词库**【确定】
    - 作用方式：静态黑名单词库命中，覆盖口播语音转写文本、字幕、标题、封面OCR、贴纸文字、简介。分为精确命中、模糊命中、组合命中；部分词单独出现无害，多词组合触发风险标记。
    - 行为：高危词直接拦截不进入发布；中危词打风险标签推送人工；观察级词不拦截，但拉高整体风险分，影响推荐权重。
2. **语义模型（大模型语义理解）**【较确定】
    - 作用方式：不局限单个词，理解整句、段落立场、叙事倾向、价值判断。识别歪曲解读、片面引导、煽动情绪、断章取义，无高危关键词也可判定内容风险；会比对官方知识图谱，识别史实、时政、财经事实偏差。
    - 行为：输出风险打分，打分高直接送人工复审；低分则降低公域推荐权重，不弹出违规通知。
3. **画面识别**【较确定】
    - 作用方式：关键帧指纹识别，识别违规影像素材：错误地图、敏感人物影像、历史敏感影像、境外敏感标识、军事涉密画面、未经授权军事装备涉密影像；识别封面文字、贴纸、背景屏幕文字；识别拼接剪辑伪造的事件画面。
    - 行为：命中高危画面直接拦截；存疑画面送入人工复审。调速、镜像、加滤镜无法规避关键帧指纹比对。
4. **语音识别（ASR）**【确定】
    - 作用方式：把口播音频完整转写文本，与词库、语义模型对接；识别口音、停顿、谐音变体；区分正常口误与刻意敏感表述；不仅识别词汇，识别语气煽动性。
    - 行为：音频转写后文本命中风险，等同字幕违规；音频与字幕不一致，**音频内容优先级高于字幕**。

### 人工复审（二审）什么时候触发、审核员看什么、判定尺度【较确定】
1. **触发人工复审的场景**
    - 机器一审标记中高风险标签；【确定】
    - 视频流量突破流量池阈值（几百、几千、几十万播放，流量越高复审概率越高）；【较确定】
    - 用户举报达到阈值；【确定】
    - 账号历史存在违规记录，触发常态化抽检；【较确定】
    - 热点事件、重大国际冲突发生，该类选题全部提升人工复审概率；【较确定】
    - 存量视频回溯巡检，老视频会被二次复审，可出现历史视频后期下架限流；【较确定】
2. **审核员完整核查对象**【确定】
    口播音频、字幕、标题、封面、贴纸、视频内插图、简介；不单独看某一句话，看**全篇整体立意、叙事角度、情绪导向**；参考账号历史违规记录、账号资质；参考官方公开资料比对事实正误。
3. **判定尺度**【推测】
    - 官媒、权威媒体账号与自媒体执行两套尺度；自媒体对时政国际军事财经解读容错显著更低。
    - 区分：客观转述事实 / 主观偏激定性 / 歪曲篡改史实 / 煽动对立；同样一句话，上下文不同，判定结果不同。
    - 区分无心口误、素材误用 vs 刻意输出错误导向；多次同类违规会加重处罚。
    - 存在灰度样本，同一内容不同批次审核存在小概率判定差异。

### 限流的分级形式（隐性限流/仅粉丝可见/减少推荐/下架）各对应什么违规程度【较确定】
1. **隐性限流（降权重、减少公域推荐，无系统处罚通知）**【较确定】
    - 对应：轻度风险，没有明确硬性违规，但叙事片面、情绪化、事实存在小瑕疵、选题高敏感；机器语义打分偏低；没有达到下架标准。
    - 表现：播放量显著低于账号均值，0-几百播放，粉丝可正常刷到，外部搜索可以搜到视频；无罚单、无扣分。
2. **仅粉丝可见（限制公域分发）**【较确定】
    - 对应：中度风险，内容存在瑕疵，不宜对外大范围传播，但不必直接删除。
    - 表现：非粉丝刷不到，粉丝可以观看、评论；外部搜索无法检索；部分场景附带站内警告弹窗。
3. **减少推荐（公开可见，但压制流量）**【确定】
    - 对应：明确轻度违规，平台下发违规通知，视频保留，但是公域流量池大幅压缩；可以正常被搜索，所有人可看。
4. **视频下架（删除）**【确定】
    - 分为：用户可申诉下架、不可申诉直接删除。
    - 可申诉下架：中度违规，事实错误、不当解读、违规表述；视频源后台保留，申诉通过可恢复。
    - 不可申诉直接删除：严重红线违规（分裂、诋毁英烈、恶意歪曲重大历史、造谣重大时政事件等），直接删除，一般伴随账号处罚。

## 二、风险词库层
> 注意：词库是动态更新，不是命中即处罚，**结合上下文语义综合判定**；很多词汇单独出现没问题，组合、语境错误才触发风险。

### 时政国际类高危词完整清单（按严重程度分级）【推测】
#### 直接删除级（高概率下架+账号处罚，语境容错极低）
分裂国家相关、否定一个中国原则、各类分裂势力专有名词；恶意诋毁国家制度；恶意抹黑国家领导人；诋毁革命先烈、英雄烈士；泄露国家机密相关表述；美化侵略、美化恐怖主义；煽动颠覆；煽动民族仇恨对立。

#### 限流级（大概率人工复审，容易减少推荐/仅粉丝可见）
涉及重大外交事件的极端化评判；对他国国家元首恶意人身攻击；涉及领土主权争议的非官方片面结论；对我国政策进行曲解否定；渲染战争狂热；大规模社会动荡预言；金融系统性崩盘、重大经济危机煽动性论断。

#### 观察级（单独出现一般没事，搭配情绪化表述就容易限流）
大国博弈、地缘冲突相关常规名词；他国政坛人物姓名；各类国际组织名称；常规军事装备名称；常规宏观经济名词。

### 涉日、涉美、涉台、涉军、涉历史的具体敏感表述【较确定】
1. **涉台**【确定】
    - 删除级：出现"两国"等违背一个中国表述；使用错误地图；美化台独势力；否定历史事实。
    - 限流级：自媒体自行解读台海局势，输出主观战争时间预判；片面引用境外媒体片面言论当做事实。
    - 安全边界：引用官方公开新闻、官方白皮书表述。
2. **涉日**【较确定】
    - 删除级：美化日本侵略历史；洗白侵华战犯；否定南京大屠杀等史实；美化军国主义符号。
    - 限流级：极端全盘仇恨煽动；歪曲战后历史审判；对当代日本整体做极端标签化定性。
3. **涉美**【较确定】
    - 删除级：全盘美化吹捧霸权行为，诋毁我国立场。
    - 限流级：通篇情绪化谩骂人身攻击；全部事件单一阴谋论解读；无来源编造美国内部重大事件。
4. **涉军**【较确定】
    - 删除级：泄露、推测涉密武器参数、未公开军事部署；传播境外涉密军事情报；造谣我军事件；美化侵略武装。
    - 限流级：自媒体自行推演战争胜负、精确开战时间；对现役军人进行无端指责；非官方渠道爆料军事消息。
    - 观察级：公开已经官宣的装备、公开军演信息。
5. **涉历史**【确定】
    - 删除级：歪曲近现代重大历史事件；洗白历史反面人物；解构、调侃革命历史、革命先烈。
    - 限流级：片面截取史料，输出颠覆性非主流结论，无权威史料支撑；历史事件简单二元对立煽动情绪。

### 情绪化定性词、网络黑话梗、绝对化用语清单【较确定】
1. **情绪化定性词（时政军事国际高频）**：必死、必亡、彻底完蛋、注定崩盘、全面溃败、蓄谋已久、十足阴谋、百分之百注定爆发战争。
2. **网络黑话梗**：部分网络圈层针对国家、时政、历史人物的戏谑梗，即使玩梗，口播字幕出现即会触发复审。
3. **绝对化用语【确定】**：100%、必定、绝对、唯一、永远、全部、彻底；财经口播：稳赚、必涨、必跌、保本、零风险。

### 谐音/拼音/emoji替换为什么无效，平台如何识别【较确定】
1. 识别逻辑：【较确定】
    - ASR语音识别直接识别读音，口播谐音完全无效。
    - OCR模型识别字形、拼音、emoji语义映射；模型学习大量变体样本，对替换字、拆字、中间插特殊符号、emoji代指做语义还原匹配。
    - 不只看单字，看上下文语义，即便全部替换，语义模型读懂含义依旧判定风险。
2. 后果：使用谐音、emoji规避审核，不会逃脱审核；部分场景会判定为刻意规避平台规则，加重处罚。

## 三、表述规范层
### 哪些主体可以批判、哪些表述方式安全（转述官方/限定主体/数据带源的写法范式）【较确定】
1. 自媒体可以批判的边界：
    - 可以批判**境外机构、外国政府公开政策行为**，必须基于公开事实，禁止人身侮辱、全民族全盘抹黑。
    - 可以引用官方公开批评、官方定调，转述官方观点。
    - 不允许自媒体自行对我国现行政策、国家制度做否定、批判、戏谑解读。
2. 安全表述范式【确定】
    1）转述官方："根据XX官方发布消息……"，完整引述，不篡改原意，再附加有限个人分析；
    2）区分信息来源："某外媒报道称，该报道观点仅供参考，不代表我方立场"；必须标注，不能直接把外媒报道当成事实定论；
    3）数据带源：每一个关键数据标注出处机构、时间；
    4）区分事实与观点：明确分割"已发生客观事实"和"个人分析推测"，推测部分要加上"个人观点、仅供参考"；
3. 禁止范式：无来源直接下定论；把网传、小道消息当做事实；用煽动性反问引导情绪。

### 自媒体与官媒的待遇差异具体体现在哪些规则上【推测】
1. **选题权限**：【推测】官媒可以直接解读重大时政、外交、军事突发；普通自媒体不允许第一时间解读重大突发时政，自媒体优先转发官媒内容，自行解读更容易触发复审限流。
2. **容错尺度**：【推测】同样一处表述瑕疵，官媒一般退回修改；自媒体更容易限流、下架。
3. **事实偏差容错**：【推测】官媒素材错误以更正为主；自媒体事实错误直接处罚。
4. **预测推演**：【推测】官媒允许严谨局势分析推演；自媒体战争、冲突、经济崩盘推演红线严格。
5. **资质门槛**【确定】：财经领域，官媒天然具备发布财经资讯权限；自媒体必须取得对应资质，才可发布财经分析，无资质直接违规。
6. **申诉权重**：【推测】官媒申诉优先级高；普通自媒体申诉审核周期更长。

### 标题、封面、字幕、贴纸各自的风险点【确定】
> **全部位置都参与审核，标题封面权重甚至高于视频正文口播**。
1. **标题**：禁止夸张煽动、"即将开战""马上崩盘"等博眼球标题；禁止截取视频局部一句话断章取义；禁止使用谣言式问句。
2. **封面**：封面大字体文字等同于字幕审核；禁止使用敏感历史图片、错误地图、煽动性配图；封面文字不能比正文更加激进。
3. **字幕**：字幕和口播不一致，**以口播音频为准**；字幕不能删减规避敏感内容，音频口播依旧会被ASR识别。
4. **贴纸/画面文字**：视频内贴纸、后期弹窗文字，全部OCR识别，等同于字幕；不要用贴纸写敏感表述。

## 四、数据与事实层
### 数据来源标注的具体要求（什么算合规标注）【较确定】
1. ✅合规标注【确定】：完整写明机构名称+发布时间，例："根据2026年XX研究院发布报告显示"；引用官方新闻写明"新华社XX时间报道"。
2. ❌不合规标注，会被判定来源模糊【确定】：网传、有消息称、外媒消息、有报道称、数据显示、消息人士透露，没有写具体机构时间，时政国际财经类高频触发违规处罚。
3. 规则：自媒体不能把外媒报道直接当做客观事实，必须标注"外媒报道，观点仅供参考"；引用境外数据尽量搭配国内权威机构交叉佐证。
4. 引用二手转述，不能只写"网上看到"，要追溯原始权威来源。

### 事实错误的处罚等级【较确定】
1. **轻微事实偏差**（次要细节小错误，无主观恶意）：弹窗警告，视频可保留，减少推荐，一般不扣分。
2. **中等事实错误**（关键史实、时政、财经数据错误，误导公众）：视频下架，可申诉，账号累积违规记录。
3. **严重事实错误（造谣篡改历史、编造重大时政事件、编造宏观财经重大谣言）**【确定】：直接删除视频，扣分，禁言，严重直接封禁账号，网信办会同步处置通报。

### 预言类内容（战争/崩盘/冲突预测）的红线在哪【较确定】
1. ❌绝对禁止：自媒体给出确定性时间、确定性结果，例如"XX月份一定会开战""明年经济必然崩盘"；【较确定】
2. 限制：可以做局势推演分析，但**不能下确定性预言结论**；必须反复声明："仅为个人推演，不代表实际会发生，局势存在多重变量"；不允许渲染恐慌、煽动焦虑。
3. 财经预言红线【确定】：无资质账号禁止预测股市大盘、经济走向涨跌；有资质账号也不允许确定性涨跌预言，必须附带全套风险提示。

## 五、账号与运营层
### 违规累积机制、扣分、账号降权的规则【较确定】
1. 违规是**累积制**，不是单次清零；同一账号多次轻度违规，处罚逐步升级：单次警告→多次限流→下架视频→短期禁言→长期限制发布→封禁账号。
2. 扣分体系：抖音社区自律公约有信用分机制，不同违规扣除不同分值；分数过低会限制发布、取消流量扶持、取消变现权限。【确定】
3. 账号降权：不是单一开关，是风险标签叠加；多次时政/军事/财经违规，账号整体打上高风险标签，后续该账号所有新视频复审概率大幅提升，天然压低基础推荐；即使新视频完全合规，基础流量也会变差。【较确定】
4. 主体连带：同一实名下多个账号，其中一个账号严重违规，会牵连同实名其他账号风控提升。【推测】

### 新号vs老号的容错差异【较确定】
1. **新号（0-1万粉丝）**：风控基线更高；时政、军事、国际关系选题，机器更容易打高风险标签；轻微瑕疵更容易限流；新号不建议优先碰高风险选题。
2. **老号垂直垂类账号（长期稳定输出同类合规内容）**：历史合规记录良好，同等瑕疵下容错略高；但是一旦触碰红线，处罚标准一致，不会因为粉丝多而豁免。
3. 大V账号监管更严：粉丝量级越高，人工复审频次越高，监管标准收紧，热点内容会被重点巡检。【确定】

### DOU+/千川对时政内容为什么过不了审，机制是什么【较确定】
1. DOU+/千川投放有独立的广审链路，标准严于普通自然流量审核；【确定】
2. 机制：先机器多模态筛查，高风险直接驳回；存疑全部进入人工广审队列；时政、国际关系、军事解读类口播，**绝大多数情况直接拒绝投放**，无论自然流量是否能过审；营销投放不允许将时政、地缘、军事作为营销流量素材。
3. 现象：一条视频自然流量正常分发，但是投放DOU+提示审核不通过，属于正常现象；DOU+驳回本身不会直接处罚账号，但短时间多次驳回，拉高账号投放风控。

### 申诉机制的实际情况【较确定】
1. 申诉入口：APP内违规通知卡片提交申诉，需要写明理由、附上权威资料佐证。
2. 时效：一般几小时到1-3个工作日。
3. 成功率：
    - 事实错误误判，有权威资料佐证，申诉恢复概率较高；【较确定】
    - 语义、立场、叙事导向类的灰度限流（隐性限流，无罚单），**没有申诉入口**，无法申诉；【较确定】
    - 触碰硬性红线（歪曲历史、分裂言论等）几乎申诉失败。【确定】
4. 限制：同一条视频有限申诉次数；多次申诉失败，不要再反复提交；存量历史视频下架，同样可以申诉。
5. 注意：申诉不会消除历史违规记录，即使视频恢复，该次违规记录依然留存账号档案。【推测】

## 六、动态变化
### 近一年规则收紧/放松的方向【较确定】
1. **收紧方向**
    1）自媒体涉国际时事信息来源标注强制要求，严打"网传式"模糊来源；【确定】
    2）无资质自媒体财经内容管控升级，禁止预测行情、荐股；【较确定】
    3）历史、军事类自媒体严打阴谋论、碎片化歪曲历史；【较确定】
    4）强化AI生成口播内容校验，AI生成时政历史财经内容要求事实可溯源；【较确定】
    5）加大存量历史视频回溯巡检，老视频会因为规则更新被二次处置。【较确定】
2. **放松方向：没有大规模放松；仅对于完整标注来源、客观转述官方信息、无极端情绪化的理性科普解读，保留分发空间。【推测】**

### 网信办专项整治与平台规则的联动【确定】
1. 网信办出台自媒体治理专项通知，平台会直接更新审核细则，扩大对应类别人工复审比例，开展专项巡查；专项整治期间，对应题材审核标准短期显著收紧。
2. 网信办通报典型违规自媒体案例，平台会把案例的违规特征加入模型样本，强化机器识别。
3. 平台需要定期向网信办报送违规账号处置数据；重大违规账号，平台处置同时上报网信部门。
4. 专项整治结束之后，模型、词库不会回退旧版本，只是人工抽检强度会有所回落。
