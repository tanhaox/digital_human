# 豆包规则库 · 拆书线第 4 发（2026-08-19）

> 来源: 豆包对"蒸馏前置审核"讨论的返回——书籍三级分级框架 + 4 项极简结论法 + 2 条账号实操经验。
> 用途: config/compliance_rules_book.json `book_grading` (Gate 0 预评估) 榨取源。

## 三类书籍分级（短视频读书解说，抖音/西瓜通用）
### 🟢低风险：放心做
普通文学、人物传记、通俗心理学、历史故事、商业思维、个人成长。
>特点：没有触碰民族宗教、意识形态、阴谋论、极端社会批判、敏感历史定性。
>操作：简单加一句"仅代表书中观点"即可。

### 🟡中等风险：可以做，但不能照搬原文，必须大量转述+前置免责
《乌合之众》、《修补世界》都属于这一档。书本身是正规出版物，但里面含有：
- 旧时代种族/族群论述
- 对制度、社会模式的尖锐批判
- 容易被截取当阴谋论素材的案例
**不是不能讲，但是绝对不能摘抄大段原文、不能拿原句做大字幕，不能把书中观点当成真理输出，更不能映射当下现实。**
>代价：审核更容易进人工复审，流量会比普通读书稿更不稳定，容易隐性限流。

### 🔴天然高危：尽量不做短视频解说，直接放弃
哪怕书是正规出版，也不适合短视频口播解读，很容易审核驳回、账号扣分：
1. 大量渲染阴谋论类（金融阴谋、世界幕后统治这类题材）
2. 深度涉及多民族优劣对比、宗教教义论战、极端民族理论
3. 对近现代社会制度做全盘激进批判的社科著作
4. 部分历史修正主义、对重大历史事件重新颠覆性定性
5. 部分域外社科，站在域外立场评判本国历史社会

>重点：**书能出版 ≠ 适合短视频口播解说**。纸质出版物审核逻辑，和短视频算法审核逻辑完全两套。纸质允许大段思辨、尖锐原文；短视频机器看词汇、语义联想、金句字幕，很容易误命中。

## 输出 4 项极简结论
1. 风险等级：🟢可放心 / 🟡谨慎可做 / 🔴建议放弃
2. 核心风险点（哪几块最容易踩坑）
3. 最低安全操作（要不要免责、哪些段落直接舍弃）
4. 要不要避坑：要不要干脆不做这本书

## 补充实操经验
1. **同样一本书，图文读书笔记，比视频口播宽容很多；视频+醒目大字幕是审核最严模式**，金句字幕是重灾区。很多书文稿看着没问题，一做成大字幕就触发复审。
2. 中等风险的书，不要频繁连续做。连续两本高风险社科，会拉高账号整体复审权重，后续普通内容也更容易被卡流量。高风险书建议穿插大量普通低风险书籍来稀释账号标签。
